预警页写明这些记录是规则链按演示数据预先放进页面的。生产构建的智能分析页播放 `/demo/analysis.mp4`，并写出 23 类、94.05% 和「本页不提供公网实时上传」。两处上传控件包在 `v-if="!staticDemo"` 里，开发构建仍可上传，用来录视频。没有「在线体验」按钮。

导航里的相关数据、灾害实时监测、智能分析、灾害预警、智慧决策都还在。

视频文件本身在任务 11 放入 `public/demo/analysis.mp4`。这一步只接上播放器。

### src/views/user/DataAnalysis.vue

```vue
<section v-if="staticDemo" class="analysis-demo">
  <video controls playsinline preload="metadata" :src="analysisDemoVideo"></video>
  <p>{{ ANALYSIS_DEMO_NOTE }}</p>
  <p>{{ MODEL_METRICS_LINE }}</p>
</section>
```

`analysisDemoVideo` 是字符串 `'/demo/analysis.mp4'`。不用模板上的静态 `src`，否则 Vite 会把它当成要打包的模块；文件在 `public/demo/`，应作为站点根路径在运行时播放。

上传区用 `<template v-if="!staticDemo">` 包住主预览和弹窗里的「更换图片」。

```ts
import { ANALYSIS_DEMO_NOTE, MODEL_METRICS_LINE } from '@/demo/copy'

const staticDemo = import.meta.env.PROD
```

```css
.analysis-demo video {
  width: 100%;
  max-height: 420px;
}
```

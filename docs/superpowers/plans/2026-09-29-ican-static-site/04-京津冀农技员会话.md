# 任务 4：生产构建直接进入京津冀农技员会话

评委打开静态站时不应先撞上登录接口。生产构建在读登录状态之前写入 `token=demo-static` 和农技员身份，根路径因此进首页。已经有 token 时不覆盖。开发构建不写 token，默认区域仍是东北。

生产构建的默认监测区域改为京津冀，雄县、河间、栾城才会出现在地图和预警列表里。预警、决策、地图这些路由的登录要求没有去掉。

测试：`pnpm exec tsx --test src/demo/session.test.ts`，3 项通过。

## 代码

### src/demo/session.ts

```ts
export const STATIC_DEMO_USER = {
  id: 1,
  name: '演示农技员',
  phone: '13800000000',
  role: 'agronomist' as const
}

export function seedStaticDemoSession(
  prod: boolean,
  storage: { getItem(key: string): string | null; setItem(key: string, value: string): void }
) {
  if (!prod) return
  if (!storage.getItem('token')) {
    storage.setItem('token', 'demo-static')
    storage.setItem('userInfo', JSON.stringify(STATIC_DEMO_USER))
  }
}
```

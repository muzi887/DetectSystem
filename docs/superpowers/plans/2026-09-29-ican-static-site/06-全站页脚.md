# 任务 6：全站页脚声明

每个套在 `AppLayout` 里的页面底部都显示同一句竞赛演示声明，包括首页、地图、预警、决策、相关数据、智能分析和关于我们。文案来自任务 1 的 `FOOTER_DISCLAIMER`，不在每个页面再抄一遍。

导航仍是：首页、相关数据、灾害实时监测、智能分析、灾害预警、智慧决策、关于我们。

测试：`pnpm exec tsx --test src/demo/footerSource.test.ts`，通过。

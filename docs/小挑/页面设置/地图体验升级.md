 **🌦 阶段 4（可视化 + 地图）
把图表、地图交互、实时感知这些“让 demo 更像产品”的功能做出来。

A — **增强地图体验（推荐）**

- 做什么：为 Leaflet 加入 Marker 聚类、不同状态的自定义图标、以及点击 marker 显示更丰富的 popup（含“触发/关闭预警”按钮）并即时刷新 Alerts 列表。
    
- 学到：第三方库集成（leaflet.markercluster）、DOM 与 popup 事件绑定、数据驱动 UI。
    
- 何时选它：你想让地图在数据量上看起来专业，并且想练手事件->API->状态更新的完整链路。
    

B — **实时数据模拟（伪实时）**

- 做什么：在前端用 `setInterval` 或用 `socket.io`（mock）模拟实时数据推送，地图和仪表盘实时更新；或用 Server-Sent Events (SSE) 简单实现。
    
- 学到：WebSocket / SSE 基本使用、前端订阅/去订阅、状态同步策略。
    
- 何时选它：你想演示“实时监测”和报警即时弹出效果，或为后续接真实传感器打基础。
    

C — **图表交互与时间筛选**

- 做什么：把 Dashboard 的折线图升级为可交互（范围缩放、tooltip、按等级筛选、时间段选择器），并把筛选条件与 Alerts 列表联动。
    
- 学到：ECharts 交互事件、数据聚合、组件间通信（筛选条件在 store 里管理）。
    
- 何时选它：你要做一个分析演示（展示历史趋势、筛选对比），或准备给产品经理看的数据交互证明。
    

D — **UI 打磨 & 可用性**

- 做什么：优化 Ant Design 布局、响应式样式、权限视图、表格分页、导出（CSV）功能以及基本无障碍（aria）改进。
    
- 学到：产品级界面细节、可访问性、生产准备（导出、分页、性能）。
    
- 何时选它：你想把 demo 做得更正式、好看、对评审更友好。

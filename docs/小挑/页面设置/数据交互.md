## 🧭 （循序渐进版）

> 我把原来的 8 步调整成**5个阶段**，每个阶段都能让你学到一个「新的关键技能」并有**实操任务**。  
> 每次我只会带你做**一个阶段**，等你完成我再带你进入下一个。

---

### 🌱 阶段 1：项目初始化与页面框架（Vue + Router + Ant Design Vue）

**目标**：能启动项目、切换页面、看到登录页和仪表盘基础框架。  
**你将学到**：

- 用 Vite 新建 Vue3 项目
    
- 安装并使用 Ant Design Vue
    
- 创建多页面路由（Login、Dashboard、Monitor）
    
- 基本布局（顶部导航、侧边栏）
    

---

### 🌾 阶段 2：状态管理与登录逻辑（Pinia + localStorage）

**目标**：完成登录页，能“假装登录”，并在 Dashboard 显示用户名。  
**你将学到**：

- Pinia store 管理用户状态
    
- 模拟登录流程（不用后端）
    
- localStorage 保存 token
    
- 路由守卫：未登录不能访问 dashboard
    

---

### ☀️ 阶段 3：Mock 数据与 HTTP 请求（json-server + Axios）

**目标**：能从本地 mock 接口拿数据，渲染在页面上。  
**你将学到**：

- 用 json-server 模拟后端数据
    
- Axios 请求与响应处理
    
- 数据展示（表格、卡片）
    
- 数据刷新逻辑
    

---

### 🌦 阶段 4：可视化与地图（ECharts + Leaflet）

**目标**：展示灾害趋势图表、地图上显示监测点。  
**你将学到**：

- 集成 ECharts
    
- 使用 Leaflet 展示地理数据
    
- 异步加载 mock 数据
    
- 动态 marker / 数据绑定
    

---

### 🌾 阶段 5：预警中心与交互优化

**目标**：展示预警信息、支持筛选和状态更新。  
**你将学到**：

- 组件通信（父子组件事件）
    
- 动态表格与筛选逻辑
    
- API 模拟更新（POST / PUT 请求）
    
- 最终演示项目打包与总结
    

---

Dashboard 页面提供了：

1. **系统概览** - 关键指标统计
    
2. **预警管理** - 预警列表展示
    
3. **预警操作** - 创建、标记解决、删除
    
4. **状态管理** - 使用 Pinia 管理预警状态
    
5. **用户反馈** - 操作成功/失败提示

## 新增的 alerts 特点：

1. **多样化的预警级别**：
   - `high`（高危）：3个
   - `medium`（中危）：3个  
   - `low`（低危）：2个

2. **不同的处理状态**：
   - `handled: false`（待处理）：6个
   - `handled: true`（已处理）：2个

3. **丰富的预警类型**：
   - 土壤湿度问题
   - 温度异常
   - 设备通信问题
   - 电池电量
   - 设备离线
   - 数据传输异常
   - 设备故障

4. **时间分布**：
   - 使用不同的时间戳，模拟不同时间发生的预警
   - 便于测试时间排序和筛选功能

这样在前端 Dashboard 页面中就能看到更丰富的测试数据，方便测试各种功能场景。

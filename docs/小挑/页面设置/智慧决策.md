这是一个非常棒的优化建议！仪表盘类页面的核心就是要让信息布局饱满、协调。

为了解决这个问题，我将对 `DecisionSupport.vue` 的布局进行调整，核心思路是：**将右侧纵向排列的两个信息卡片，改为在空间足够时横向并排显示，形成一个更饱满、更具仪表盘感的三栏式布局**。

### 主要修改点：

1. **布局结构调整**:
    
    - 在`<template>`中，我用一个新的 `<div class="right-column-grid">` 包裹了右侧的“实时监测数据”和“AI 决策建议”这两个卡片。
    - 通过 CSS Grid 布局，让这个新容器内的两个卡片**并排显示** (`grid-template-columns: 1fr 1fr`)。
2. **内容高度自适应拉伸**:
    
    - 为了让并排的两个卡片在内容多少不一的情况下也能保持**底部对齐**，我为 `.widget-card` 添加了 `display: flex` 和 `flex-direction: column`。
    - 同时，让卡片的主体内容区域 `:deep(.ant-card-body)` 能够**自动拉伸** (`flex-grow: 1`)，从而填满多余的垂直空间。这确保了无论哪个卡片内容更多，另一个都会优雅地与之对齐。
3. **占位符优化**:
    
    - 当未选择任何预警时，右侧的占位符提示现在会**在整个右侧区域垂直居中**，视觉效果更好。
4. **响应式设计**（可选，但推荐）：
    
    - 虽然未在代码中直接体现，但这种 Grid 布局很容易通过媒体查询 (`@media`) 在屏幕宽度较窄时恢复为单列堆叠，以适应移动端或小窗口。

经过这些修改，页面在宽屏下的空间利用率大大提高，视觉上更加均衡、专业，完美解决了“没有填满”的问题。

这个地图没有显示（通常表现为空白或者只有文字）的原因是 **Leaflet 地图容器的初始化时机不正确**。

### 问题分析

1. **条件渲染 (`v-if`)**: 您的代码中，包含地图的卡片是通过 `v-if="selectedArea"` 来控制是否渲染的：
    
    ```vue
    <a-card v-if="selectedArea" title="区域概览" ...>
        <div ref="mapRef" class="mini-map-container"></div>
        <!-- ... -->
    </a-card>
    ```
    
    当组件刚挂载时，`selectedArea` 是 `null`，所以这个卡片和里面的 `mapRef` 元素**不在 DOM 中**。
    
2. **地图初始化时机 (`onMounted`)**: 您的代码在组件挂载完成后（`onMounted`）尝试初始化地图：
    
    ```typescript
    onMounted(() => {
        // ... fetch data ...
        initMap() // <-- 在这里调用
    })
    ```
    
    当 `onMounted` 运行时，`mapRef.value` 仍然是 `null`，因为 map 容器还没有被 `v-if` 渲染出来。因此，`initMap` 中的 `if (!mapRef.value) return` 导致初始化提前退出，`map` 变量始终为 `null`。
    
3. **Leaflet 渲染机制**: Leaflet 必须依附于一个已经存在于 DOM 中且具有实际尺寸的 HTML 元素。
    

### 解决方案

您需要修改 `onMounted` 和 `watch(selectedArea)` 的逻辑，确保地图只在 **`selectedArea` 首次变为非空**（即地图容器被渲染到 DOM 中）时才进行初始化。

#### 1. 引入 `nextTick` 并修改 `watch` 逻辑

首先，确保从 Vue 中导入 `nextTick`。

```typescript
// 位于 <script setup> 标签内顶部
import { ref, computed, onMounted, onBeforeUnmount, watch, nextTick } from 'vue'
// ...
```

然后，修改 `onMounted` 钩子和 `watch(selectedArea)` 的逻辑：

**步骤一：在 `onMounted` 中移除 `initMap()`**

```typescript
onMounted(() => {
  dataStore.fetchAlerts()
  dataStore.fetchMonitorPoints()
  // 移除 initMap()，让它在 watch 中触发
})
```

**步骤二：在 `watch(selectedArea)` 中添加初始化逻辑**

我们需要判断 `map` 是否已创建。如果 `map` 尚未创建，使用 `nextTick` 确保地图容器 (`mapRef`) 已经被 `v-if` 渲染出来后再调用 `initMap`。

```typescript
// 确保导入了 nextTick

watch(selectedArea, (newArea) => {
  if (newArea) {
    if (!map) {
      // 1. 等待 DOM 更新，确保 v-if 渲染的 mapRef 元素已存在
      nextTick(() => {
        if (mapRef.value) { // 再次检查 mapRef 是否存在
          initMap()
          if (map) {
            updateMap(newArea)
          }
        }
      })
    } else {
      // 2. 如果 map 已经初始化，则直接更新标记点
      updateMap(newArea)
    }
  }
})
```

### 总结修改后的 Script 部分

```typescript
<script setup lang="ts">
import { ref, computed, onMounted, onBeforeUnmount, watch, nextTick } from 'vue' // <-- 重点：引入 nextTick
import * as L from 'leaflet'
// ... (其他导入保持不变)

// ... (数据和 computed 属性保持不变)

const selectedArea = ref<any>(null)
const isAreaSelected = computed(() => !!selectedArea.value)
const mapRef = ref<HTMLDivElement | null>(null)
let map: L.Map | null = null
let areaMarker = ref<L.Marker | null>(null)

// ... (selectArea, getLevelColor, getStatusColor 等函数保持不变)

const initMap = () => {
  if (!mapRef.value) return
  const darkTileLayer = L.tileLayer(
    'https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png',
    { attribution: '&copy; CARTO', subdomains: 'abcd', maxZoom: 19 }
  )
  // 注意：这里 L.map 传入的是 mapRef.value
  map = L.map(mapRef.value, { layers: [darkTileLayer], zoomControl: false }).setView(
    [35.1, 139.1],
    11
  )
}

const updateMap = (area: any) => {
  if (!map || !area.coords) return
  const { lat, lng } = area.coords
  if (areaMarker.value) {
    areaMarker.value.remove()
  }
  areaMarker.value = L.marker([lat, lng]).addTo(map)
  areaMarker.value.bindPopup(`<b>${area.pointName}</b><br/>${area.message}`).openPopup()
  map.flyTo([lat, lng], 13)
}

onMounted(() => {
  dataStore.fetchAlerts()
  dataStore.fetchMonitorPoints()
  // 移除 initMap()，它将在 watch 中被调用
})

onBeforeUnmount(() => {
  if (map) map.remove()
})

// ***** 关键修改在这里 *****
watch(selectedArea, (newArea) => {
  if (newArea) {
    if (!map) {
      // selectedArea 首次变为非空，容器已添加到 DOM，但尚未渲染尺寸
      nextTick(() => {
        // 确保 mapRef 已经存在
        if (mapRef.value) {
          initMap()
          if (map) {
            // 地图初始化后，立即更新地图视图
            updateMap(newArea)
          }
        }
      })
    } else {
      // 地图已初始化，只需更新视图
      updateMap(newArea)
    }
  }
})
</script>
```

应用上述修改后，当您从左侧列表中点击选择一个预警项时，`selectedArea` 变为非空，地图容器会被渲染到 DOM 中，`watch` 触发，并使用 `nextTick` 确保 DOM 准备好后再初始化 Leaflet，地图就会正确显示。

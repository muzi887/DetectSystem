开启 **三个** 终端：

1. **终端 1 (Python)**: 运行 `python app.py` (端口 5000)。
	1. cd server
2. **终端 2 (Mock 数据)**: 运行 `npm run mock` 或者 `npx json-server db.json` (端口 3000)。
3. **终端 3 (Vue 前端)**: 运行 `npm run dev`。

### 方案一：局域网访问

**场景**：你和想用的人连着同一个 WiFi（或者都在同一个办公室/学校内网）。  
**缺点**：你的电脑必须开着，且必须连着同一个网络。

你需要修改一下代码的启动方式，让你的服务监听“所有 IP”，而不仅仅是 `localhost`。

#### 1. 修改 Flask (后端)

修改 `app.py` 的启动代码：

```python
if __name__ == '__main__':
    # host='0.0.0.0' 表示允许局域网内的任何设备访问
    app.run(debug=True, port=5000, host='0.0.0.0')
```

#### 2. 修改 Json-Server (数据库)

修改 `src/mock/server.ts` (数据库)

打开该文件，找到最后启动监听的那一行代码（通常是 `server.listen`）。你需要添加 `'0.0.0.0'` 作为第二个参数。

请将你的 `src/mock/server.ts` 修改为如下代码：

```typescript
// 路由器启动
const PORT = Number(process.env.MOCK_PORT || 3000)

// 启动服务器监听指定端口
// 修改处：在 PORT 后面加一个 '0.0.0.0'
server.listen(PORT, '0.0.0.0', () => {
  console.log(`JSON Server is running on http://0.0.0.0:${PORT}`)
  console.log(`(现在局域网内的其他设备可以通过你的IP访问数据库了)`)
})
```

##### 解释

`server.listen` 方法的标准用法是 `server.listen(端口, 主机地址, 回调函数)`。

- **不写主机地址**：默认是 `localhost` (127.0.0.1)，只有你自己能访问。
- **写 `'0.0.0.0'`**：代表监听你电脑上所有的网卡，这样局域网里的其他人就能访问到了。

#### 3. 修改 Vite (前端)

修改 `package.json` 中的 `dev` 命令：

```json
"scripts": {
  "dev": "vite --host", 
  ...
}
```

或者在 `vite.config.ts` 的 `server` 里加上 `host: '0.0.0.0'`。

#### 4. 获取你的 IP 地址

- 打开终端（CMD），输入 `ipconfig` (Windows) 或 `ifconfig` (Mac/Linux)。
- 找到 **IPv4 地址**，通常是 `192.168.x.x` 或者 `10.x.x.x`。
IPv4 地址 . . . . . . . . . . . . : 192.168.128.160
#### 5. 让别人访问

告诉你的朋友打开浏览器，输入：`http://你的IP地址:5173`  
（注意：你的防火墙可能会拦截，如果连不上，尝试暂时关闭 Windows 防火墙）。

### 方案二：内网穿透（无需服务器，适合远程演示）

**场景**：你想发给异地的朋友看，或者手机流量访问，但不想买云服务器。  
**工具**：使用 **Ngrok** 或 **Cpolar** 等工具。

1. 下载并安装 [[Ngrok]]。
2. 在电脑上正常启动你的前端(5173)、后端(5000)、数据库(3000)。
3. 打开一个新的终端，输入命令映射前端端口：
    
    ```bash
    ngrok http 5173
    ```
    
4. Ngrok 会给你生成一个公网链接（比如 `https://abcd-1234.ngrok.io`）。
5. 把这个链接发给朋友即可。
    - _注意：免费版 Ngrok 速度较慢，且链接也是临时的。_

### 方案三：部署到云服务器（专业做法，永久在线）

**场景**：正经发布产品，即使你关机睡觉，别人也能 24 小时访问。  
**成本**：需要花钱买一台云服务器（腾讯云/阿里云/AWS），新用户通常很便宜（几十块一年）。

#### 部署流程简介：

1. **购买服务器**：买一台 Linux (Ubuntu/CentOS) 服务器。
2. **环境安装**：在服务器上安装 Node.js, Python, Nginx。
3. **前端打包**：  
    在你的项目里运行：
    
    ```bash
    npm run build
    ```
    
    这会生成一个 `dist` 文件夹。这个文件夹里就是纯粹的网页文件，不需要 Vue 也能运行。
4. **上传代码**：把 `dist` 文件夹、Flask 代码、`db.json` 上传到服务器。
5. **启动服务**：
    - **前端**：使用 **Nginx** 托管 `dist` 文件夹（作为静态网站）。
    - **后端**：使用 `gunicorn` 运行 Flask，使其在后台运行。
    - **数据库**：使用 `pm2` 运行 json-server。
6. **配置 Nginx 反向代理**：  
    配置 Nginx，让访问 `xx.com/api` 的请求转发给 Flask 端口，其他的请求指向 `dist` 目录。

#### 特别提醒：关于 `db.json`

Json-Server 只是一个**模拟**数据库，主要用于开发测试。  
如果你要真正上线部署，**强烈建议**把 `db.json` 换成真正的数据库（如 **SQLite** 或 **MySQL**）。

- **为什么？** 因为 Json-Server 在高并发下不稳定，且部署在服务器上时，文件写入权限很容易出问题。
- **简单替代方案**：Python 自带 `sqlite3`，你可以改写 Flask 代码，用 SQLite 存储数据，它也是通过一个文件存数据，但比 json-server 稳定得多。


### 第四步：这一步最重要！(关于 Proxy 代理)

**你不需要修改 `vite.config.ts` 里的 `proxy` 目标地址。**

请保持代理指向 localhost：

```typescript
proxy: {
  '/api': {
    target: 'http://localhost:5000', // 保持 localhost 不变
    // ...
  },
  '/alerts': {
    target: 'http://localhost:3000', // 保持 localhost 不变
    // ...
  }
}
```

**原理**：

1. 室友的手机访问你的电脑 IP (`http://192.168.1.5:5173`)。
2. 手机发送请求给你的电脑（Vite 服务）。
3. **你的电脑（Vite）** 帮手机把请求转发给 **你的电脑（Flask/JsonServer）**。
4. 因为转发发生在你的电脑内部，所以 Vite 找 Flask 依然是用 `localhost`。

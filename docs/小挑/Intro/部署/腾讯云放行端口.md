在腾讯云里，轻量应用服务器放行端口的操作比普通云服务器（CVM）还要简单，它的专属配置区域叫“防火墙”（而不是“安全组”）。请按照以下最直接的步骤操作：

### 🛠️ 腾讯云放行端口步骤：

**第一步：进入服务器详情页**

点击你截图页面中间“我的资源”区块里的 **“轻量应用服务器”** 图标，进入服务器列表。然后点击这台服务器的卡片（或服务器名字），进入这台服务器的管理详情页。

**第二步：找到防火墙设置**

在服务器详情页的顶部，有一排水平的菜单栏（通常包含概览、实例信息、硬盘等），找到并点击 **“防火墙”** 选项卡。

**第三步：添加规则**

在防火墙页面，点击 **“添加规则”** 按钮。在弹出的配置窗口中，按照以下方式填写：

- **应用类型/协议**：选择 **`自定义`** 或直接确认协议为 **`TCP`**。
    
- **端口**：填入你需要开放的端口号。结合咱们前面的部署方案，你需要添加这几个端口（建议分多次添加，一次添加一个）：
    
    - 填入 `5000`（给你的 Python AI 接口用）
        
    - 填入 `3000`（给你的 JSON Server 模拟后端用）
        
    - _（如果你前端部署时没有走默认的 80 端口，而是用了比如 `8080`，也请把 `8080` 放行）_
        
- **策略**：选择 **`允许`**。
    
- **来源/源IP**：保持默认的 `0.0.0.0/0` 即可（表示允许所有人访问）。
    
- **备注**：写个自己能看懂的名字，比如“挑战杯-AI后端5000”、“挑战杯-模拟数据3000”，这样老师以后看到也不会去随便删它。
    

填写完毕后，点击 **“确定”** 保存。腾讯云的规则是**即时生效**的，不需要重启服务器！

### ⚠️ 终极双重检查（极其关键）

想要别人能通过外网成功访问你的系统，必须满足“两扇门”都打开：

1. **外面的大门**：也就是你现在正在设置的**腾讯云防火墙**（放行 3000、5000）。
    
2. **里面的房门**：也就是你**宝塔面板的系统防火墙**。请务必去宝塔面板左侧菜单点击 **“安全”**，在“系统防火墙”里同样把 3000 和 5000 端口“添加放行”。
    

两扇门都打开后，你的大作就可以正式在线上被评委和同学们访问啦！快去试试吧！

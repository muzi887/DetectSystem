### 2. 关于 `src/assets` 里的图片的澄清

你提到：“会在网站上上传 `src/assets` 里面的图片让 py 解析”。这里有一个前后端分离逻辑需要理清：

1. **这些图片属于前端**：`src/assets` 里的图片（如 `apple.jpg`, `wheat.jpg`）是前端打包的一部分。当你运行 `npm run build` 时，它们会被压缩并放进 `dist` 文件夹里，最终部署在 Nginx 上。

3. **后端的处理流程**：后端的 `app.py` 接收到网络传来的图片，把它保存在 `uploads` 文件夹里，然后调用深度学习算法进行识别，最后把结果返回给前端。

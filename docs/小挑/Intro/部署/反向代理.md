太棒了！后端（3000 端口）和 AI 接口（5000 端口）都跑起来了，意味着你项目的“心脏”和“大脑”已经到位。现在只需要完成最后一步：**部署前端网页并建立“桥梁”**，让用户能通过浏览器正式访问你的系统。

以下是完成最后闭环的三个关键步骤：

### 1. 准备并上传前端代码

前端代码在浏览器中运行，我们需要把它们通过 **Nginx**（网页服务器）发布出去。

1. **本地打包**：在你的本地开发环境（如 VS Code）终端执行 `npm run build`。
    
2. **提取产物**：执行完后，你的项目根目录下会多出一个 **`dist`** 文件夹。
    
3. **上传宝塔**：
    
    - 在宝塔面板的 `/www/wwwroot/DetectSystem/` 下新建 **`frontend`** 文件夹。
        
    - 把本地 `dist` 文件夹里的**所有内容**上传到这个 `frontend` 文件夹中。
        

---

### 2. 在宝塔中创建站点并配置“桥梁”

这一步是让你的服务器监听一个端口（比如常用的 80 或 8080），并在用户访问时分发请求。

1. **创建站点**：
    
    - 点击宝塔左侧 **“网站”** -> **“添加站点”**。
        
    - **域名**：填入你的“服务器公网IP:8080”（如果 80 端口被老师占用，我们用 8080）。
        
    - **根目录**：选择刚才的 `/www/wwwroot/DetectSystem/frontend`。
        
    - 点击提交。
        
2. **设置反向代理（核心桥梁）**：
    
    点击该站点的 **“设置”** -> **“配置文件”**，在文件中找到 `server` 块内部，插入以下内容，让前端能找到你的两个后端：
    
    Nginx
    
    ```
    # 转发给 Flask AI 接口 (5000)
    location /api/analysis/ {
        proxy_pass http://127.0.0.1:5000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # 转发给 JSON Server 模拟数据 (3000)
    location /api/ {
        proxy_pass http://127.0.0.1:3000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    ```
    
    _保存配置。_
    

### 1. 添加第一个反向代理（给 JSON Server 模拟数据）

- **代理名称**：填 `mock_api`
    
- **代理目录**：填 **`/api/`** （⚠️ **这个极其重要，别漏了！** 代表只要前端请求路径里有 `/api/`，就按这条规则走）
    
- **目标 URL**：填 `http://127.0.0.1:3000`
    
- **发送域名**：保持默认的 `$host` 或 `$http_host` 不动。
    
- 点击提交保存。
    

### 2. 添加第二个反向代理（给 Flask AI 接口）

- **代理名称**：填 `flask_api`
    
- **代理目录**：填 **`/api/analysis/`** （⚠️ **同样极其重要！** 专门用来拦截上传图片的请求）
    
- **目标 URL**：填 `http://127.0.0.1:5000`
    
- **发送域名**：保持默认的 `$host` 或 `$http_host` 不动。
    
- 点击提交保存。
    

**💡 原理小贴士：** 只要把**“代理目录”**和**“目标URL”**这两把钥匙配对好，Nginx 就能精准地把你前端 Vue 代码发出的 `/api/login` 送给 3000 端口，把 `/api/analysis/image` 送给 5000 端口。

---

### 3. 开放大门（防火墙）

如果你用了 8080 端口来部署网页，必须确保这个端口也是放行的。

1. **腾讯云后台**：进入你之前操作过的“防火墙”页面，添加规则放行 **`8080`** 端口。
    
2. **宝塔安全**：点击宝塔左侧 **“安全”**，同样添加放行 **`8080`** 端口。
    

---

### 🚀 现在，见证奇迹的时刻

打开浏览器，输入：`http://你的服务器IP:8080`。

- **测试登录**：如果能进入首页，说明 8080 网页和 3000 模拟后端通了。
    
- **测试 AI 识别**：在智能分析页面上传一张 `src/assets` 里的测试图，如果返回了病害结果，说明 5000 端口的 Flask 也通了！

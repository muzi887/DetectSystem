你截图里的 **`/home` 返回 404**，说明 Nginx 没把 Vue 路由交给 `index.html`，不一定是文件没传对。覆盖 `dist` 和 `api_mock` 之后，按下面顺序做。

---

## 1. 确认文件路径（最常见问题）

在宝塔 **文件** 里检查：

```
/www/wwwroot/DetectSystem/frontend/dist/index.html   ← 必须存在
/www/wwwroot/DetectSystem/api_mock/server.js
/www/wwwroot/DetectSystem/api_mock/db.json
/www/wwwroot/DetectSystem/api_mock/package.json
```

注意：
- 是 **`frontend/dist`**，不是 `fontend`（历史拼写错误目录可忽略）
- `dist` 里应是 **`index.html` + assets/**，不要把整个 `dist` 文件夹再套一层

---

## 2. 修复 Nginx（解决 `/home` 404）

宝塔 → **网站** → `82.157.234.123:88` → **设置** → **配置文件**

确认 **网站根目录** 指向：
```
/www/wwwroot/DetectSystem/frontend/dist
```

配置里必须有（顺序也重要）：

```nginx
# Flask AI
location /api/analysis/ {
    proxy_pass http://127.0.0.1:5000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

# Mock API
location /api/ {
    rewrite ^/api/(.*)$ /$1 break;
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

# Vue 前端 SPA 路由（缺这个就会 /home 404）
location / {
    try_files $uri $uri/ /index.html;
}
```

保存后终端执行：
```bash
nginx -t && nginx -s reload
```

先访问 **http://82.157.234.123:88/**（根路径），能打开再试 `/home`。

---

## 3. 重启 Mock 后端（加载新坐标 + server.js）

本次除了 `db.json`，还改了 `server.js`（GET 热读数据库），需要重启 Node 项目：

1. 宝塔 → **网站** → **Node 项目** → 找到 `api_mock` / `json-api`
2. 点击 **重启**
3. 若状态不是绿色，在该目录终端执行：
   ```bash
   cd /www/wwwroot/DetectSystem/api_mock
   npm install --registry=https://registry.npmjs.org
   ```
   再在面板里启动项目

服务器上验证：
```bash
curl http://127.0.0.1:3000/monitorPoints
```
应看到 **`lat: 51.78`** 等大兴安岭坐标，而不是 `35, 115`。

---

## 4. 确认前端 dist 是最新构建

地图底图、初始视野等改动在 **前端代码**里，需要先本地构建再上传：

```bash
pnpm build
```

再把 **`dist/` 内所有文件** 覆盖到服务器 `/www/wwwroot/DetectSystem/frontend/dist/`。

若只上传了旧 `dist`，接口坐标对了，地图样式/中心可能仍是旧的。

## 快速判断你当前卡在哪

| 现象 | 原因 | 处理 |
|------|------|------|
| `/home` 直接 404（nginx 字样） | 缺 `try_files` 或根目录不对 | 做 **第 2 步** |
| 首页能开，地图还在山东 | Mock 未重启或 `db.json` 未更新 | 做 **第 3 步** |
| 坐标对了，底图还是路网 | `dist` 不是最新 build | 做 **第 4 步** |
| 登录 502/404 | Node 项目未运行或反代丢失 | 重启 Node + 检查 Nginx 反代 |

---

**最短路径**：先做 **第 2 步 Nginx**（修 `/home` 404）→ **第 3 步重启 Mock** → 本地 **`pnpm build` 后重传 dist** → 浏览器硬刷新测试。

如果你愿意，可以把宝塔里该站点的 Nginx 配置贴出来，我帮你看是否缺 `try_files` 或根目录写错。

## 关键点
- **前端页面路径 (Page Path / Route):** 决定用户在浏览器地址栏看到的路径，例如 `/home` 或 `/login`。这个路径由你的前端路由（Vue Router）管理。
- **后端 API 接口路径 (API Endpoint):** 决定你的前端代码向后端服务器发送请求的地址，例如 `/api/login` 或 `/api/user/info`。这个路径由你的后端服务管理。

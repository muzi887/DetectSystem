# 🌱原理卡：对象展开 `...` 中的默认值和覆盖

> [!NOTE] **定义**：  
> 在对象合并时，**后出现的属性会覆盖先出现的同名属性**。把默认值放在前面，用户传入的值放在后面，就能被用户覆盖；反过来则不会被覆盖。

---

## 关键点

- `...a, ...b` 时，若 `a` 和 `b` 有相同键名，**`b` 覆盖 `a`**。
    
- 想让用户值可选地覆盖默认值：把 **默认放前面**、用户对象放后面。
    
- 如果需要某些字段**不可被覆盖**，把它们放在最后，或在合并后再次赋值：
    
    ```ts
    const safePayload = { ...defaults, ...user, time: Date.now() } // time 无法被用户覆盖
    ```
    
### 另一种写法 — 解构默认值（当你只想默认某些字段时）

```ts
function createAlert({ pointId, level = 'low', message = '', handled = false, time = Date.now() } = {}) {
  // level/handled/time 有默认值
}
```

这在函数参数层面很常见，清晰且类型友好。

---

## 代码示例
（最常见的场景 — 为请求体设默认字段）

```ts
const alertDataFromUser = { pointId: 3, level: 'high', message: '温度异常', handled: true }

// 把默认值写在前面，用户提供的同名字段会覆盖默认
const payload = {
  time: Date.now(),
  handled: false,
  ...alertDataFromUser
}
// 结果：payload.handled === true（用户覆盖了默认 false）
```

## 调试工具使用指南

### 1. **查看 localStorage 中的 token**

**步骤：**

1. 按 `F12` 打开开发者工具
    
2. 点击 **Application** 标签（或者 **Storage**）
    
3. 在左侧找到 **Local Storage** → `http://localhost:5173`
    
4. 查看是否有 `token` 字段
    

**应该看到：**

token: "mock-token-123456"

### 2. **查看 Network 请求和 Authorization 头**

**步骤：**

1. 保持开发者工具打开，切换到 **Network** 标签
    
2. **重要**：勾选 **Preserve log**（保留日志）
    
3. 在登录页面重新登录一次
    
4. 查看网络请求：
    

**查找登录请求：**

- 找 `POST /api/login` 请求
    
- 点击这个请求，查看 **Headers** 标签
    
- 向下滚动到 **Request Headers** 部分
    

**应该看到：**

Authorization: Bearer mock-token-123456


> [!NOTE]
> **刷新页面（Ctrl+R / Cmd+R）**

# 🌱原理卡：Interceptor

> [!NOTE] **定义**：  
> 一种设计模式，它允许你在请求处理的过程中插入自定义逻辑，在特定的"钩子点"拦截并处理数据流。

---

## 关键点
### 1. **AOP（面向切面编程）思想**

拦截器基于AOP理念，将**横切关注点（如日志、认证、错误处理）** 从**业务逻辑**中分离出来
### 2. **生命周期钩子**

拦截器在HTTP请求的生命周期中提供钩子函数：

```
[请求发起] 
    ↓
[请求拦截器] → 可以修改请求配置
    ↓
[发送到服务器]
    ↓
[接收响应]
    ↓
[响应拦截器] → 可以修改响应数据
    ↓
[业务代码处理]

```
### 拦截器的类型
#### 1. **请求拦截器 (Request Interceptors)**

在请求发送到服务器之前执行
#### 2. **响应拦截器 (Response Interceptors)**

在接收到服务器响应后执行

```ts
// 请求拦截器：把 localStorage 中的 token 加到 Authorization header
http.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers = config.headers || {}
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器：简单错误处理
http.interceptors.response.use(
  response => response,
  error => {
    // 这里可以全局处理 401/403 等
    return Promise.reject(error)
  }
)
```
### 拦截器应用
场景1：**API网关模式**
场景2：**监控和日志**
场景3：**数据转换层**
场景4：**缓存拦截器**
### 拦截器的优势
1. **代码复用**
2. **关注点分离**
3. **可维护性**

## 代码示例

```ts
// 伪代码展示拦截器内部机制
class AxiosWithInterceptors {
  constructor() {
    this.requestInterceptors = []
    this.responseInterceptors = []
  }

  // 添加拦截器
  interceptors = {
	  // 请求拦截器
    request: {
      use: (successFn, errorFn) => {
        this.requestInterceptors.push({ successFn, errorFn })
      }
    },
	// 响应拦截器
    response: {
      use: (successFn, errorFn) => {
        this.responseInterceptors.push({ successFn, errorFn })
      }
    }
  }

  // 执行请求
  async request(config) {
    try {
      // 1. 执行所有请求拦截器
      for (const interceptor of this.requestInterceptors) {
        config = await interceptor.successFn(config)
      }
      
      // 2. 发送实际请求
      let response = await this.realRequest(config)
      
      // 3. 执行所有响应拦截器
      for (const interceptor of this.responseInterceptors) {
        response = await interceptor.successFn(response)
      }
      
      return response
    } catch (error) {
      // 错误处理流程
      for (const interceptor of this.responseInterceptors) {
        // 执行错误处理函数
      }
      throw error
    }
  }
}
```

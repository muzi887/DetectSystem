具体解释如下：

- **`EADDRINUSE`**: 是 "Error Address In Use" 的缩写，意思是地址（端口）正在被使用。
- **`address already in use 0.0.0.0:3000`**: 说明你的程序试图在 **3000** 端口启动服务，但你的电脑上已经有另一个程序正在使用这个端口了。

这种情况通常发生在你之前运行过一次 `npm run mock`（或类似开启 3000 端口的项目），但没有正常关闭它，导致它还在后台运行。

---

### 解决方法

你有两种选择：要么**关掉占用端口的程序**（推荐），要么**给当前程序换个端口**。

#### 方法一：找出并关闭占用 3000 端口的程序（Windows 系统）

既然你使用的是 PowerShell (`PS`), 请按以下步骤操作：

1. **查找占用端口的进程 ID (PID)：**  
    在终端中输入以下命令：
    
    ```powershell
    netstat -ano | findstr :3000
    ```
    
    你会看到类似这样的输出：
    
    ```text
    TCP    0.0.0.0:3000           0.0.0.0:0              LISTENING       12345
    ```
    
    每一行的最后那个数字（在这个例子中是 `12345`）就是 **PID**。
    
2. **强制结束该进程：**  
    记下上面的 PID，然后运行以下命令（将 `12345` 替换为你实际看到的数字）：
    
    ```powershell
    taskkill /PID 12345 /F
    ```
    
    _`/F` 表示强制结束。_
    
3. **重新运行你的程序：**  
    再次执行 `npm run mock` 即可。
    

---

#### 方法二：修改代码，换一个端口

如果你不想关闭原来的程序，或者想同时运行两个，你可以修改你的 Mock Server 代码。

1. 打开文件：`src/mock/server.ts`
2. 找到类似 `.listen(3000)` 的代码。
3. 将 `3000` 改为其他数字，例如 `3001` 或 `8080`。
4. 保存文件，重新运行。

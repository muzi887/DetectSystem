### `pnpm add vue-router@4 pinia`

这个命令做了两件事：

1. **添加依赖**：它将 `vue-router`（指定版本为4）和 `pinia` 这两个包**写入**到你的项目的 `package.json` 文件中的 `dependencies` 列表里。
    
2. **安装依赖**：紧接着，它会执行安装操作，将这些包的实际文件下载到 `node_modules` 目录中。

# token引用
这三行代码是 Vue 3 组合式 API 的典型用法，用于管理用户认证状态。让我逐行详细解释：

## 第一行：token 引用

```typescript
const token = ref<string>(localStorage.getItem('token') || '')
```

**逐部分解释：**

- `ref<string>`：创建一个响应式引用，类型为 string
- `localStorage.getItem('token')`：从浏览器的本地存储中获取名为 'token' 的值
- `|| ''`：逻辑或操作符，如果 localStorage 中没有 token 就返回空字符串 ''
- **整体作用**：创建一个响应式的 token 变量，初始值从 localStorage 中读取，如果没有则为空字符串

**示例过程：**
```typescript
// 假设 localStorage 中有 token
localStorage.setItem('token', 'abc123')
const token = ref<string>('abc123') // token.value = 'abc123'

// 假设 localStorage 中没有 token
const token = ref<string>('') // token.value = ''
```

## 第二行：用户信息引用

```typescript
const userInfo = ref<{ name?: string; phone?: string }>({})
```

**逐部分解释：**

- `ref<{ name?: string; phone?: string }>`：创建响应式引用，类型是一个对象
- `<{ name?: string; phone?: string }>`：TypeScript 类型定义，表示对象可以有：
  - `name`：可选字符串属性
  - `phone`：可选字符串属性
- `({})`：初始值为空对象
- **整体作用**：创建一个响应式的用户信息对象，初始为空，后续可以添加 name 和 phone 属性

**使用示例：**
```typescript
// 初始状态
userInfo.value = {} // 空对象

// 设置用户信息
userInfo.value = { name: '张三', phone: '13800138000' }

// 或者逐个设置
userInfo.value.name = '李四'
userInfo.value.phone = '13900139000'
```

## 第三行：计算登录状态

```typescript
const isLogged = computed(() => !!token.value)
```

**逐部分解释：**

- `computed(() => ...)`：创建计算属性，当依赖的响应式数据变化时会自动重新计算
- `!!token.value`：双重逻辑非运算，将值转换为布尔值
  - `token.value`：获取 token 的实际值
  - `!token.value`：第一次取反，将值转为布尔值并取反
  - `!!token.value`：第二次取反，得到正确的布尔值
- **整体作用**：创建一个计算属性，根据 token 是否存在来自动判断用户是否登录

**转换过程示例：**
```typescript
// token.value = 'abc123'
!!'abc123' → true

// token.value = ''
!!'' → false

// token.value = null
!!null → false

// token.value = undefined  
!!undefined → false
```

## 完整的使用场景

```typescript
import { ref, computed } from 'vue'

// 认证状态管理
const token = ref<string>(localStorage.getItem('token') || '')
const userInfo = ref<{ name?: string; phone?: string }>({})
const isLogged = computed(() => !!token.value)

// 登录函数
const login = (userToken: string, userData: { name: string; phone: string }) => {
  token.value = userToken
  userInfo.value = userData
  localStorage.setItem('token', userToken) // 持久化到本地存储
}

// 退出函数
const logout = () => {
  token.value = ''
  userInfo.value = {}
  localStorage.removeItem('token') // 清除本地存储
}

// 在模板中使用
/*
<template>
  <div v-if="isLogged">
    欢迎，{{ userInfo.name }}！
    <button @click="logout">退出</button>
  </div>
  <div v-else>
    <button @click="login('new-token', { name: '王五', phone: '13600136000' })">
      登录
    </button>
  </div>
</template>
*/
```

## 响应式效果演示

```typescript
// 初始状态
console.log(token.value) // '' (空字符串)
console.log(isLogged.value) // false

// 用户登录后
token.value = 'user-jwt-token'
console.log(isLogged.value) // true (自动更新)

// 用户退出后  
token.value = ''
console.log(isLogged.value) // false (自动更新)
```

**总结：**
- `token`：管理认证令牌的响应式状态，与 localStorage 同步
- `userInfo`：管理用户信息的响应式对象
- `isLogged`：自动计算的登录状态，依赖于 token 的存在性

这种模式在 Vue 3 应用中非常常见，用于构建响应式的状态管理系统。

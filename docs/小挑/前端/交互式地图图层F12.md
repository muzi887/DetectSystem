## 整个地图 (The "Whole")

```html
<main class="ant-layout-content" ...>
  <div style="height: 70vh; ...">
    <div class="leaflet-container ..." ...>
      <!-- ... 大量复杂的内部代码 ... -->
      <div class="leaflet-pane leaflet-popup-pane">
         <!-- 你找到的第一个代码块就住在这里面！ -->
      </div>
      <!-- ... 更多代码 ... -->
    </div>
  </div>
</main>
```

这是**整个地图组件的完整实时HTML**。

---

### 详细解读 

一个交互式地图非常复杂，它是由很多**图层（Layers/Panes）**叠加在一起组成的。让我们来解构一下这些“零件”：

1. **`<main class="ant-layout-content"...>`**
    
    - 这是你的 Ant Design Vue 布局组件，是包裹地图的**最外层容器**。
2. **`<div class="leaflet-container ...">`**
    
    - 这是 Leaflet 地图的**根容器**，所有地图相关的东西都在它里面。相当于汽车的“底盘和车架”。
3. **`<div class="leaflet-tile-pane">`**
    
    - 这是**瓦片图层**。你看到的地图背景（街道、陆地、海洋）就是由很多张 `256x256` 像素的正方形图片（瓦片，`<img ...>`）拼接而成的。当地图缩放或拖动时，Leaflet 会自动加载新的图片。你看到的那些大量的 `<img>` 标签就是这些地图瓦片。
4. **`<div class="leaflet-shadow-pane">`**
    
    - 这是**阴影图层**。专门用来放地图标记（Marker）下面的那个淡淡的阴影效果，让标记看起来有立体感。
5. **`<div class="leaflet-marker-pane">`**
    
    - 这是**标记图层**。所有蓝色的地图大头针图标（`<img ... class="leaflet-marker-icon" ...>`）都放在这个图层。
6. **`<div class="leaflet-popup-pane">`**
    
    - 这是**弹窗图层**。**你找到的第一段代码就住在这里！** 当你点击一个标记时，Leaflet 会在这个图层里动态创建弹窗的HTML。这个图层通常在所有图层的最上面，以确保弹窗不会被其他东西遮住。
	- `popupContent` 指向`<div class="leaflet-popup-content-wrapper">...</div>`。
	- `btn` 指向 `<button id="trigger-2">...</button>`。
	- `point` 变量里存着 `{ id: 2, name: '点B', temp: 33, ... }` 完整的数据对象。

```html
<div class="leaflet-pane leaflet-popup-pane">
	<div class="leaflet-popup  leaflet-zoom-animated" style="opacity: 1; transform: translate3d(344px, 240px, 0px); bottom: -7px; left: -71px;">
		<div class="leaflet-popup-content-wrapper" style="background-color: rgb(193, 230, 198);">
			<div class="leaflet-popup-content" style="width: 95px;">
		          <div>
		            <strong>点B</strong><br>
		            温度: 33 °C<br>
		            土壤湿度: 12%<br>
		            状态: warning<br>
		            <br>
		            <button id="trigger-2" data-id="2" style="background-color: rgb(193, 230, 198);">模拟触发预警</button>
		          </div>
	        </div>
        </div>
		<div class="leaflet-popup-tip-container">
			<div class="leaflet-popup-tip" style="background-color: rgb(193, 230, 198);">
			</div>
		</div>
		<a class="leaflet-popup-close-button" role="button" aria-label="Close popup" href="#close">
			<span aria-hidden="true">×</span>
		</a>
	</div>
</div>
```


7. **`<div class="leaflet-control-container">`**
    
    - 这是**控件容器**。地图左上角的放大/缩小按钮（`+` / `-`）和右下角的版权信息（"Leaflet | © OpenStreetMap"）都放在这里。

### 弹窗Popup

```html
<div class="leaflet-popup-content-wrapper" ...>
  <div class="leaflet-popup-content" ...>
    <div>
      <strong>点B</strong><br>
      ...
      <button id="trigger-2" data-id="2" ...>模拟触发预警</button>
    </div>
  </div>
</div>
```

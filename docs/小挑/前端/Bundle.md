# 🌱原理卡：打包

> [!NOTE] **定义**：  
> 通过打包工具（如 Webpack、Vite）将你项目中的许多零散源代码文件（模块）合并、转换、优化后生成的少数几个（通常为1个）供浏览器直接运行的文件。

> npm run build
> 生成打包文件

---

## 关键点
### **打包过程的作用：**

- **依赖解析**：理清模块间的依赖关系
    
- **资源合并**：将多个文件合并为少数几个文件
    
- **语法转换**：将 TS、JSX、Vue SFC 转换为普通 JavaScript
    
- **代码优化**：删除未使用代码、压缩、混淆
    
- **资源处理**：处理 CSS、图片、字体等

### Bundle 优化策略
#### 1. **Tree Shaking**
删除未使用的代码
#### 2. **压缩和混淆**

#### 3. **资源优化**

- 图片压缩
    
- CSS 压缩
    
- Gzip/Brotli 压缩
### 打包工具
1. Webpack
2. Vite（更现代的选择）

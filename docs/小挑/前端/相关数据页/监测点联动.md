## 二、无人机 Tab：日期/地块 + 叠加 + 历史对比

### 2.1 UI 结构

在 `RelatedData.vue` 的 drone 区域增加：

| 控件 | 作用 |
|------|------|
| 地块下拉 | 过滤 `ndviLayers` |
| 日期下拉 | 选当前期影像 |
| 「对比历史」开关 | 再选一个历史日期 |
| 透明度滑块 | 双图层叠加对比 |
| Leaflet 地图 | 底图 + NDVI 叠加层 |

### 2.2 地图叠加（复用现有 Leaflet 经验）

```typescript
import * as L from 'leaflet'

let map: L.Map | null = null
let baseLayer: L.TileLayer | null = null
let ndviOverlay: L.ImageOverlay | null = null
let compareOverlay: L.ImageOverlay | null = null

function initDroneMap(container: HTMLElement, bounds: L.LatLngBoundsExpression) {
  baseLayer = L.tileLayer(
    'https://webst0{s}.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z}',
    { subdomains: ['1', '2', '3', '4'], maxZoom: 18 }
  )

  map = L.map(container, { layers: [baseLayer] }).fitBounds(bounds)
}

function setNdviLayer(layer: NdviLayer, opacity = 1) {
  if (!map) return
  ndviOverlay?.remove()
  ndviOverlay = L.imageOverlay(layer.imageUrl, layer.bounds, { opacity }).addTo(map)
  map.fitBounds(layer.bounds)
}

function setCompareLayer(layer: NdviLayer, opacity = 0.5) {
  compareOverlay?.remove()
  compareOverlay = L.imageOverlay(layer.imageUrl, layer.bounds, { opacity }).addTo(map)
}
```

**历史对比**两种常见做法：

1. **透明度叠加**（实现简单）：当前期 opacity=1，历史期 opacity=0.4–0.6，拖动滑块看变化。  
2. **分屏对比**（效果更好）：用 [leaflet-side-by-side](https://github.com/digidem/leaflet-side-by-side) 插件，左右拖动分割线。

### 2.3 Pinia Store 示例

```typescript
// src/stores/remoteSensing.ts
export const useRemoteSensingStore = defineStore('remoteSensing', () => {
  const fields = ref<Field[]>([])
  const ndviLayers = ref<NdviLayer[]>([])
  const selectedFieldId = ref('A3')
  const selectedDate = ref('')
  const compareDate = ref<string | null>(null)

  const layersForField = computed(() =>
    ndviLayers.value.filter(l => l.fieldId === selectedFieldId.value)
  )

  const currentLayer = computed(() =>
    layersForField.value.find(l => l.date === selectedDate.value)
  )

  const compareLayer = computed(() =>
    compareDate.value
      ? layersForField.value.find(l => l.date === compareDate.value)
      : null
  )

  async function fetchNdviLayers() {
    const res = await http.get('/ndviLayers')
    ndviLayers.value = res.data
    selectedDate.value = res.data[0]?.date ?? ''
  }

  return { fields, ndviLayers, selectedFieldId, selectedDate, compareDate, currentLayer, compareLayer, fetchNdviLayers }
})
```

### 2.4 生产环境怎么换真实 NDVI

| 阶段 | 数据源 | 前端用法 |
|------|--------|----------|
| 演示 | 静态 WebP + bounds | `L.imageOverlay` |
| 中期 | 预切好的 PNG/WebP 瓦片 | `L.tileLayer(url + '/{z}/{x}/{y}.png')` |
| 生产 | 无人机正射 GeoTIFF/COG | TiTiler / GeoServer 出 WMS 或 XYZ 瓦片 |

无人机作业流程一般是：多光谱原始图 → 正射校正 → 算 NDVI → 导出 GeoTIFF → 切片服务。前端只消费「图层元数据 + 瓦片 URL」，不自己做遥感计算。

## 三、GIS Tab：墒情栅格 + 点击查值 + 监测点联动

### 3.1 同一套地图，多两层信息

GIS Tab 建议在同一 Leaflet 上叠：

1. **墒情栅格层**（`L.imageOverlay` 或瓦片）  
2. **监测点 Marker 层**（直接复用 `MapVisualization.vue` 的 marker 逻辑）  
3. **点击查询**（地图 `click` 事件）

```typescript
function bindMoistureQuery(map: L.Map) {
  map.on('click', async (e) => {
    const { lat, lng } = e.latlng
    const res = await http.get('/moisture/value', { params: { lat, lng } })
    // res.data: { moisture: 28.5, source: 'raster' | 'idw', nearestPointId: 2 }
    L.popup()
      .setLatLng(e.latlng)
      .setContent(`墒情: ${res.data.moisture}%<br/>来源: ${res.data.source}`)
      .openOn(map)
  })
}
```

### 3.2 Mock 后端：点击查值（三种精度递进）

**方案 A — 最近监测点（最快落地）**

```typescript
// src/mock/server.ts 自定义路由
server.get('/moisture/value', (req, res) => {
  const lat = Number(req.query.lat)
  const lng = Number(req.query.lng)
  const db = JSON.parse(fs.readFileSync(dbPath, 'utf-8'))
  const points = db.monitorPoints || []

  let nearest = points[0]
  let minDist = Infinity
  for (const p of points) {
    const d = (p.lat - lat) ** 2 + (p.lng - lng) ** 2
    if (d < minDist) { minDist = d; nearest = p }
  }

  res.jsonp({
    moisture: nearest.soilMoisture,
    source: 'nearest-point',
    nearestPointId: nearest.id,
    pointName: nearest.name
  })
})
```

**方案 B — IDW 插值（更像 GIS）**

用监测点 `soilMoisture` 做反距离加权，点击坐标返回插值结果；仍可在 Mock 里用纯 JS 算，不必 PostGIS。

**方案 C — 真实栅格采样（生产）**

后端存 GeoTIFF，用 Python `rasterio.sample((lng, lat))` 读像素值；或 TiTiler 的 `/cog/point/{lng},{lat}` 接口。

## 六、生产环境后端要点（简要）

```text
无人机 NDVI:
  原始多光谱 → ODM/Pix4D 正射 → NDVI GeoTIFF → TiTiler/GeoServer → 前端 tileLayer

GIS 墒情:
  方案1: Sentinel-2 反演 → 墒情栅格 GeoTIFF
  方案2: monitorPoints 历史序列 → PostGIS/Scipy IDW → 动态 GeoJSON 等值面
  方案3: 两者融合（栅格为主，监测点校准）
```


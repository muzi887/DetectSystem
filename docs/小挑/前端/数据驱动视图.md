## 代码示例

**不是在用代码直接操作DOM（比如 `document.getElementById('icon').className = '...';`），而是在改变一个被Vue监视的数据 (`loading`)。Vue 检测到数据变化后，会自动、高效地根据 `v-if` / `v-else` 等指令去更新界面，将界面渲染成与新数据匹配的样子。**

这就是 Vue “数据驱动视图”的核心思想

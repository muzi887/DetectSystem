：**`Sources` (源代码)** 和 **`Console` (控制台)**。

这才是前端开发的正确调试方式：

1. **在 `Sources` 面板设置断点：**
    
    - 在开发者工具中，切换到 **"Sources"** 标签页。
    - 在左侧的文件列表中，通过 `Ctrl+P` (或 `Cmd+P`) 搜索并打开 `Monitor.vue` 文件。
    - 找到 `map.on('popupopen', ...)` 这段代码。
    - 在你想要观察的那一行的**行号**上点击一下，比如在 `const point = ...` 这一行。这会设置一个**断点** (一个蓝色的标记)。
2. **触发代码执行：**
    
    - 回到你的网页，点击一个地图标记以打开弹窗。
3. **观察奇迹发生：**
    
    - 你的网页会“冻结”，开发者工具会自动跳到你设置断点的那一行，并高亮显示它。这意味着代码执行到这里**暂停**了！
4. **检查变量：**
    
    - 现在，你可以把鼠标悬停在 `popupContent`、`btn`、`pointId` 这些变量名上，工具会立刻显示出它们**当前的值**！
    - 你也可以在右侧的 "Scope" 窗格里看到所有当前作用域内的变量和它们的值。
    - 你还可以在下面的 **"Console"** 面板里输入变量名（比如 `point`），然后按回车，来打印出它的值。

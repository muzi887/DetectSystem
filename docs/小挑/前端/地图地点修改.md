## 本次修改总结

围绕 **灾害实时监测** 页面的地图功能，共涉及 4 个文件，主要做了三类改动。

---

### 一、监测点坐标（`src/mock/db.json`、`deploy/api_mock/db.json`）

6 个监测点从日本/山东一带，最终统一迁到 **黑龙江大兴安岭无人自然区域**，并与地形标签对应：

| 监测点 | 位置说明 | 坐标 |
|--------|----------|------|
| A - 平原 | 新林北部开阔苔原草甸 | `51.78, 124.92` |
| B - 丘陵 | 南瓮河保护区低山丘陵 | `51.52, 125.28` |
| C - 山谷 | 呼中深山沟谷 | `51.68, 123.15` |
| D - 河畔 | 南瓮河远程湿河畔（原「海岸」） | `51.28, 125.58` |
| E - 森林 | 呼中国家级自然保护区原始林海 | `51.58, 122.88` |
| F - 山顶 | 大白山主峰（1528 m） | `51.847, 123.048` |

所有点位均避开城镇，落在自然保护区、原始森林、河谷等地。

---

### 二、地图组件（`src/views/user/MapVisualization.vue`）

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 初始视野 | 日本静冈 `[35.05, 139.05]` zoom 9 | 大兴安岭 `[51.55, 124.0]` zoom 7 |
| 底图类型 | CARTO 暗色 → 高德标准路网（英文/中文） | **高德卫星影像**（`style=6`） |
| 地图风格 | 人文地图（道路、城镇、行政区划） | **自然地理**（地形、植被、河流） |
| CSS 滤镜 | 暗色路网滤镜 | 已移除，保留卫星自然色彩 |

---

### 三、Mock 服务热更新（`src/mock/server.ts`、`deploy/api_mock/server.js`）

**问题**：`json-server` 启动后将 `db.json` 缓存在内存，修改文件后接口仍返回旧坐标（山东），页面看起来没有变化。

**修复**：GET 请求前自动重新读取 `db.json`，修改坐标后无需重启 mock 服务即可生效。

---

### 涉及文件

```
src/views/user/MapVisualization.vue   # 地图底图、初始视野
src/mock/db.json                      # 监测点坐标（开发环境数据源）
src/mock/server.ts                    # Mock 热更新
deploy/api_mock/db.json               # 部署环境同步数据
deploy/api_mock/server.js             # 部署 Mock 同步逻辑
```

---

### 使用说明

本地开发需同时运行：

- `npm run dev` — 前端
- `npm run mock` — 接口服务（端口 3000）

修改坐标后，在地图页点击 **「刷新数据」** 或硬刷新浏览器即可。

# 🌱原理卡：

> [!NOTE] **定义**：  
> 一个开源的、轻量级的 JavaScript 库，用于在网页上创建交互式地图。

---

## 关键点
提供了创建地图所需的所有基本构件：

- **地图容器**：在网页上定义一个显示地图的区域。
    
- **图层**：
    
    - **底图图层**：用于显示地图的“背景”，通常是栅格图块，例如街道图、卫星图、地形图。
        
    - **叠加图层**：显示在底图之上的内容，例如：
        
        - **标记**：用于标示特定位置的点。
            
        - **弹出窗口**：点击标记或其他要素时显示更多信息的对话框。
            
        - **矢量图形**：如折线、多边形、圆形等，用于绘制区域、路线等。
            
        - **GeoJSON**：直接加载和显示地理JSON数据，这是数据可视化的核心功能

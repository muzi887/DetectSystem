# 第一章 系统简介

## 1.1 系统做什么

本系统（简称「青禾智匠」）用于**作物灾害相关的监测、预警与辅助决策**，在一张 Web 页面里完成以下工作：

- 在地图上查看监测点位置与状态（状态机中文显示：正常 / 预警 / 严重 / 离线 / 维护中 / 未知）；
- 查看传感器、无人机、气象、GIS 等分类农情数据；
- 上传作物图片做病害/灾害分类，返回识别结果并写入预警列表；
- 新建、处理、删除预警记录；
- 针对待处理预警查看监测点信息与系统给出的处置建议。

系统面向作物灾害监测、农情数据展示和预警处置等业务场景，可用于农业合作社日常管理、农技推广辅助研判、教学培训及创新创业项目展示。

## 1.2 功能模块一览

| 导航菜单 | 路由 | 主要功能 |
|----------|------|----------|
| 首页 | /home | 监测点数量、待处理预警数、系统状态汇总、最新预警列表、快捷入口 |
| 相关数据 | /related-data | 四类 Tab；无人机/GIS 为 Leaflet 地图；NDVI 历史对比；GIS 点击查墒情与监测点联动；AI 文案、生成简报 |
| 灾害实时监测 | /map | Leaflet 地图、监测点聚类、监测点详情、手动触发/标记解决 |
| 智能分析 | /analysis | 上传图片、选择作物与分类、调用分析接口并生成预警 |
| 灾害预警 | /warnings | 预警列表、新建/标记状态/删除 |
| 智慧决策 | /decision | 待处理预警列表、小地图定位、监测数据与建议文案 |

## 1.3 统一领域术语

为保证说明书表述统一，本文采用以下领域术语：

| 术语 | 含义 |
|------|------|
| 监测点 | 地图上的农田或果园监测位置，包含经纬度、温度、土壤湿度和状态信息 |
| 农情数据 | 传感器、无人机遥感、气象、GIS 等用于判断作物长势和灾害风险的数据 |
| 墒情 | 土壤湿度 / 土壤含水量，单位一般为 %；GIS 模块中热力图与查值结果均表示此含义 |
| NDVI | 归一化植被指数，用于反映作物长势；无人机 Tab 以热力图形式展示 |
| 预警记录 | 系统或用户创建的一条风险提示记录，通常关联到某个监测点 |
| 待处理预警 | 尚未完成处置的预警记录，需要继续跟踪或现场核查 |
| 已处理预警 | 已完成处置或确认闭环的预警记录 |
| 智能分析 | 上传作物图片后生成识别结果、风险等级和农技建议的过程 |
| 处置建议 | 系统根据预警级别、监测值和规则模板生成的辅助处理建议 |

下文提到具体菜单时保留界面原名，例如「相关数据」「灾害实时监测」「灾害预警」。

### 4.3.3 无人机遥感（NDVI 地图）

#### 界面组成

- 地图左上角：**地块**、**影像日期**下拉；可选 **对比历史** 及相关控件。
- 地图主区域：NDVI 植被指数热力图叠加在卫星底图上。
- 左下角：图层标题、数据来源、当前影像日期（开启对比时显示对比日期与历史透明度）。
- 右下角：NDVI 五级色标（低→高）。
- 页面底部：**AI 智能分析** 文案（开启历史对比时会描述两期变化）。

#### 地块与影像日期

| 地块 | 可选影像期数 | 说明 |
|------|--------------|------|
| 1号地块（河间市） | 2 期（如 2026-05-20、2026-05-01） | 支持历史对比 |
| 2号地块（雄县） | 1 期 | 对比历史开关不可用 |
| 3号地块（栾城区） | 1 期 | 对比历史开关不可用 |

切换地块后，地图视野自动缩放到该地块范围；影像日期下拉仅显示**当前地块**可用日期。

#### 历史影像对比（仅多期地块可用）

适用于河间等拥有 **2 期及以上** NDVI 影像的地块：

1. 选择地块与当前「影像日期」。
2. 打开 **对比历史** 开关。
3. 在 **对比日期** 中选择另一期（列表中不含当前影像日期）。
4. 拖动 **历史透明度** 滑块（约 20%～80%），观察两期 NDVI 叠图变化。
5. 关闭对比开关后恢复单层显示。

仅 1 期影像的地块，对比开关为灰色不可用，鼠标悬停提示「当前地块仅一期影像」。

### 4.3.4 GIS 数据（墒情地图）

GIS Tab 的主画面是一片贴在**栾城附近**的墒情热力图（演示数据），上面叠有 **3 个监测站**圆点。左下角有墒情说明、影像日期和操作提示；右下角是墒情（%）色标，从干旱到饱和由暖色过渡到冷色。墒情栅格只覆盖这一片演示区域，河间、雄县等地在图上以**监测站圆点**表示传感器位置，并不是每个县都有一张墒情图。

点监测站圆点可查看该站温度、土壤湿度和状态；有待处理预警时会显示红色提示。**此处与「灾害实时监测」不同：弹窗里没有「手动触发」「标记解决」按钮**，只能看，不能在这里直接处置。

查墒情可以这样试：先切到 GIS Tab，鼠标会变成十字形。在**雄县附近**轻轻点一下地图（不要按住拖很远再松手），点击处会弹出「墒情查询」，大约显示 **12%**，并标明参考站为「监测站 · 雄县」；地图会同时拉开视野，打开该站的详情弹窗，左下角也会出现「最近查值：12% · 监测站 · 雄县」，底部 **AI 智能分析** 会改成与这次查值相关的说法。点到**栾城附近**时，数值会接近 **65%**；**河间附近**大约 **30%**。查值弹窗和监测站弹窗可以同时留着，再点别处会更新结果；离开 GIS Tab 再回来，「最近查值」一行会清空。

说明：这是演示用法——系统按点击位置找**最近的监测站**，用该站土壤湿度当作这一带的墒情示数，用来对照「热力图上看趋势、站点上看实测」，不是专业栅格反演或空间插值产品。

### 4.3.5 AI 智能分析文案

页面底部 **AI 智能分析** 会跟着当前 Tab 和用户操作换内容，不是一整段固定话术。

在**传感器** Tab，文案主要看最近有没有预警、最新一条未处理预警说了什么。在**无人机** Tab，没开「对比历史」时，多写当前地块长势和施肥建议；河间等地块打开两期对比后，会改成描述两期 NDVI 影像的差别。在 **GIS** Tab，还没点地图时，一般是栾城一带偏湿、河间—雄县段偏干这类区域概况；点过地图查墒情之后，会带上刚才的墒情数值、参考监测站，以及是否偏干、偏湿、要不要多留意灌溉或排水，并提示已定位到对应传感器。

### 4.3.6 生成简报

1. 选定某一 Tab 后，点击右上角「生成 XXX 简报」。
2. 弹窗显示进度条与「正在聚合分析最近 30 天的 XXX…」。
3. 进度完成后提示可下载；点击「确定」后提示已下载 PDF。

简报功能用于展示系统对当前农情数据的汇总能力，具体导出格式以实际系统实现为准。

## 4.4 灾害实时监测

**进入方式：** 导航栏 →「灾害实时监测」。

### 4.4.1 查看地图与监测点

1. 页面加载后，地图显示系统中的监测点；近距显示单点，远距自动聚类。
2. 点击「缩放至全部」：视野包含所有点。
3. 点击「刷新数据」：重新请求监测点与预警数据。

监测点颜色与中文状态见 3.1.4 节。

![[attachments/4.2.1.png]]

### 4.4.2 监测点弹窗操作

1. 点击地图上的标记，弹出详情：名称、温度、土壤湿度、**状态（中文）**。
2. 若存在待处理预警，弹窗显示红色提示文案。
3. **手动触发：** 为该监测点创建一条中级别人工预警。
4. **标记解决：** 将该监测点关联的待处理预警标为已处理。

![[attachments/4.2.2.png]]

### 4.4.3 状态判断口径

监测点状态统一使用 3.1.4 节中的状态机：正常、预警、严重、离线、维护中、未知。监测点状态表示监测对象当前状况，预警记录表示系统或用户创建的风险处置记录，两者在页面中联动展示。

## 4.5 智能分析

**进入方式：** 导航栏 →「智能分析」。

### 4.5.1 上传与分析

1. 点击上传区，选择 JPG / PNG / WEBP 图片（建议 ≤ 2MB）。
2. 下拉选择作物：桃、苹果、小麦、水稻。
3. （可选）填写补充说明。
4. 右侧选择分析类型：灾害识别、病虫害识别、气候灾害识别、其他。
5. 点击「确定」或「识别」。

系统提交图片后生成识别结果、置信度、风险等级和农技建议。识别完成后，用户可在页面下方查看结果卡片；存在风险的结果可归档到预警列表。

成功提示：「分析完成！请查看下方结果卡片。」可在「灾害预警」页查看新记录。

**窄屏布局：** 上传区与结果区由左右双栏改为**上下排列**。

![[attachments/4.3.1.png]]

### 4.5.2 分析类型说明

| 按钮 | 适用场景（说明性） |
|------|-------------------|
| 灾害识别 | 一般性灾害/长势异常 |
| 病虫害识别 | 病斑、虫害相关 |
| 气候灾害识别 | 冻害、涝渍等 |
| 其他 | 以上未覆盖情况 |

识别结果会带置信度文案写入预警；非「健康」类结果可归档为较高预警级别，供后续处置和决策分析使用。

## 4.7 智慧决策

**进入方式：** 导航栏 →「智慧决策」。

本模块用于对待处理预警进行辅助分析，展示关联监测点位置、监测数据和处置建议。

### 4.7.1 选择预警

1. 左侧为待处理预警列表；点击一条后高亮。

**窄屏布局（≤992px）：** 预警列表在上、决策详情在下；监测数据卡片在手机上为单列。

### 4.7.2 查看建议

选择预警后：

- **实时监测数据：** 显示该点温度、土壤湿度、监测点状态等。
- **处置建议：** 根据级别与监测值生成多条文字建议。
- **导出方案：** 点击右上角按钮导出当前建议（以实现为准）。

# 第五章 使用注意事项

## 5.1 账号与登录

1. 用户应使用系统分配的手机号、验证码和角色登录。
2. 公共电脑使用完毕后，应通过右上角用户菜单退出登录。
3. 如登录失败，应确认手机号、验证码、角色和备用密码是否填写正确。
4. 不同角色可访问的页面范围不同，实际权限以系统配置为准。

## 5.2 数据查看

1. 首页统计、地图监测、预警列表和智慧决策页面之间存在数据联动关系。
2. 若页面数据未及时更新，可点击页面提供的「刷新数据」按钮，或重新进入当前页面查看。
3. 一个监测点可以关联多条预警记录，因此预警数量可能大于监测点数量。
4. 遥感热力图、气象卡片和趋势图用于辅助查看农情变化，用户应结合现场情况综合判断。
5. GIS「点击查墒情」为演示联动，数值取自最近监测站传感器，非专业空间插值产品。
6. 无人机「历史对比」仅在有多期影像的地块可用；单期地块开关不可用属正常设计。

## 5.3 图片分析

1. 建议上传 JPG、PNG 或 WEBP 格式图片。
2. 上传图片应尽量清晰，避免主体过小、严重模糊或光照过暗。
3. 智能分析结果用于辅助识别和风险提示，不应直接替代实地农情判断。
4. 分析完成后，用户可根据结果进入「灾害预警」页查看关联预警记录。

## 5.4 预警处置

1. 新建预警时，应选择正确的监测点和预警级别。
2. 预警处置完成后，应及时点击「标记解决」，保证首页统计和智慧决策列表同步更新。
3. 删除预警记录后不可在页面中直接恢复，操作前应确认该记录不再需要。
4. 智慧决策页面提供的处置建议为辅助参考，实际生产处置仍需结合当地农技规范和现场复核结果。

## 5.5 运行环境

1. 推荐使用 Chrome 或 Edge 最新版浏览器访问系统。
2. 系统支持 PC、平板和手机浏览器访问；涉及地图、图表和表格操作时，建议使用 PC 或平板获得更完整的显示效果。
3. 如系统地址无法访问，应联系维护人员检查服务器、网络和后端服务状态。

**当前模型口径（2026-08-22）**：

- **产品目标**：小麦 / 玉米 / 番茄 / 水稻，**23 类**中文标签（`ml-bjj/serving/crop_filter.py` 的 `CANONICAL_CLASSES`，与 `ml-bjj/data/bjj_cls/classes.txt` 一致）。
- **已训权重**：`pest-cls-meta.json` 仍是 2026-07-08 的 **8 类、验证准确率 98.99%**。不要把 98.99% 写成「23 类线上指标」。
- **Serving 门禁**：`app.py` 加载后若 `len(classes) != 23` 会 `SystemExit`。补图、重切分、`train_cls.py` 出 23 类权重并改写 meta 之前，智能分析进程起不来。
- **作物掩码**：用户选的 `cropType`（含 `rice`）会划掉无关病名后再取第一名；小麦图不会再把稻瘟病排第一。
- **防治**：`treatments.json` 23 类已接线；低置信度走 `needs_review`。
- **训练环境**：CPU 可训；**训练期间勿休眠**。

## 三、阶段 A：模型接入网站（已完成 ✅ · 2026-07-09）

> **实施方案**：[阶段A-网站接入方案.md](../网站/方案/阶段A-网站接入方案.md) · **启动方式**：[项目启动说明.md](../网站/项目启动说明.md)  
> **之后加厚**：[作物掩码与推理接入.md](../模型/方案/作物掩码与推理接入.md)、[`新模型训后-后端丰富说明.md`](../网站/方案/新模型训后-后端丰富说明.md)（规格；P1–P3 代码已落地，**权重门禁仍要求 23 类**）

### 3.1 目标（当时）

用户在「智能分析」页上传叶片照片 → 后端加载 `pest-cls-best.pt` 推理 → 返回中文病名与置信度 → 写入预警中心。

### 3.2 现在实际架构

```text
DataAnalysis.vue
    POST /api/analysis/image（cropType: wheat / corn / tomato / rice）
         ↓（Vite 代理）
    http://127.0.0.1:5000/api/analysis/image
         ↓
    ml-bjj/serving/app.py
         ↓
    inference.py：softmax → 作物掩码 → topk / needs_review
         ↓
    pest-cls-best.pt（门禁：必须 23 类；当前磁盘仍是 8 类）
```

### 3.3 任务清单（阶段 A 原清单 · 已勾选）

| 序号 | 任务 | 状态 | 产出 |
|------|------|------|------|
| A1 | `inference.py` + `app.py` | ✅ | 与 `predict.py` 同骨干 |
| A2 | 启动 `:5000` | ✅ | 8 类时期 curl 已通过 |
| A3 | Vite 代理 `/api/analysis` → 5000 | ✅ | |
| A4 | 联调 `DataAnalysis.vue` | ✅ | 现含 rice |
| A5 | 低置信度提示 | ✅ | `needs_review` / confidence &lt; 70% |
| A6 | 启动说明 | ✅ | `网站/项目启动说明.md` |

A+ 加厚（作物掩码、防治 23 类、batch、waitress、病名×环境）见 `docs/互联网+/网站/训后实施/P1-Task*`、`P2-Task*`、`P3-Task*`。

### 3.4 推荐流程（操作顺序）

```powershell
# 终端 1：Mock 后端（登录、预警、规则链 60s）
pnpm run mock

# 终端 2：AI 推理服务（须 23 类权重，否则进程退出）
cd D:\code2\software\vue\program\DetectSystem
ml-bjj\.venv\Scripts\Activate.ps1
python ml-bjj\serving\app.py

# 终端 3：前端
pnpm dev
```

23 类权重到位前：登录 / 地图 / 预警 / 相关数据仍可用；智能分析会因 5000 起不来而失败。

### 3.5 接口约定（当前）

请求：`POST /api/analysis/image`，`multipart/form-data`

| 字段 | 说明 |
|------|------|
| file | 图片文件 |
| cropType | `wheat` / `corn` / `tomato` / `rice`；**会按作物掩码过滤** |
| category | pest / disaster / climate / other |

响应在 `result` / `confidence` / `level` 之外，还有 `topk`、`needs_review`、`model_version`、防治片段、可选 `env_context`。细节以 serving 代码与训后 Task 为准。

### 3.6 本阶段完成标志（A 已达成；A+ 代码已达成）

- 网站上传验证集图，结果与 `predict.py` 一致（8 类时期已抽测小麦锈病、玉米大斑病）
- 识别后预警中心出现 `[AI识别]` 记录
- 作物掩码、23 类防治、水稻选项、batch：**代码已齐**；**权重未齐**

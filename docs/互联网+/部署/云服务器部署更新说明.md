本地开发见 [`../网站/项目启动说明.md`](../网站/项目启动说明.md)。

## 一、架构

```text
浏览器  http://82.157.234.123:88
    │
    ├─ 页面  ──────────►  Nginx → frontend/dist/
    ├─ /api/analysis/* ─►  127.0.0.1:5000（路径保留）
    ├─ /api/treatments/* ►  127.0.0.1:5000（路径保留）
    └─ 其余 /api/* ────►  127.0.0.1:5000/ （去掉 /api → /login、/alerts）
                              Flask → 127.0.0.1:13306 → Docker 里的 MySQL
```

| 组件 | 端口 | 路径 / 说明 |
| --- | --- | --- |
| Vue | **88** | `frontend/dist/`，Nginx 静态站（面板可能仍叫 PHP 项目） |
| Flask | **5000** | `api_flask/`，宝塔 Python 项目；入口脚本 `start.sh` → `serving/serve.py` |
| MySQL | 宿主机 **13306** → 容器 3306 | 库 `detect_system`，已有数据。Flask 用 `127.0.0.1:13306` |

Navicat / 本机 Flask 用 `82.157.234.123:13306`。云上 Flask **不要**写公网 IP，也 **不要**写 3306（宿主机没有 3306）。

不要再启：PM2 `json-api`、Node `api_mock`、根目录旧 `server/app.py`。外网放行 **88**；13306 仅给远程连库。

## 二、首次部署

### 2.1 目标目录

```text
/www/wwwroot/DetectSystem/
├── frontend/dist/              ← 网站根：index.html、assets/、favicon.png
└── api_flask/
    ├── start.sh                ← 宝塔启动命令只填这个（含 DATABASE_URL）
    ├── serving/                ← 本地 ml-bjj/serving
    ├── models/                 ← pest-cls-best.pt、pest-cls-meta.json
    ├── knowledge/              ← treatments.json
    ├── requirements.txt        ← 本地 ml-bjj/requirements.txt
    ├── uploads/                ← 可空
    └── py-project-env/         ← 在服务器创建，不要从 Windows 上传 .venv
```

`serving`、`models`、`knowledge` 必须同级。不要上传本机 `.venv`、`__pycache__`、训练集。`.pt` 不在 Git 里，必须从本机拷。

库 **已经有数据**：不要重建、不要跑 `import_db_json.py`、不要清空表。

### 2.2 本机准备

```powershell
pnpm install
pnpm build
```

| 本地 | 传到服务器 |
| --- | --- |
| `dist/` 内全部文件 | `frontend/dist/`（不要再套一层 dist） |
| `ml-bjj/serving/` | `api_flask/serving/` |
| `ml-bjj/models/pest-cls-best.pt` 与 `pest-cls-meta.json` | `api_flask/models/` |
| `ml-bjj/knowledge/treatments.json` | `api_flask/knowledge/` |
| `ml-bjj/requirements.txt` | `api_flask/requirements.txt` |
| `ml-bjj/baota_start.sh` | 见 §2.5，改名为 `start.sh` 并改密码 |

### 2.3 前端站点

宝塔 → **网站** → 根目录 `/www/wwwroot/DetectSystem/frontend/dist`，端口 **88**。上传 `dist/` **里面**的文件。

### 2.4 清空并上传 `api_flask`

1. Python 项目若已有 `api_flask`，先 **停止**
2. 文件管理器进入该目录，**全选删除**后按 §2.1 上传
3. 不要留 2024 年那份 3KB 空壳 `app.py`

历史包袱：停掉 PM2 `json-api`、Node `api_mock`。`ss -tlnp | grep 3000` 不应再有输出。

### 2.5 启动脚本 `start.sh`（文件管理器即可）

宝塔执行 `nohup <启动命令>`。把 `DATABASE_URL=...` 写进启动命令会被当成程序名。面板「指定变量」也容易灌不进去。密码放在脚本里。

1. 打开 `api_flask/` → **新建文件** `start.sh`
2. 粘贴本地 `ml-bjj/baota_start.sh`，把 `改成你的密码` 换成库密码：

```bash
#!/bin/bash
set -e
cd /www/wwwroot/DetectSystem/api_flask
export DATABASE_URL='mysql+pymysql://detect_system:<密码>@127.0.0.1:13306/detect_system'
exec ./py-project-env/bin/python serving/serve.py
```

3. 该文件 **权限 755**
4. Python 项目 **环境变量选「无」**，启动命令 **只填**：

```text
/www/wwwroot/DetectSystem/api_flask/start.sh
```

### 2.6 虚拟环境（上传不会自动出现）

在 `api_flask` 的终端：

```bash
cd /www/wwwroot/DetectSystem/api_flask
python3 -m venv py-project-env
py-project-env/bin/pip install -U pip
py-project-env/bin/pip install -r requirements.txt
```

必须用 `py-project-env/bin/pip`，否则会装到系统 Python。含 torch，耗时长。装完文件管理器里应有 `py-project-env/`。

### 2.7 宝塔 Python 项目

| 项 | 值 |
| --- | --- |
| 名称 | `api_flask` |
| 路径 | `/www/wwwroot/DetectSystem/api_flask` |
| 启动方式 | 命令行启动 |
| **启动命令** | `/www/wwwroot/DetectSystem/api_flask/start.sh` |
| 端口 | `5000` |
| Python | 3.10 / 3.11 |
| 启动用户 | `www` |
| 环境变量 | **无** |

先装完依赖再点启动。日志应有 waitress:5000；有权重时打印 23 类就绪。

### 2.8 Nginx

只配 **一处**（配置文件或「反向代理」，不要两处都加）。

```nginx
location /api/analysis/ {
    proxy_pass http://127.0.0.1:5000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

location /api/treatments/ {
    proxy_pass http://127.0.0.1:5000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

location /api/ {
    proxy_pass http://127.0.0.1:5000/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

location / {
    try_files $uri $uri/ /index.html;
}
```

`/api/` 的 `proxy_pass` 必须带尾部 `/`。analysis / treatments **不要** rewrite。全部进 5000，不要 3000。

```bash
nginx -t && nginx -s reload
```

主配置：`/www/server/panel/vhost/nginx/82.157.234.123.conf`

### 2.9 防火墙

腾讯云防火墙 + 宝塔 **安全** 都放行 TCP **88**。外网以手机 4G 为准。

### 2.10 验收

```bash
ss -tlnp | grep -E ':88|:5000|:13306|:3000'
pgrep -af serve.py
tr '\0' '\n' < /proc/$(pgrep -n -f serve.py)/environ | grep DATABASE

curl -I http://127.0.0.1:88/
curl -s -w "\n%{http_code}\n" -X POST http://127.0.0.1:5000/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800000000","password":"123456"}'
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:5000/api/analysis/health
```

`/login` 只接受 POST，裸 GET 会 404，不能用来判断。登录 200/401 表示已连上库。`environ` 里应有 `:13306`。

浏览器强刷后：登录、预警、地图、识图各点一遍。

## 三、日常发版

服务器不拉 Git。业务数据在 MySQL，不要靠上传 `db.json`。

| 档位 | 何时 | 做什么 |
| --- | --- | --- |
| **A 仅前端** | 只改页面 / 样式 / Store | `pnpm build` → 覆盖 `frontend/dist/` → 强刷。不动 Python |
| **B Flask / 权重** | 改了 `serving`、`.pt`、`knowledge`、依赖 | 覆盖对应目录；依赖变则 `py-project-env/bin/pip install -r requirements.txt`；**重启 Python** |

保留 `py-project-env/` 和 `start.sh`，不要用本机虚拟环境覆盖。换 `.pt` 后必须重启。

```text
pnpm build → 上传 dist/
    →（档位 B）覆盖 serving / models / knowledge → pip → 重启 Python
    → curl + 浏览器强刷
```

发版后建议：登录、首页/预警、相关数据、智慧决策、智能分析、手机导航。

## 四、排查

面板「PHP 项目」根目录若是 `frontend/dist`，就是静态 Vue，不用删。

### 4.1 先看端口

```bash
ss -tlnp | grep -E ':88|:5000|:13306|:3000'
```

| 现象 | 处理 |
| --- | --- |
| 本机 88 通、公网不通 | 腾讯云 / 宝塔未放行 88 |
| 88 不通 | Nginx 或网站根目录不是 `frontend/dist` |
| 整站 nginx **500** | 网站目录指错；看站点错误日志 |
| 5000 没有 | 未启动，或 `start.sh` 权限不是 755 |
| 13306 没有 | Docker MySQL 容器未运行 |
| 仍有 3000 | 停掉 Node / PM2 |

### 4.2 对照表

| 现象 | 处理 |
| --- | --- |
| `nohup: failed to run command 'DATABASE_URL=...'` | 启动命令只能是 `start.sh` 路径；环境变量选「无」；旧日志可忽略 |
| `nohup: failed to run command 'python'` | 不要写裸的 `python` |
| `Can't connect to MySQL ... 127.0.0.1` 且 111 | URL 写成了 3306；应是 `127.0.0.1:13306` |
| Navicat 能连、云上 Flask 不能 | Navicat 走公网 13306；Flask 必须走本机 13306，且进程 `environ` 里真有该变量 |
| 登录 503「未配置数据库」 | `start.sh` 未 `export DATABASE_URL`，或没走 `start.sh` |
| 502 仅 API | Flask 没起来，或 Nginx 仍反代 3000 |
| `/home` 404 | 缺 `try_files` |
| `duplicate location "/api/..."` | 配置文件与面板反代重复，只留一处 |
| 识病失败 | `models/` 与 `serving/` 不同级，或缺 `.pt`，未重启 |
| 页面旧样式 | `dist` 未覆盖全，或浏览器缓存 |
| `favicon.ico` 500 | 只有 `favicon.png`，可忽略 |

查进程环境变量（文件名是 **environ**）：

```bash
tr '\0' '\n' < /proc/$(pgrep -n -f serve.py)/environ | grep DATABASE
```

### 4.3 网站挂了时

1. `ss` 看 88 / 5000 / 13306  
2. 防火墙 88  
3. Python 是否运行、启动命令是否为 `start.sh`  
4. `environ` 是否含 13306  
5. `nginx -t && nginx -s reload`  
6. 手机 4G：首页、登录、识图

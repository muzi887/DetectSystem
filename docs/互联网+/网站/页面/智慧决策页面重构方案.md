# 智慧决策页面重构方案（一屏展示 · 三列 IoT 决策台）

> **页面**：`/decision` · `src/views/user/DecisionSupport.vue`  
> **背景**：互联网＋ 2.0 答辩需「仪表盘式一屏决策」；V1.0 已解决列表撑破页面问题，但 **左栏同时承担「待办队列 + 地图」**，信息角色混杂，不符合主流物联网平台的 **告警 → 态势 → 处置** 工作流。  
> **关联**：[`防治知识库实现方案.md`](../方案/防治知识库实现方案.md)、[`2.0非AI模块实现方案.md`](../方案/2.0非AI模块实现方案.md)、[`../2.0-功能扩展规划.md`](../../规划/2.0-功能扩展规划.md) §决策支持  
> **状态**：V2.2 ✅ 已实施  
> **左/右栏溢出**（分页、级别筛选、Collapse）：见 [`智慧决策-左栏分页与溢出实现说明.md`](./智慧决策-左栏分页与溢出实现说明.md)  
> **基准截图**：`docs/互联网+/网站/屏幕截图 2026-07-09 101649.png`

## 一、问题与目标

### 1.1 各版本已解决项

| 项 | 版本 | 状态 |
|----|------|------|
| 页面级纵向滚动 | V1.0 | ✅ `page-main-shell--fill` 高度链 |
| 三列布局与地图归位 | V2.0 | ✅ 左队列 / 中态势 / 右处置 |
| 进入页默认选中首条 | V2.1 | ✅ `syncDefaultSelection()` |
| 区域概览与灾害实时监测同地图 | V2.1 | ✅ 高德卫星 + `createMonitorPointLayer` |
| 左栏溢出（滚动条） | V2.2 | ✅ 见 [溢出说明](./智慧决策-左栏分页与溢出实现说明.md) |
| 右栏 AI 建议溢出 | V2.2 | ✅ 见同上 |

### 1.2 V2.0 动机（布局）

| 现象 | 原因 |
|------|------|
| 左栏「待办 + 地图」职责不清 | 地图挤占队列空间，打断 **选告警 → 看态势 → 读建议** 动线 |
| 中、右缺空间上下文 | 监测与 AI 建议并排，地图被降级为左栏附属 |
| 进入页为空态 | 有待办时也需手动点选，答辩首屏信息量为零 |

### 1.3 重构目标（当前）

| 编号 | 要求 | 验收标准 |
|------|------|----------|
| **G1** | **一屏三列** | 桌面 ≥1280px：告警队列 \| 态势（监测+地图）\| AI 建议同屏，无页面级滚动 |
| **G2** | **左栏纯队列** | 仅「待处理灾害预警」+ 级别 Tab + 分页；**无地图、无列内滚动条** |
| **G3** | **中栏态势** | 上：实时监测数据；下：区域概览（Leaflet + 经纬度） |
| **G4** | **右栏处置** | AI 建议 `a-collapse` 分段；「导出方案」在标题栏 |
| **G5** | **IoT 工作流** | 队列选事件 → 中间看数据与位置 → 右侧读建议 |
| **G6** | **窄屏降级** | ≤992px 单列堆叠；左栏分页规则见 [溢出说明](./智慧决策-左栏分页与溢出实现说明.md) |
| **G7** | **默认选中首条** | 有待办时自动选中最新一条，中/右立即展示 |

## 二、开源物联网平台参考

### 2.1 常见布局模式

| 平台 | 典型决策/告警界面 | 可借鉴点 |
|------|-------------------|----------|
| **[ThingsBoard](https://github.com/thingsboard/thingsboard)** | 左侧 Alarm 列表 → 中间 Dashboard（遥测 + 地图）→ 右侧属性/规则 | Alarm 队列独立；地图与遥测同属「详情区」 |
| **[Grafana](https://github.com/grafana/grafana)** | Alerting 分组列表 + 详情侧栏 | 选中驱动详情；侧栏承载下一步操作 |
| **[Home Assistant](https://github.com/home-assistant/core)** | 实体列表 → 详情（状态 + 地图） | 状态指标优先；详情分段折叠 |
| **[JetLinks](https://github.com/jetlinks/jetlinks-community)** | 设备列表 \| 详情 \| 告警处理 | 三栏 + 分页表格 |
| **[OpenRemote](https://github.com/openremote/openremote)** | 资产树 + 地图主视图 + 属性面板 | 地图居中 SCADA 思路 |

### 2.2 告警处置三件套

```text
┌─────────────┬──────────────────────┬─────────────────┐
│  Alarm Queue│  Situation Awareness │  Runbook / Action│
│  待办队列    │  遥测 + 地图 + 上下文  │  建议 / 工单 / 导出│
└─────────────┴──────────────────────┴─────────────────┘
```

| IoT 概念 | 本系统模块 | 列位置 |
|----------|------------|--------|
| Alarm Queue | `unhandledAlerts` | **左列** |
| Telemetry + Geo | 设备状态、温湿度、小地图 | **中列** |
| Runbook | 规则文案 + `treatments.json` | **右列** |

### 2.3 布局方案对比

| 方案 | 布局 | 结论 |
|------|------|------|
| A. V1.0 两栏 | 左：队列+地图；右：监测+建议 | 归档 |
| **B. 三列** | 左：队列；中：监测+地图；右：建议 | **★ 采用** |
| C. 地图居中 | 中：大地图 | 答辩备选 |
| D. Tab 详情 | 右栏 Tab 切换 | 不推荐（违背 G1） |

## 三、布局设计

### 3.1 目标线框（桌面 ≥1280px）

```text
┌──────────────────────────────────────────────────────────────────────────┐
│  AppLayout 顶栏 + 主导航                                                  │
├──────────────────────────────────────────────────────────────────────────┤
│  智慧决策支持（glass 卡片 · 占满视口）                                       │
│  ┌─────────────┬──────────────────────────┬───────────────────────────┐  │
│  │ 左列 260–300│ 中列 flex-1               │ 右列 300–360               │  │
│  │ 待处理预警   │  实时监测数据              │  AI 决策建议    [导出方案]  │  │
│  │ [N][折叠]   │  区域概览（Leaflet 地图）   │  a-collapse 分段           │  │
│  │ 全部/高/中/低│                          │                           │  │
│  │ 列表+分页    │                          │                           │  │
│  └─────────────┴──────────────────────────┴───────────────────────────┘  │
│  有待办 → 首条已选中；无待办 → 左列空态 + 中右占位                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 3.2 Grid 规格

```css
.decision-dashboard {
  display: grid;
  grid-template-columns: minmax(260px, 300px) minmax(0, 1fr) minmax(300px, 360px);
  gap: 16px;
  flex: 1;
  min-height: 0;
  overflow: hidden;
}
```

| 列 | 类名 | 内容 |
|----|------|------|
| 左 | `.col-queue` | `alert-panel`：级别 Tab + 分页列表 |
| 中 | `.col-situation` | `monitor-panel` + `map-panel` |
| 右 | `.col-action` | `suggestion-panel` + Collapse |

### 3.3 高度链

```text
.app-shell (100vh)
  └─ .content-slot (min-height:0)
       └─ .page-main-shell--fill
            └─ .decision-page-fill
                 └─ .decision-dashboard
```

工具类见 `src/styles/page-card.css`（`.page-main-shell--fill`）。

### 3.4 中列态势层

- **monitor-panel**：设备状态、温度、土壤湿度（三指标横排）  
- **map-panel**：与 [`MapVisualization.vue`](../../../../src/views/user/MapVisualization.vue) 同底图（高德卫星）+ `createMonitorPointLayer`；选中预警 `highlightPoint`

## 五、交互规格

### 5.1 左列 · 告警队列

| 行为 | 说明 |
|------|------|
| Badge | 标题旁待处理总数 |
| 折叠 | 收起 body；选中与中/右栏保留 |
| 选中 | 高亮；驱动中、右列更新 |

级别筛选、分页规则见 [溢出说明](./智慧决策-左栏分页与溢出实现说明.md)。

### 5.2 中列 · 态势

绑定当前 `selectedArea`：`pointStatus`、`pointTemp`、`pointSoilMoisture`、地图坐标。

**P2 可选**：监测区迷你 sparkline（依赖 2.0 时序 API）。

### 5.3 右列 · AI 决策建议

| 行为 | 说明 |
|------|------|
| 展示 | `buildTreatmentPanels` + `buildRuleSuggestions` → `a-collapse` |
| 默认展开 | 「化学防治」「联动处置建议」（无化学则展开「病害概述」） |
| 导出 | 标题栏「导出方案」，导出全部面板文案 |

Collapse 结构与无滚动实现见 [溢出说明](./智慧决策-左栏分页与溢出实现说明.md)。

### 5.4 默认选中首条（G7）

```typescript
function syncDefaultSelection() {
  const list = filteredAlerts.value.length ? filteredAlerts.value : unhandledAlerts.value
  if (list.length === 0) {
    selectedArea.value = null
    return
  }
  const stillExists =
    selectedArea.value != null && list.some((a) => a.id === selectedArea.value!.id)
  if (!stillExists) selectedArea.value = list[0]
}
```

- 进入页 / `fetchAlerts` + `fetchMonitorPoints` 完成后调用  
- 排序与列表一致：`time` 降序，**默认最新待办**  
- 预警中心「标记解决」后列表变化 → 自动选中下一条或空态

### 5.5 空态

| 场景 | 左列 | 中列 + 右列 |
|------|------|-------------|
| 无待办 | 「暂无待处理预警」 | 「当前无待处理预警，请先在预警中心或智能分析产生事件」 |
| 有待办 | 列表 + 首条高亮 | 态势 + AI 建议（不用「请先选择」文案） |

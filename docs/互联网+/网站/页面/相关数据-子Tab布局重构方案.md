## 一、当前网站结构

```text
┌ AppLayout 顶栏（站点导航，不改）─────────────────────────────┐
┌ data-page-content：Tab 条 + 全宽主卡 ─────────────────────────┐
│ ┌ 地面监测站 (地) │ 无人机遥感 (空) │ 卫星遥感 (天) ─────────┐ │
│ └────────────────────────────────────────────────────────────┘ │
│ ┌ 主玻璃卡 ──────────────────────────────────────────────────┐ │
│ │ 标题 + 本 Tab 操作 + 生成简报 + 查看详情                    │ │
│ │ 土壤折线 / 气象九宫格 / NDVI 地图 / 卫星左图右栏            │ │
│ │ 地面站、无人机：底栏 AI；卫星：AI 在右栏底部                │ │
│ └────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

| 按钮 | `currentTab` | 主内容 | 顶栏额外操作 |
|------|----------------|--------|----------------|
| 地面监测站 (地) | `sensor` | 默认土壤折线；`sensorSection` 切气象 | 土壤：`对比监测站 · N`（固定宽度，不下标签）；气象：单站下拉。「查看气象数据 / 查看土壤监测」 |
| 无人机遥感 (空) | `drone` | Leaflet NDVI、地块/日期/对比 | 简报、详情 |
| 卫星遥感 (天) | `satellite` | 左栏 `docs/出图` JPG，右栏类型/日期/期数 | 「全屏看图」、简报、详情 |

已取消：`weather` 独立 Tab、`gis` 独立 Tab。气象布局仍是左实时 / 右预报+阈值，只是挂在地面站里（`showWeatherPanel`）。

窄屏 `width <= 992px`：Tab 可换行；卫星改为上图下栏。

## 二、方案 B 为什么还在（历史）

原先四个大按钮竖在右侧 220px 栏，主卡被挤窄。已改为页内横排 Tab，**不要**写进 `AppLayout` 顶栏。这一刀仍然有效，只是后来 Tab 从四格收成三格。

---

## 三、地面站选择器（现网）

土壤对比最多 3 站。顶栏 **不**把完整站名做成多行标签（会把选择框撑高）。

现网方案 C：选择框固定约 `11rem × 32px`，关闭态只显示 `对比监测站 · 2`；全名在下拉里勾选。折线图例用短站名（`建三江-气温` 等）表示选了谁。

气象版块仍是单站下拉（九类读数按站）。

---

## 四、生成简报（现网）

同一份 Flask `{ markdown }`：

- 弹窗 HTML 预览（公文式米色纸面；监测点/预警/极端天气渲成表；附图为带图题的图版）
- 「下载 md」
- 「导出 PDF」=`window.print()` 另存；勿给摘要卡片加 `page-break-inside: avoid`（会空出第一页）

附图来自当前页能拿到的 NDVI `imageUrl`、卫星 `currentSatelliteItem.url`、以及已加载的 `forecastDays` 表。

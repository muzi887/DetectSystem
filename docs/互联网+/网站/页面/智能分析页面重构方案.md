## 一、问题与目标

### 1.1 现状问题

**V1.4 左栏（本版要改）**

| 现象 | 原因 |
|------|------|
| 叶片预览只有 120×120，在 1:1 左栏里显得过小 | 列变宽后仍用三列时期的缩略格 |
| 「灾害 / 病虫害 / 气候 / 其他」四个短词占两大行 | `.category-grid` 为 `1fr 1fr`，按钮被拉满栏宽 |

**已归档（不再作为本版目标）**

| 现象 | 处理 |
|------|------|
| 中列图像预览空白 | V1.3 删除中列，大图改弹窗 |
| 整页滚动、防治平铺 | V1.1 / V1.2 Collapse + `--fill` |

### 1.2 业务工作流（不变）

```text
上传图片 + 选作物/类别 → POST /api/analysis/image → 展示病名 + 置信度
    → createAlert 写预警 → 预警中心 / 智慧决策可读
```

API、Vite 代理、推理服务 **不改动**。V1.5 只改 **左栏内部排版**（预览尺寸 + 类别控件），不改两列比、不改弹窗、不改 API。

### 1.3 重构目标

| 编号 | 要求 | 验收标准 |
|------|------|----------|
| **G1** | **一屏两列等宽** | 桌面 ≥1280px：输入 \| 结果同屏、**1:1**；无常驻预览列；无页面级滚动 |
| **G2** | **风格统一** | 与决策页共用 `page-main-shell--fill`、`.glass-widget-card` |
| **G3** | **左栏输入** | 大图预览与表单横排；作物、类别胶囊、补充、「开始分析」、批量 |
| **G4** | **大图核对** | 左栏预览区展示叶片（`contain`）；再点仍打开 `a-modal`；无图为同尺寸上传框 |
| **G5** | **右栏输出** | 病名、置信度、健康 Tag；作物·类别·时间；防治 `a-collapse`；跳转预警/决策 |
| **G6** | **窄屏降级** | ≤992px 单列：输入 → 结果；弹窗仍可用 |
| **G7** | **状态清晰** | 空态 / 上传中 / 分析中 / 有结果；进度在左栏缩略 overlay + 右栏 Spin，不依赖中列 |

## 二、与智慧决策的对齐关系

### 2.1 双页 IoT 工作流

```text
┌──────────────────── 智能分析 /analysis ────────────────────┐
│  Input                         │  Output / Runbook          │
│  上传缩略 + 参数 + 开始分析      │  病名 + 置信度 + 防治       │
│  （点缩略图 → 预览弹窗）         │  [预警中心] [智慧决策]      │
└───────────────────────────┬────────────────────────────────┘
                            │ createAlert
                            ▼
┌──────────────────── 智慧决策 /decision ────────────────────┐
│  Alarm Queue    │  Situation           │  AI 建议 Collapse  │
│  待办列表        │  监测+地图            │  联动处置           │
└────────────────────────────────────────────────────────────┘
```

| 决策页列 | 分析页 | 职责 |
|----------|--------|------|
| 左 · 队列 | 左 · **输入** | 发起任务 |
| 中 · 态势 | **不做常驻列** | 叶片图不是地图/监测，核对时用弹窗即可 |
| 右 · 处置 | 右 · **输出**（与左等宽） | 结论与可执行建议 |

### 2.2 共用设计令牌

| 项 | 决策页已有 | 分析页 |
|----|------------|--------|
| 页面壳 | `page-main-shell--fill` | ✅ 同 |
| 卡片 | `glass-widget-card`、`widget-card` | ✅ 同 |
| Grid | 三列 `260–300 \| 1fr \| 300–360` | **两列 `1fr 1fr`**，见 §3.2 |
| 右栏防治 | `buildTreatmentPanels` + `a-collapse` | ✅ 同 |
| 溢出 | 右栏 Collapse、无列内滚动 | ✅ 同 [溢出说明](./智慧决策-左栏分页与溢出实现说明.md) |

### 2.3 布局方案对比

| 方案 | 布局 | 结论 |
|------|------|------|
| A. 上表单下结果 | 小挑时期纵向布局 | 归档（V1.1 已淘汰） |
| B. 三列 | 左输入 / 中预览 / 右结果 | V1.2 已实施；中列空态差，**本版归档** |
| C. 两列、无弹窗 | 删中列；只能看 120 缩略 | 版面干净，但答辩核对病斑不便 |
| **E. 两列 + 预览弹窗** | 删 `.col-preview`；点预览开 `a-modal` | ✅ V1.3 采用 |
| **F. 左栏图左表右 + 类别胶囊** | 见 §3.5 | **★ V1.5 采用** |
| D. Tab 切换输入/结果 | 一屏只能看一块 | 不采用 |

**不采用「只改弹窗、保留中列」**：中列存在本身就是空态来源；弹窗是大图的替代，不是中列的附件。

## 三、布局设计

### 3.1 目标线框（桌面 ≥1280px）

```text
┌──────────────────────────────────────────────────────────────────┐
│  AppLayout 顶栏 + 主导航                                          │
├──────────────────────────────────────────────────────────────────┤
│  智能分析（glass 卡片 · 占满视口）                                   │
│  ┌────────────────────────────┬────────────────────────────────┐  │
│  │ 左列 1fr                    │ 右列 1fr                        │  │
│  │ 分析参数                    │  分析结果                       │  │
│  │ ┌─────────┬──────────────┐  │  病名 + Tag + 置信度             │  │
│  │ │ 大图预览 │ 类别胶囊一行  │  │  作物 · 类别 · 时间               │  │
│  │ │ contain │ 作物 / 补充   │  │  a-collapse 防治建议             │  │
│  │ │         │ [开始分析]    │  │  [预警中心] [智慧决策]            │  │
│  │ └─────────┴──────────────┘  │                                 │  │
│  │ 批量                       │                                 │  │
│  └────────────────────────────┴────────────────────────────────┘  │
│  未分析 → 右列空态；分析中 → 右列 Spin；有图点缩略 → Modal 大图     │
└──────────────────────────────────────────────────────────────────┘
```

**预览弹窗**（有图且用户点击缩略图后）：

```text
┌─────────────────────────────┐
│  图像预览              [×]  │
│  ┌───────────────────────┐  │
│  │  叶片大图 contain      │  │
│  │  最大约 70vh           │  │
│  └───────────────────────┘  │
│         [更换图片]  [关闭]   │
└─────────────────────────────┘
```

### 3.2 Grid 规格

```css
.analysis-dashboard {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(0, 1fr);
  gap: 16px;
  flex: 1;
  min-height: 0;
  overflow: hidden;
}
```

### 3.2.1 为何是 1:1 而不是 1:2

V1.3 写 `minmax(300px, 380px) 1fr`，桌面实际约 **1:2**。那是把决策页「中间列给地图」的 `1fr` 套到了分析右栏。

| | 约 1:2（V1.3） | **1:1（本版）** |
|--|----------------|-----------------|
| 空态 | 2/3 屏给烧杯占位，第一印象空 | 左右份量接近 |
| 有结果 | 防治是纵向 Collapse，行被拉得很长 | 中文阅读宽度约半屏，合适 |
| 左栏拥挤 | 不解决（挤在竖向叠放） | 单独也不解竖向拥挤，但不再像细侧栏 |

右栏内容是病名 + 置信度条 + Collapse，接近决策页**最右处置列**（300–360px 就够读），不需要地图那种剩余宽度。`minmax(0, 1fr)` 防止子项把格子撑破（同首页等宽两列）。

左栏内部「图 | 控件」横排见 **V1.5 §3.5**。

| 列 | 类名 | 面板 |
|----|------|------|
| 左 | `.col-input` | `input-panel` |
| 右 | `.col-output` | `output-panel` |

**删除**：`.col-preview`、`preview-panel`、中列 `a-upload-dragger`。

### 3.3 高度链

```text
.app-shell (100vh)
  └─ .content-slot (min-height:0)
       └─ .page-main-shell--fill
            └─ .analysis-page-fill
                 └─ .analysis-dashboard   ← 两列 Grid
```

细节见 [`智能分析-一屏高度与溢出实现说明.md`](./智能分析-一屏高度与溢出实现说明.md)。Modal 挂在 `body`，**不参与**高度链。

### 3.4 各列与弹窗规格

**左列 · 输入（V1.5）**

见 §3.5。交互不变：无图上传；有图点击预览打开弹窗（不直接选文件）；「更换图片」仍在弹窗。

**右列 · 输出**

| 状态 | 展示 |
|------|------|
| 空态 | 图标 + 「开始分析后，病名、置信度与防治建议会显示在这里」 |
| 分析中 | `a-spin` + 「推理中，请稍候」 |
| 有结果 | 病名 + 健康/需关注 Tag；置信度进度条；**meta：作物 · 类别 · 时间**（从原中列底栏迁入） |
| 防治 | `buildTreatmentPanels` → `a-collapse` |
| 底栏 | 非健康：链接 **预警中心**、**智慧决策** |

**预览弹窗**

| 项 | 规格 |
|----|------|
| 组件 | Ant Design Vue `a-modal`；`wrapClassName` 走 glass（半透明深绿底、白字） |
| 打开 | 左栏已有 `imageUrl` 时点击**预览区**（不是 120 小格） |
| 关闭 | 右上角 ×、遮罩、Esc、「关闭」 |
| 图 | `object-fit: contain`；弹窗宽度约 720px 或 `width: 70vw`（上限 900px）；图 `max-height: 70vh` |
| 更换图片 | 页脚按钮，触发与现上传相同的 `beforeUpload` / `customRequest` / `handleChange`；更换成功后可保持弹窗打开并刷新大图 |
| 不自动打开 | 上传完成、分析完成都 **不** 自动弹，避免打断填参数 |
| 上传/分析中 | 预览区 overlay（进度圈 / Spin）；弹窗若已打开同样加一层 |

### 3.5 左栏内部（V1.5）

#### 3.5.1 三种排法

| 方案 | 做法 | 结论 |
|------|------|------|
| F1. 图在上拉满宽 | 预览全宽、高度 220–280；下面再叠表单 | 图变大，但左栏又变回「上图下表」长条，一屏易挤 |
| **F2. 图左表右 2:1** | `.input-main`：预览 `2fr` \| 表单 `1fr`；底栏批量仍全宽 | **★ 采用** |
| F3. 只改类别为一行四等分 | 按钮仍 `flex:1` 拉满 | 不采用。短词仍然占地 |

#### 3.5.2 目标线框（左栏卡片 body）

```text
┌──────────────────────────────────────────────┐
│ 分析参数                                      │
│  ┌─────────────────────┬──────────┐ │
│  │ .preview-box  2fr   │ 表单 1fr │ │
│  │ 无图：虚线上传  │  [灾害][病虫害][气候][其他]│ │
│  │ 有图：contain  │  （选中加深；宽随文字）     │ │
│  │ 最小约 220×220 │  [小麦              ▼]  │ │
│  │ 高度跟表单齐   │  补充信息（2 行）         │ │
│  │ 点图 → 弹窗    │  [     开始分析     ]    │ │
│  └────────────────┴────────────────────────┘ │
│  [批量] 未选择任何文件              [识别]    │
└──────────────────────────────────────────────┘
```

#### 3.5.3 预览区

| 项 | 规格 |
|----|------|
| 容器 | `.preview-box`：`min-height: 220px`；`flex/grid` 与右侧表单**同高**（吃 `.input-main` 剩余高度，上限不撑破左栏） |
| 无图 | 同尺寸虚线框 + 「上传叶片」；仍走现有 `beforeUpload` |
| 有图 | `object-fit: contain`（不要 `cover` 裁病斑）；点击打开现有弹窗 |
| 进度 | overlay 盖在预览区上，逻辑沿用 `uploading` / `analyzing` |
| 不再使用 | `list-type="picture-card"` 的 120×120 选择格作为主预览 |

#### 3.5.4 类别胶囊

```css
.category-row {
  display: flex;
  flex-wrap: wrap;
  gap: 6px;
}
.category-btn {
  height: 28px;
  padding: 0 12px;
  width: auto;          /* 禁止 1fr 拉满 */
  flex: 0 0 auto;
}
```

文案仍用短名：灾害 / 病虫害 / 气候 / 其他。默认「病虫害」。非病虫害仍显示「当前模型为病虫害分类，其他类别仅供参考」（可缩成一行小字，放在胶囊下方）。

#### 3.5.5 Grid

```css
.input-main {
  display: grid;
  grid-template-columns: minmax(0, 2fr) minmax(0, 1fr);
  gap: 12px;
  flex: 1;
  min-height: 0;
}
```

`.input-fields` 纵向：胶囊 → hint → 作物 → 补充 → 开始分析（`margin-top: auto` 贴底，与预览下沿齐）。`.batch-row` **不进** `.input-main`，仍在卡片最底。

≤992px：`.input-main` 改为单列，预览在上（`min-height: 200px`），表单在下。

## 五、交互规格

### 5.1 分析流程

```text
无图：点预览区 → beforeUpload 校验 → 本地预览（左栏大图 contain）
有图：点预览区 → 打开预览弹窗
点「开始分析」→ analyzing=true → analyzeImage API
    → 写 analysisResult → createAlert → analyzing=false
```

推理逻辑保持现有 `handleConfirm` / 批量 / 纠错，**不改 API**。

### 5.2 右栏防治展示

| 项 | 说明 |
|----|------|
| 数据源 | `useTreatmentGuide().getTreatment(result)` |
| 组件 | `buildTreatmentPanels` + `a-collapse` |
| 默认展开 | 同决策页：「化学防治」，否则「病害概述」 |
| 低置信度 | `< 70%` 且非健康：复核提示 + 纠错 |

### 5.3 答辩快捷跳转

| 按钮 | 路由 | 场景 |
|------|------|------|
| 预警中心 | `/warnings` | 核对新写入的 `[AI识别]` 预警 |
| 智慧决策 | `/decision` | 演示「分析 → 决策」闭环 |

需要给评委看原图时：**点左栏预览区 → 弹窗**（栏内已是 contain 大图，弹窗用于再放大）。

### 5.4 空态与错误

| 场景 | 左栏 | 右栏 | 弹窗 |
|------|------|------|------|
| 未上传 | 预览区虚线上传 | 空态文案 | 不出现 |
| 已上传未分析 | 预览区 contain 大图 | 空态文案 | 可点开 |
| 分析中 | 预览 + overlay | Spin | 若已打开则保留 |
| API 失败 | 保留预览图 | `message.error`；不写 result | 可点开核对原图 |
| 健康结果 | 预览图 | Tag「健康」+ 巡检类防治 | 可点开 |

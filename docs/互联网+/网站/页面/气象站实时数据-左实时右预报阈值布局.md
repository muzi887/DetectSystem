# 气象站实时数据 · 左实时 / 右预报+阈值布局

> 方案 **B**（已选定）：相关数据页「气象预报」Tab 的三块内容（实时指标、7 日预报、阈值配置）不再挤在同一 `1fr` 网格里。  
> **页面**：`/related-data` · Tab `weather` · `src/views/user/RelatedData.vue`  
> **状态**：✅ 已实施（2026-08-22）

---

## 一、要解决什么问题

| 现象 | 原因 |
|------|------|
| 7 日预报表「消失」 | `.weather-grid` 使用 `grid-auto-rows: 1fr`，预报、3 行卡片、阈值**每一行等高**；表需要约 7 行高度，只分到一张卡那么高，再被 `.chart-wrapper { overflow: hidden }` 裁掉 |
| 阈值配置被遮盖、标签叠在输入框上 | `a-form layout="inline"` 单行硬塞 4 个数字框 + 保存按钮；底边同样被 `overflow: hidden` 裁切 |
| 副标题写「含 7 日预报」但屏上没有表 | 数据接口仍在（`loadForecast`），是布局把表裁没了，不是缺数据 |

**约束（与既有玻璃拟态一致）**：

- 不改气象接口、阈值保存、AI 结论文案
- AI 智能分析条仍在网格外、始终可见
- 输入/按钮：深绿半透明底、细白边、白字；保存按钮用 `--dark-green`，不用 Ant 默认亮蓝
- 7 行预报不用分页；仅当右栏略高时用细玻璃滚动条

## 二、方案选型

| 方案 | 说明 | 结论 |
|------|------|------|
| A. 上下铺满，区内滚动 | 三块竖排，中间区滚动 | 不采用。答辩时预报/阈值可能滚出首屏 |
| **B. 左实时 / 右预报+阈值** | 左 3×3 实时卡；右上 7 日表、右下阈值 | **★ 采用** |
| C. Tab 切换三块 | 同时只显示一块 | 不采用。答辩要来回切 |

窄屏（`width <= 992px`）：上→下为 **实时卡 → 7 日表 → 阈值 → AI 条**。

## 三、定稿结构

```text
┌ 气象站实时数据（glass-panel）──────────────────────────┐
│ 标题 · 监测站选择 · 生成简报                             │
│ ┌ weather-body ───────────────────────────────────────┐ │
│ │ 左 weather-metrics 3×3     │ 右 weather-side        │ │
│ │ 墒情 / 地温 / EC            │ 7 日预报（玻璃表）     │ │
│ │ 气温 / 湿度 / 风速          │                        │ │
│ │ 风向 / 气压 / 降水          │ 阈值配置 2×2 + 保存    │ │
│ └────────────────────────────┴────────────────────────┘ │
│ [AI 智能分析]（flex-shrink: 0，不进网格）                │
└─────────────────────────────────────────────────────────┘
```

**DOM 骨架**（只动气象 Tab，其它 Tab 不动）：

```vue
<div v-if="currentTab === 'weather'" class="weather-layout">
  <div v-if="activeExtremeTitles.length" class="weather-extreme-tags">...</div>
  <div class="weather-body">
    <div class="weather-metrics">
      <a-card v-for="item in weatherMetrics" class="weather-card" />
      <div v-if="!weatherMetrics.length" class="weather-empty">暂无该监测站气象读数</div>
    </div>
    <aside class="weather-side">
      <section class="weather-forecast-block">
        <h4 class="weather-side-title">7 日预报</h4>
        <a-table v-if="forecastDays.length" class="forecast-table" />
        <div v-else class="forecast-empty">暂无该站 7 日预报</div>
      </section>
      <section class="threshold-settings">
        <h4 class="threshold-title">阈值配置</h4>
        <a-form layout="vertical" class="threshold-form">
          <!-- 2×2：墒情提示 / 墒情告警 / 气温提示 / 气温告警 -->
          <a-button type="primary" @click="savePointThresholds">保存阈值</a-button>
        </a-form>
      </section>
    </aside>
  </div>
</div>
```

**布局 CSS 要点**：

```css
.weather-layout { flex: 1; min-height: 0; display: flex; flex-direction: column; overflow: hidden; }
.weather-body {
  flex: 1; min-height: 0;
  display: grid;
  grid-template-columns: minmax(0, 1.4fr) minmax(280px, 1fr);
  gap: 16px;
}
.weather-metrics { display: grid; grid-template-columns: repeat(3, minmax(0, 1fr)); gap: 12px; }
.weather-side { display: flex; flex-direction: column; gap: 12px; min-height: 0; overflow: hidden; }
.weather-forecast-block { flex: 1; min-height: 0; display: flex; flex-direction: column; overflow: hidden; }
.forecast-table { flex: 1; min-height: 0; overflow: auto; } /* 仅略高时出现细滚动条 */
.threshold-settings { flex-shrink: 0; } /* 永不裁切 */
.threshold-grid { display: grid; grid-template-columns: 1fr 1fr; gap: 8px 12px; }
```

删除 `.weather-grid` 的 `grid-auto-rows: 1fr`（根因）。

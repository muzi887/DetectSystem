## 一、入口（现网）

相关数据 → **地面监测站 (地)** → **查看气象数据**。标题变为「气象站实时数据」。点「查看土壤监测」回到折线。

模板条件是 `showWeatherPanel`（`currentTab === 'sensor' && sensorSection === 'weather'`），**不是** `currentTab === 'weather'`。

顶栏：单站 `a-select`（不是土壤页的「对比监测站 · N」）+ 切回土壤 + 简报 + 详情。

AI 条在气象版块时仍在主卡底部（卫星页 AI 在右栏，与此无关）。

---

## 二、要解决什么问题

| 现象 | 原因 |
|------|------|
| 7 日预报表曾「消失」 | 旧 `.weather-grid` 用 `grid-auto-rows: 1fr`，表被 `.chart-wrapper { overflow: hidden }` 裁掉 |
| 阈值标签叠在输入框上 | `a-form layout="inline"` 单行硬塞 |
| 副标题写「含 7 日预报」但看不见表 | 接口仍在，是布局裁切 |

**约束**：不改气象接口、阈值保存；保存按钮 `--dark-green`，不用 Ant 亮蓝。

## 三、定稿结构

```text
┌ 气象站实时数据 ─────────────────────────────────────────┐
│ 标题 · 监测站选择 · 查看土壤监测 · 简报 · 详情            │
```

窄屏（`width <= 992px`）：实时 → 预报 → 阈值 → AI。

删除 `.weather-grid` 的 `grid-auto-rows: 1fr`（根因）。左栏 `minmax(0, 1.4fr)`，右栏 `minmax(280px, 1fr)`。

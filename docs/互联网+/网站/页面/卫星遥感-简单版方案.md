## 一、为什么要做简单版

完整清单（NDVI、土地利用、作物类型、病虫害、气象灾害 + GIS）若全部做成卫星页上的并列入口，比三个 Tab 更重，空按钮也没有图层可接。

本系统已有分工，不必在卫星页重复：

| 内容 | 放哪 | 说明 |
|------|------|------|
| 土壤折线、气象站读数 | 地面监测站 | 「查看气象数据」切到气象版块 |
| 地块 NDVI、航迹、历史对比 | 无人机遥感 | 地块尺度，不进卫星页 |
| 病虫害识别与草稿 | 智能分析 / 灾害预警 | 已有流程 |
| 土地利用、作物类型 | **不做入口** | 暂无稳定图层 |
| 区域墒情热力、点选查墒 | 已取消独立 GIS Tab | 不作为卫星页主画面 |
| 干旱/高温/暴雨/大风空间分布 | **卫星遥感** | 出图按日调取，左图右栏 |

## 二、相关数据入口

三个 Tab，无独立 GIS、无独立气象 Tab：

| 按钮 | key | 主内容 |
|------|------|--------|
| 地面监测站 (地) | `sensor` | 土壤折线；按钮切气象站读数 |
| 无人机遥感 (空) | `drone` | NDVI Leaflet |
| 卫星遥感 (天) | `satellite` | 左栏出图、右栏类型/日期/统计 |

气象站九类读数只留在地面监测站内。

## 三、卫星页长什么样

不做五个 pill。页面是 **左主图 + 右信息栏**。

```text
┌ 卫星遥感监测 · 区域灾害专题图          全屏看图 · 简报 · 详情 ┐
├──────────────────────────┬──────────────────────────────────┤
│                          │ 干旱  高温                       │
│   docs/出图 竖版专题图    │ 暴雨  大风                        │
│   （按框内最大完整显示）   │ 日期 ▼                           │
│                          │                                  │
│                          │ 大风专题 65 期 · 最新 2025-08-16  │
│                          │ [⚠ 极端天气预警]  （按钮，跳预警） │
│                          │ AI 智能分析                       │
└──────────────────────────┴──────────────────────────────────┘
```

- 顶栏四个字是**出图产品**（干旱/高温/暴雨/大风），不是能力分类。类型与日期在右栏。  
- 「全屏看图」用 `ZoomableImage`（滚轮缩放、拖拽），弹窗底为站点深绿。  
- 统计口径是**专题期数**（单日图张数，不含 1–8 月汇总），不要写成「共 N 天有图」。  
- 预警是橙色描边按钮，不是小标签。  
- 窄屏（`width <= 992px`）改为上图下栏。

### 3.1 两类图，两种看法

| 类型 | 例子 | 怎么显示 |
|------|------|----------|
| 成品专题图 | `docs/出图/` 竖版 JPG | **左栏主图**。原比例完整显示，不叠进 Leaflet |
| 可叠加栅格 | 原 GIS 墒情 `moistureLayers` | 不再作为卫星页主画面；无人机 Tab 仍用 NDVI 地图 |

### 3.2 默认态

进入卫星遥感：默认灾害类型为大风，日期为该类型最近一期单日图。无图时左栏空状态。日期下拉只列出有文件的日期（另加「1–8 月汇总」若存在）。

## 四、按时间段调专题图

数据来源：`docs/出图/`（备份 `docs/出图 (2)/`）。按灾害分子目录。`docs/出图/总/` 四张为 1–8 月汇总，与单日图分开。

开发时 **不把约 900MB JPG 拷进 `public/`**。Vite 把 `/satellite-maps/` 映射到 `docs/出图/`。清单是 [`public/satellite/catalog.json`](../../../../public/satellite/catalog.json)，由 [`scripts/build-satellite-catalog.ts`](../../../../scripts/build-satellite-catalog.ts) 扫描生成。前端 `fetch('/satellite/catalog.json')`，**不要** `import` 大图进打包。

文件名规则（年份按 2025）：`1.5.jpg` → `2025-01-05`；`高温7.08.jpg`；`2025-06-03 高温.jpg`；`xindafeng.jpg` 为汇总；`mmexport*` 忽略。

交互：

1. 选灾害类型 → 下拉只出现该类型有文件的日期。  
2. 点日期 → 左栏换成该日 JPG；「全屏看图」放大同一张。  
3. 无文件的日期不出现在下拉里。  
4. 右栏：`{类型}专题 N 期 · 最新 YYYY-MM-DD`；按钮跳 `/warnings`。AI 文案用「收录 N 期」，不要「有图 / 一张」。

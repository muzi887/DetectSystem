## 一、为什么要做简单版

完整清单（NDVI、土地利用、作物类型、病虫害、气象灾害 + GIS）若全部做成卫星页上的并列入口，比现在四个 Tab 更重，空按钮也没有图层可接。

网上「一张图」平台用的是**一张地图换图层**，不是五个栏目平铺。本系统已有分工，不必再在卫星页重复：

| 内容 | 放哪 | 说明 |
|------|------|------|
| 土壤折线、气象站读数 | 地面监测站 | 「查看气象数据」已能切到气象版块 |
| 地块 NDVI、航迹、历史对比 | 无人机遥感 | 地块尺度，不进卫星页 |
| 病虫害识别与草稿 | 智能分析 / 灾害预警 | 已有流程 |
| 土地利用、作物类型 | **不做入口** | 暂无稳定图层 |
| 区域墒情热力、点选查墒 | 已取消独立 GIS Tab | 不作为卫星页主画面 |
| 干旱/高温/暴雨/大风空间分布 | **卫星遥感** | 出图按日调取，左图右栏 |

## 三、卫星页长什么样

不做五个 pill。页面是 **左主图 + 右信息栏**。

```text
┌ 卫星遥感 (天)                     全屏看图 · 简报 · 详情 ┐
├──────────────────────────┬─────────────────────────────┤
│                          │ 干旱  高温                  │
│                          │ 暴雨  大风                   │
│   docs/出图 竖版专题图    │ 日期 2025-08-03 ▼            │
│   （按框内最大完整显示）   │ 有图 65 天 · 最近 2025-08-16 │
│                          │ [极端天气预警]               │
│                          │ AI 智能分析                  │
└──────────────────────────┴─────────────────────────────┘
```

顶栏四个字是**出图产品**（干旱/高温/暴雨/大风），不是能力分类。同一时刻只显示一类出图的日期，避免多层抢色。类型与日期放在右栏，避免挤在标题行。

窄屏（`width <= 992px`）改为上图下栏。

### 3.1 两类图，两种看法

| 类型 | 例子 | 怎么显示 |
|------|------|----------|
| 成品专题图 | `docs/出图/` 竖版 JPG（自带标题、图例、比例尺） | **左栏主图**。按原比例完整显示，不叠进 Leaflet。点「全屏看图」弹窗放大 |
| 可叠加栅格 | 原 GIS 墒情 `moistureLayers` | 不再作为卫星页主画面；无人机 Tab 仍用 NDVI 地图 |

出图没有贴图坐标，硬塞进 Leaflet 会变形、图例看不清。左栏收窄后更接近竖图比例，减少左右留白。

### 3.2 默认态

进入卫星遥感：默认灾害类型为大风，日期为该类型最近有图日。无图时左栏空状态，不弹空白大图。有图的日期在下拉里可点；点「全屏看图」打开同一张 JPG。

## 四、按时间段调专题图

数据来源：`docs/出图/`（及 `docs/出图 (2)/` 备份）。按灾害分子目录，文件名带月日（如大风 `1.5.jpg` → 2025-01-05；高温 `2025-06-03 高温.jpg` 等）。`docs/出图/总/` 四张为 1–8 月汇总，时间轴上可单独一项「1–8 月汇总」，不要和单日图混成同一天。

交互：

1. 选灾害类型 → 时间轴只点亮该类型有文件的日期。  
2. 点日期 → 左栏换成该日 JPG；点「全屏看图」放大同一张。  
3. 无图日期不可点，或灰显。  
4. 统计极端天气（轻量）：当前类型「有图天数」、最近一张图日期；橙色标签可跳 `/warnings`（复用已有极端天气预警，不在本页新做一张大表）。右栏展示这些摘要。

出图文件放到 `public/satellite/`（或按类型分子目录），前端用静态路径读取，**不要** `import` 进打包。清单可用一份小 JSON（类型、日期、文件名），不必改后端。

- 地面监测站的气象按钮、无人机 NDVI 行为与现在一致。

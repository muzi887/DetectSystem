## 一、为什么要做简单版

完整清单（NDVI、土地利用、作物类型、病虫害、气象灾害 + GIS）若全部做成卫星页上的并列入口，比现在四个 Tab 更重，空按钮也没有图层可接。

网上「一张图」平台用的是**一张地图换图层**，不是五个栏目平铺。本系统已有分工，不必再在卫星页重复：

| 内容 | 放哪 | 说明 |
|------|------|------|
| 土壤折线、气象站读数 | 地面监测站 | 「查看气象数据」已能切到气象版块 |
| 地块 NDVI、航迹、历史对比 | 无人机遥感 | 地块尺度，不进卫星页 |
| 病虫害识别与草稿 | 智能分析 / 灾害预警 | 已有流程 |
| 土地利用、作物类型 | **不做入口** | 暂无稳定图层 |
| 区域墒情热力、点选查墒 | **并入卫星遥感** | 取消独立 GIS Tab |
| 干旱/高温/暴雨/大风空间分布 | **卫星遥感** | 出图按日调取 |

## 三、卫星页长什么样

不做五个 pill。页面只有 **一张图 + 一条底栏**。

```text
┌ 卫星遥感 (天) ─────────────────────────────────────────┐
│ 干旱 | 高温 | 暴雨 | 大风     日期 2025-01-05 ▼   全屏看图 │
├──────────────────────────────────────────────────────────┤
│                                                          │
│   Leaflet 全幅：墒情热力 + 监测点 + 点击查墒（原 GIS）     │
│   图例、来源、影像日期仍贴在图角                           │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 时间轴：只高亮「当前灾害类型有出图」的日期                  │
│ 摘要：本类型本月有图天数 · 可跳转灾害预警                   │
└──────────────────────────────────────────────────────────┘
```

顶栏四个字是**出图产品**（干旱/高温/暴雨/大风），不是能力分类。同一时刻只显示一类出图的日期轴，避免多层抢色。

### 3.1 两类图，两种看法

| 类型 | 例子 | 怎么显示 |
|------|------|----------|
| 可叠加栅格 | 现有 GIS 墒情 `moistureLayers` | 继续铺在 Leaflet 上，可缩放、点选查墒 |
| 成品专题图 | `docs/出图/` 竖版 JPG（自带标题、图例、比例尺） | **不要缩进主卡**。日期选中后点「全屏看图」铺满视口，Esc 关闭 |

出图没有贴图坐标，硬塞进 Leaflet 会变形、图例看不清。全屏查看器就是为这个准备的。

### 3.2 默认态

进入卫星遥感：底图 = 现在的 GIS 墒情 + 监测点。未选日期或该日无出图时，只看底图，不弹空图。有出图的日期在时间轴上可点；点「全屏看图」才打开 JPG。

## 四、按时间段调专题图

数据来源：`docs/出图/`（及 `docs/出图 (2)/` 备份）。按灾害分子目录，文件名带月日（如大风 `1.5.jpg` → 2025-01-05；高温 `2025-06-03 高温.jpg` 等）。`docs/出图/总/` 四张为 1–8 月汇总，时间轴上可单独一项「1–8 月汇总」，不要和单日图混成同一天。

交互：

1. 选灾害类型 → 时间轴只点亮该类型有文件的日期。  
2. 点日期 → 记录当前专题，底图仍为 GIS；点「全屏看图」打开该日 JPG。  
3. 无图日期不可点，或灰显。  
4. 统计极端天气（轻量）：当前类型「有图天数」、最近一张图日期；橙色标签可跳 `/warnings`（复用已有极端天气预警，不在本页新做一张大表）。

出图文件放到 `public/satellite/`（或按类型分子目录），前端用静态路径读取，**不要** `import` 进打包。清单可用一份小 JSON（类型、日期、文件名），不必改后端。

## 七、验收

- 相关数据只有地 / 空 / 天三个按钮，无 GIS Tab。  
- 进卫星遥感能看到原 GIS 墒情图，点图仍能查最近站墒情。  
- 切「大风」能看到有图日期；选 2025-01-05 全屏能看到对应空间分布图。  
- 无图日期不会打开空白大图。  
- 地面监测站的气象按钮、无人机 NDVI 行为与现在一致。

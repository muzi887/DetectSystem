# 首页 · 近期识别独立底栏布局

> 方案 **B**（已选定）：「近期识别」从预警右栏拆出，做成欢迎条下方的独立全宽卡片。  
> **页面**：`/home` · `src/views/user/Home.vue`  
> **状态**：✅ 已实施（2026-08-22）

---

## 一、要解决什么问题

| 现象 | 原因 |
|------|------|
| 「近期识别」看起来像半截功能 | 嵌在右栏「最新预警动态」**同一个** `recent-alerts` 里，预警占满高度后只剩一个空托盘 |
| 空托盘没有下一步 | Flask `GET /api/analysis/recent` 未开或失败时静默 `[]`，空状态只有 Ant 空图标，没有说明、没有去智能分析的入口 |
| 左栏大片留白 | 核心指标只有 3 张矮卡；右栏硬塞两份列表，视觉重心全在右侧 |
| 有数据时条目也不完整 | 只渲染 `label · 置信度`，记录里已有的 `cropType` / `level` / `pointId` 没用上，也不能点进智能分析 |

**约束**：

- 不改 Flask 识病接口、不改 `analysis_records.json` 结构
- Flask 未开时仍不挡首页，**不编造**识别记录
- 预警列表仍每页 3 条 + 底部分页（与智慧决策左栏同一套手法）
- 玻璃拟态：深绿半透明、细白边、白字；空状态用现有 `GlassEmpty`

---

## 二、方案选型

| 方案 | 说明 | 结论 |
|------|------|------|
| A. 右栏对半切开 | 预警 / 识别各占右栏 50% 高度 | 不采用。右栏仍窄，识别 3 条标题会被裁；空状态更难看 |
| **B. 识别独立底栏** | 上：欢迎；中：左指标 / 右预警；下：全宽「近期识别」 | **★ 推荐** |
| C. 左指标+识别、右预警 | 识别塞进左栏指标下方 | 不采用。指标卡被压矮，识别仍挤在窄列 |

窄屏（`width <= 992px`）：上→下为 **欢迎 → 核心指标 → 最新预警 → 近期识别**。

## 三、定稿结构

```text
┌ 首页 dashboard-container ─────────────────────────────────┐
│ 欢迎（grid-column 1 / 3）                                  │
│ 快捷：实时监测 / 处理预警 / 智能分析                         │
│ ┌ 核心指标概览 2fr ──────┐  ┌ 最新预警动态 1fr ──────────┐ │
│ │ 监测点总数 / 待处理    │  │ 3 条 + 分页（不变）         │ │
│ │ / 系统状态             │  │ 标题可点进 /warnings        │ │
│ └────────────────────────┘  └────────────────────────────┘ │
│ ┌ 近期识别（grid-column 1 / 3）──────────────────────────┐ │
│ │ 有数据：横排最多 3 张识别卡                              │ │
│ │ 无数据：说明 +「去智能分析」                             │ │
│ └────────────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────┘
```

**DOM 骨架**（欢迎、指标、预警列表逻辑不动，只拆识别）：

```vue
<div class="dashboard-container">
  <div class="glass-panel welcome">...</div>

  <div class="glass-panel stats">...</div>

  <div class="glass-panel recent-alerts">
    <!-- 只保留最新预警动态 + 分页 -->
  </div>

  <div class="glass-panel recent-analyses">
    <div class="recent-analyses-head">
      <h3>近期识别</h3>
      <router-link to="/analysis" class="recent-analyses-more">去智能分析</router-link>
    </div>
    <div v-if="pagedAnalyses.length" class="analysis-card-grid">
      <router-link
        v-for="item in pagedAnalyses"
        :key="item.id ?? item.createdAt"
        to="/analysis"
        class="analysis-card">
        <span class="analysis-card-label">{{ item.label }}</span>
        <span class="analysis-card-meta">
          {{ cropLabel(item.cropType) }} · {{ formatConfidence(item.confidence) }}
        </span>
        <span class="analysis-card-time">{{ formatAnalysisTime(item.createdAt) }}</span>
      </router-link>
    </div>
    <div v-else class="analysis-empty">
      <GlassEmpty description="暂无识别记录。启动识病服务并在智能分析页上传叶片后，最近结果会显示在这里。" />
      <router-link to="/analysis" class="quick-btn">去智能分析</router-link>
    </div>
    <a-pagination
      v-if="showAnalysisPagination"
      v-model:current="analysisPage"
      class="home-list-pagination"
      :total="recentAnalyses.length"
      :page-size="HOME_ANALYSIS_PAGE_SIZE"
      size="small"
      :show-size-changer="false" />
  </div>
</div>
```

**布局 CSS 要点**：

```css

  display: grid;
  grid-template-columns: 2fr 1fr;
  grid-template-rows: auto minmax(0, 1fr) auto;

.welcome { grid-column: 1 / 3; }
.stats { grid-column: 1 / 2; }
.recent-alerts { grid-column: 2 / 3; } /* 不再 overflow 裁切识别 */

  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));

}
```

`HOME_ANALYSIS_PAGE_SIZE` 仍为 **3**（一屏三张卡）。`fetchAnalysisRecent(5)` 改为 `fetchAnalysisRecent(6)`，正好两页。

## 四、卡片字段与空状态

接口记录（`append_record`）已有：`id`、`label`、`confidence`、`cropType`、`level`、`pointId`、`createdAt`。首页目前只用了前三项。

| 展示 | 取值 |
|------|------|
| 主标题 | `label`（病名 / 健康） |
| 副行 | 作物中文名 + 置信度百分比 |
| 时间 | `createdAt`（沿用 `formatTime`） |
| 整卡点击 | `router-link` → `/analysis` |

作物码转中文（只在首页用，不抽公共表除非已有）：

| `cropType` | 文案 |
|------------|------|
| `wheat` | 小麦 |
| `corn` | 玉米 |
| `tomato` | 番茄 |
| `rice` | 水稻 |
| 其它 / 空 | 作物未标注 |

空状态文案必须同时覆盖两种真实情况：还没上传过、以及 Flask:5000 未启动。不假装有历史记录。

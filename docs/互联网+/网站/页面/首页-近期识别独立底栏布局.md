# 首页 · 近期识别独立底栏布局

> 方案 **C**（已选定）：欢迎条下方两列。左栏 **上核心指标、下近期识别**；右栏 **最新预警** 拉满左栏两块的总高度。左右等宽。  
> **页面**：`/home` · `src/views/user/Home.vue`  
> **状态**：✅ 已实施（2026-08-22）

---

## 一、要解决什么问题

| 现象 | 原因 |
|------|------|
| 「近期识别」看起来像半截功能 | 曾嵌在右栏「最新预警动态」同一张卡里 |
| 方案 B：预警偏窄 | 中行 `2fr` 指标 / `1fr` 预警，识别全宽垫底 |
| 方案 D：三列并排 | 把「指标 + 识别」理解成左右相加；实际应是 **上下叠放** |

**约束**：

- 不改 Flask 识病接口、不编造识别记录
- 预警仍每页 3 条 + 底部分页
- 玻璃拟态；空状态用 `GlassEmpty` +「去智能分析」

---

## 二、方案选型

| 方案 | 说明 | 结论 |
|------|------|------|
| A. 右栏对半切开 | 预警 / 识别挤在 1fr 右栏 | 不采用 |
| B. 识别独立底栏 | 中行 `2fr` 指标 / `1fr` 预警；底栏识别全宽 | 预警偏窄 |
| **C. 左叠指标+识别、右预警** | 左右各 `1fr`；预警行跨左栏两行 | **★ 采用** |
| D. 三列 1fr + 1fr + 2fr | 指标、识别、预警横排 | 关系错了：识别应在指标下方 |

窄屏（`width <= 992px`）：上→下为 **欢迎 → 核心指标 → 近期识别 → 最新预警**。

## 三、定稿结构（方案 C）

```text
┌ 首页 dashboard-container（两列 1fr 1fr）─────────────────┐
│ 欢迎（grid-column 1 / 3）                                 │
│ ┌ 核心指标 ─────────────┐ ┌ 最新预警（跨两行）──────────┐ │
│ │ 3 张指标卡（横排）     │ │ 3 条 + 分页                 │ │
│ └───────────────────────┘ │ 标题进 /warnings            │ │
│ ┌ 近期识别 ─────────────┐ │                             │ │
│ │ 竖排最多 3 张识别卡 / 空│ │                             │ │
│ └───────────────────────┘ └─────────────────────────────┘ │
└───────────────────────────────────────────────────────────┘
```

**宽度关系**：左右各半。左栏两块上下叠，右栏预警高度 = 核心指标 + 近期识别。长文案不得撑破格子（`minmax(0, 1fr)` + 面板 `min-width: 0`）。

**DOM 顺序**（窄屏按此堆叠）：欢迎 → 核心指标 → 近期识别 → 最新预警。桌面用 `grid-row` 把预警放到右侧跨行。

**布局 CSS 要点**：

```css
.dashboard-container {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(0, 1fr);
  grid-template-rows: auto auto minmax(0, 1fr);
  gap: 24px;
}
.welcome { grid-column: 1 / 3; grid-row: 1; }
.stats { grid-column: 1; grid-row: 2; }
.recent-analyses { grid-column: 1; grid-row: 3; }
.recent-alerts { grid-column: 2; grid-row: 2 / 4; }
.stat-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
.analysis-card-grid { grid-template-columns: 1fr; }
```

`HOME_ANALYSIS_PAGE_SIZE` 仍为 **3**。`fetchAnalysisRecent(6)` 不变。

## 四、卡片字段与空状态

接口记录（`append_record`）已有：`id`、`label`、`confidence`、`cropType`、`level`、`pointId`、`createdAt`。首页目前只用了前三项。

| 展示 | 取值 |
|------|------|
| 主标题 | `label`（病名 / 健康） |
| 副行 | 作物中文名 + 置信度百分比 |
| 时间 | `createdAt`（沿用 `formatTime`） |
| 整卡点击 | `router-link` → `/analysis` |

作物码转中文（只在首页用，不抽公共表除非已有）：

| `cropType` | 文案 |
|------------|------|
| `wheat` | 小麦 |
| `corn` | 玉米 |
| `tomato` | 番茄 |
| `rice` | 水稻 |
| 其它 / 空 | 作物未标注 |

空状态文案必须同时覆盖两种真实情况：还没上传过、以及 Flask:5000 未启动。不假装有历史记录。

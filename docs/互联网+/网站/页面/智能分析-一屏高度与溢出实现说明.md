## 一、要解决什么问题

截图里浏览器 **最右侧那条白滚动条** 是 **整页** 在滚，不是卡片内部。

| 现象 | 原因 |
|------|------|
| 视口右侧出现滚动条 | `AppLayout` `.content-slot { overflow-y: auto }`；子页再套 `page-main-shell--scroll` |
| 卡片比一屏高 | 上传区 **250×250** + 右侧四颗 **48px** 类别按钮 + 作物行 + 补充 + 「确定」+ 批量行 + 底下结果区 |
| 有结果后更长 | `TreatmentGuidePanel` 把概述/症状/化学/生物/农艺全部平铺 |

智慧决策已经用 `page-main-shell--fill` + 列内 `overflow: hidden`，**页面级不滚**。分析页还停在小挑时期的「表单在上、结果在下、整页往下翻」。

**设计原则**（与决策页溢出说明一致）：

- 桌面 **一屏填满**，不要整页滚动条
- 长内容用 **折叠分段**（防治 = 决策页 R1），不用无限长平铺
- 窄屏才允许整页滚（决策页 ≤992px 同样放开）

分析页 **没有** 待办长列表，因此 **不套** 决策页左栏 L1 分页；那是队列溢出的办法，这里用不上。

## 三、高度链（V1.3 两列）

```text
.app-shell (100vh)
  └─ .content-slot (flex:1; min-height:0; overflow-y: auto 仍在，但子项不再撑破)
       └─ .page-main-shell--fill.analysis-page-root
            └─ .content-wrapper.page-card-fill.analysis-page-fill
                 └─ a-card（高 100%，body 纵向 flex）
                      └─ .analysis-dashboard（两列 1:1 Grid，flex:1; min-height:0）
                           ├─ 左 · 分析参数
                           │     ├─ .input-main（预览 | 表单，同高）
                           │     └─ .batch-row（贴底）
                           └─ 右 · 分析结果 + Collapse（1fr）
```

预览弹窗不在此树内，不影响 `--fill`。

由 `--scroll` 改为 `--fill`，与决策页相同。子项 `min-height: 0` 后，`.content-slot` 虽然仍是 `overflow-y: auto`，**没有多余高度就不会画出右侧条**。

窄屏（`width <= 992px`）：与决策页一样，`--fill` 改为可滚（输入 + 结果纵向排不下时才出现滚动条）。

## 四、输入区怎么变矮

| 原状 | 第一刀 |
|------|--------|
| 类别四颗竖排 48px + 间距 16px（约 240px 高） | **一行四等分**，高 36px |
| 上传 250×250 | **160×160** |
| 「识别」与「确定」两套主操作 | 仍保留（不改推理逻辑）；「确定」改为默认高度，不再 `size="large"` |
| 批量行掉出卡片底 | 收进输入区最后一行，随输入区 `flex-shrink: 0` |

类别文案不变：灾害识别 / 病虫害识别 / 气候灾害识别 / 其他。

## 五、结果区溢出 = R1 Collapse

有分析结果且命中知识库时，**不再**平铺 `TreatmentGuidePanel`。

与决策页右栏相同：

```text
buildTreatmentPanels(getTreatment(病名))
  → a-collapse（默认展开化学防治，否则概述）
```

| 条件 | 页面滚动条 | 结果区内滚动条 |
|------|------------|----------------|
| 未分析 | 无 | 无（空态居中） |
| 分析中 | 无 | 无 |
| 有结果 + Collapse | 无 | **无**（只展开一节；多开时超出部分裁在结果区内，与决策页右栏相同） |

默认展开规则与 [`智慧决策-左栏分页与溢出实现说明.md`](./智慧决策-左栏分页与溢出实现说明.md) §4.2 一致。

非健康结果底栏：保留「前往预警列表」，并加 **前往智慧决策**（答辩动线）。

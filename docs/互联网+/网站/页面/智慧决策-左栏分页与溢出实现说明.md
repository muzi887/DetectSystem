# 智慧决策页 · 左栏分页与溢出实现说明

> 自 [`智慧决策页面重构方案.md`](./智慧决策页面重构方案.md) 拆出的专项说明：左、右栏 **列内溢出** 的问题背景、方案选型与代码实现。  
> **页面**：`/decision` · `src/views/user/DecisionSupport.vue`  
> **状态**：✅ 已实施（2026-07-12）

---

## 一、要解决什么问题

| 阶段 | 现象 | 原因 |
|------|------|------|
| V2.1 | 左栏 `overflow-y: auto`，Windows 下滚动条占宽、不美观 | 待办条数随 Mock/联调增多，列表在固定高度内滚动 |
| V2.2 初版 | 改用 `a-list` 内置 `:pagination`，但 **>6 条仍看不到分页器** | 分页栏渲染在列表底部，被卡片 `overflow: hidden` **裁切** |
| V2.2 定稿 | 手动分页 + 独立 `a-pagination`，**去掉列表区滚动条** | 分页器 `flex-shrink: 0` 固定在左栏底部，始终可见 |

**设计原则**（对齐 ThingsBoard / JetLinks / 预警中心）：

- 窄侧栏 **不用无限长列表 + 原生粗滚动条**
- 用 **分页**（左栏）或 **折叠分段**（右栏）消化溢出
- 一屏三列布局不变，**页面级不滚动**

## 二、方案选型

### 2.1 左栏：L1 分页 + L2 级别筛选

| 方案 | 说明 | 结论 |
|------|------|------|
| **L1 分页** | 每页 6 条，>6 条显示底部分页器 | **★ 采用** |
| **L2 级别 Tab** | `全部 / 高 / 中 / 低`，减少单页条数 | **★ 采用**（与 L1 组合） |
| L3 虚拟列表 | 仅渲染可视区 DOM | 不采用。答辩场景条数有限，实现成本高 |
| L4 细滚动条 | 自定义滚动条样式 | 不采用。已有 L1，无需过渡方案 |
| L5 仅 Top N | 只展示最新 N 条 | 不采用。削弱决策页完整待办能力 |

**L2 级别映射**（`src/utils/alertLevel.ts`）：

| Tab | 包含 `level` |
|-----|----------------|
| 全部 | 所有待处理 |
| 高 | `critical`、`high`、`warning` |
| 中 | `medium` |
| 低 | `low` |

### 2.2 右栏：R1 知识库 Collapse

| 方案 | 说明 | 结论 |
|------|------|------|
| **R1 知识库 Collapse** | 按知识库字段分段折叠，默认展开「化学防治 + 联动处置建议」 | **★ 采用** |
| R2 列内滚动 | `overflow-y: auto` 平铺列表 | 不采用。与「无列内滚动条」目标冲突 |
| R3 Tab 切换 | 按防治类型分 Tab | 不采用。一次只能看一类，不如 Collapse 可并排展开 |
| R4 摘要 + 弹窗 | 右栏只显示摘要，详情 Modal | 不采用。增加点击层级，答辩演示不直观 |
| R5 截断 +「展开更多」 | 固定高度截断文案 | 不采用。导出与阅读体验差 |

右栏定稿：**无列内滚动条**；内容过长时通过 Collapse 按需展开。

### 2.3 方案演进时间线

| 版本 | 左栏溢出 | 右栏溢出 |
|------|----------|----------|
| V2.1 | 列内 `overflow-y: auto` + 折叠按钮 | `a-list` 平铺 + body 滚动 |
| V2.2a | `a-list` 内置分页（分页器被裁切，废弃） | `a-collapse` 分段 |
| V2.2b | **手动 slice + 独立 `a-pagination`，无滚动条** | 同 V2.2a |

## 三、左栏实现（L1 + L2）

### 3.1 数据流

```text
dataStore.unhandledAlerts
    → unhandledAlerts（合并监测点、按 time 降序）
    → filteredAlerts（级别 Tab 筛选）
    → pagedAlerts（当前页 slice，每页 6 条）
    → a-list :data-source="pagedAlerts"
```

### 3.2 核心常量与计算属性

```typescript
const ALERT_PAGE_SIZE = 6

const levelFilter = ref<'all' | 'high' | 'medium' | 'low'>('all')
const alertPage = ref(1)

const filteredAlerts = computed(() =>
  unhandledAlerts.value.filter((alert) => matchesLevelFilter(alert.level, levelFilter.value))
)

const showAlertPagination = computed(() => filteredAlerts.value.length > ALERT_PAGE_SIZE)

const pagedAlerts = computed(() => {
  const start = (alertPage.value - 1) * ALERT_PAGE_SIZE
  return filteredAlerts.value.slice(start, start + ALERT_PAGE_SIZE)
})
```

**显示规则**：

| 条件 | 分页器 | 列表滚动条 |
|------|--------|------------|
| 筛选结果 ≤ 6 条 | 隐藏 | 无 |
| 筛选结果 > 6 条 | 显示（如 10 条 → 2 页） | 无 |

等价于原方案中的 `hideOnSinglePage: true`，但通过 `v-if="showAlertPagination"` 显式控制。

### 3.3 模板结构（为何不用 `a-list` 内置分页）

初版使用：

```vue
<a-list :pagination="{ pageSize: 6, hideOnSinglePage: true }" />
```

在 **flex + `overflow: hidden` 一屏布局** 下，Ant Design Vue 把分页器插在列表 DOM 底部，常被裁切不可见（见 §一 V2.2 初版）。

**定稿结构**：

```vue
<div class="alert-list-body">
  <!-- L2：级别筛选 -->
  <div class="level-filter">...</div>

  <!-- L1：仅渲染当前页，关闭内置分页 -->
  <a-list :data-source="pagedAlerts" :pagination="false" />

  <!-- 独立分页器，不参与列表 overflow -->
  <a-pagination
    v-if="showAlertPagination"
    v-model:current="alertPage"
    :total="filteredAlerts.length"
    :page-size="ALERT_PAGE_SIZE"
    size="small"
    :show-size-changer="false" />
</div>
```

### 3.4 布局 CSS（分页器不被裁切）

```css
.alert-list-body {
  flex: 1;
  min-height: 0;
  display: flex;
  flex-direction: column;
  overflow: hidden;
}

.level-filter {
  flex-shrink: 0;
}

.decision-alert-list {
  flex: 1;
  min-height: 0;
  overflow: hidden;   /* 无滚动条 */
}

.alert-list-pagination {
  flex-shrink: 0;
  margin-top: auto;     /* 贴左栏底部 */
  display: flex;
  justify-content: center;
}
```

分页器样式与 [`WarningSystem.vue`](../../../../src/views/user/WarningSystem.vue) 预警列表分页一致（深色玻璃主题）。

### 3.5 交互联动

| 事件 | 行为 |
|------|------|
| 切换级别 Tab | `alertPage = 1`；`syncDefaultSelection()` 若当前选中不在筛选结果内则改选第一条 |
| 筛选后条数变少 | `watch(filteredAlerts)` 将 `alertPage` 限制在合法页码内 |
| 点击列表项 | 更新 `selectedArea`，中/右列联动；**不强制跳页**（选中项可在其他页，切页后仍高亮） |
| 左栏折叠 | 仅隐藏 body，选中态与中/右列保留 |

## 四、右栏实现（R1 Collapse · 无滚动）

### 4.1 结构

```vue
<a-collapse v-model:activeKey="activeCollapseKeys">
  <a-collapse-panel v-for="panel in suggestionCollapsePanels" :key="panel.key" :header="panel.title">
    <ul>...</ul>
  </a-collapse-panel>
</a-collapse>
```

`suggestionCollapsePanels` 来源：

1. **知识库**：`buildTreatmentPanels(getTreatment(病名))` → 病害概述、典型症状、化学/生物/农艺防治、适期、安全提示  
2. **规则引擎**：`buildRuleSuggestions(area)` → 单独一节「联动处置建议」

实现见 `src/composables/useTreatmentGuide.ts` 中 `buildTreatmentPanels` / `flattenTreatmentPanels`。

### 4.2 默认展开

```typescript
function resolveDefaultCollapseKeys(panels: TreatmentPanel[]): string[] {
  const keys: string[] = []
  if (panels.some((p) => p.key === 'linkage')) keys.push('linkage')
  if (panels.some((p) => p.key === 'chemical')) keys.push('chemical')
  else if (panels.some((p) => p.key === 'summary')) keys.push('summary')
  return keys.length ? keys : panels.slice(0, 1).map((p) => p.key)
}
```

切换选中预警时，`watch(suggestionCollapsePanels)` 重置展开项。

### 4.3 样式

```css
.suggestion-panel :deep(.ant-card-body) {
  overflow: hidden;   /* 右栏 body 不滚动 */
}
```

## 五、验收清单

- [ ] 全部 **10 条**：列表 **6 条**，底部 **分页 1/2** 可见可点  
- [ ] 全部 **≤6 条**：**无**分页器，**无**滚动条  
- [ ] 筛选「高 **5**」：仅 5 条，无分页器

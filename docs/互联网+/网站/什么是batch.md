# 什么是 batch（批量分析）

> 说明智能分析里「一次多张图」是什么、和单张有何不同。  
> 路由字段、前端按钮、pytest 见 [`新模型训后-P3-规则链与工程化实施计划.md`](./新模型训后-P3-规则链与工程化实施计划.md) Task 3，本文不重复。

---

## 一、一句话

**batch** 在这里就是 **批量**：一次请求里带上多张叶子照片，服务端逐张识别，一次返回多份结果。英语 batch 本意是「一批」，和「单张上传」相对。

P0–P2 的接口是 `POST /api/analysis/image`，一次一张。P3 增加 `POST /api/analysis/batch`，一次多张。

---

## 二、为什么要单独做一批

田里拍一趟往往不止一张。若只能单张，用户要点很多次上传。批量把「同一作物、同一套环境字段」套在多张图上，少点几次。

每张图内部仍走原来的路：推理 → softmax → 作物掩码 → topk / 复核。批量 **不换模型**，只是循环调用同一套单张逻辑。

```text
单张：  选作物 → 选 1 张图 → 得到 1 条病名
批量：  选作物 → 选 n 张图 → 得到 n 条结果（列表）
```

---

## 三、和单张的差别（概念上）

| | 单张 | 批量 |
|--|------|------|
| 请求里的图 | 一张 | 多张（字段名约定为 `files`） |
| 作物 / 温湿墒 | 带一份 | **共用** 这一份，不每张各填一套 |
| 某一张坏了 | 整次失败（常见） | 计划里：这一张记错误，其余仍返回；HTTP 仍可 200 |
| 页面 | 已有上传 | 只加「多选文件」最小入口，不改三列大布局 |

没有文件时仍应拒绝（400）。YAGNI：不做结果画廊，提示「完成 n 张」并展示第一张即可。

---

## 四、它不是什么

- 不是「把多张图拼成一张再识别」。
- 不是训练时的 batch（训练里 batch 指一次喂给模型多少张，用来算梯度）。两边都叫 batch，这里只指 **接口一次收多张用户照片**。
- 不是规则链、也不是 ONNX。那是 P3 另外两件事。

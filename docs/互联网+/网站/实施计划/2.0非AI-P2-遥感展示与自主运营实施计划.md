# 2.0 非 AI · P2 遥感展示与自主运营 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 高风险地块在 NDVI 图上描边并提示地面复核；决策页列出虫情 `factors`；顶栏通知铃铛；相关数据「生成简报」改为可下载的真文本；无人机 Tab 画一条演示航迹。链 3 草稿发布已有，不重做规则。

**Architecture:** 虫情展示读已有 `pestRiskPredictions`（含 `factors`/`window`/`riskLevel`/`fieldId`）。通知在 `runAllChains` **新写入** `alerts` 时各插一条 `notifications`。日报是纯函数拼 Markdown，`GET /reports/daily` 返回 `{ markdown }`，前端 Blob 下载 `.txt`。航迹用 `droneMissions` 折线叠在 `RemoteSensingMap`（仅 NDVI 模式）。

**Tech Stack:** Vue 3、Leaflet rectangle/polyline、Ant Design Badge/Drawer、tsx 单测。

**Spec:** [`2.0非AI模块实现方案.md`](../方案/2.0非AI模块实现方案.md) §4.4 展示缺口、§4.5 通知与日报。前置：规则链总线已完成；P0/P1 无硬依赖（描边只需 `fields.bounds`）。

## Global Constraints

- **禁止**改 Flask / P3 / 链 3 凑分公式。
- 不要接外部推送（邮件/微信）；通知只做站内。
- 不要做格点气象插值、完整热力图。
- `deploy/api_mock` 同步：新路由 + `ruleChainRunner` 写通知；`syncKeys` 增加 `notifications`、`droneMissions`（`auditLogs` 本计划不做）。
- 简报必须是真实文件下载，禁止只 `message.success('已下载 pdf')` 而无 Blob。

### Task 2: 决策页列出虫情因子

**Files:**
- Create: `src/utils/pestFactors.ts`
- Test: `src/utils/pestFactors.test.ts`
- Modify: `src/views/user/DecisionSupport.vue`

**Interfaces:**
- Produces: `factorsFromAlert(message: string, prediction?: { factors?: string[] }): string[]`  
  优先用 prediction；否则从 `[虫情风险] ...（因子A；因子B）` 里按 `；` 切开。

- [ ] **Step 1: Tests**

```ts
import assert from 'node:assert/strict'
import { test } from 'node:test'
import { factorsFromAlert } from './pestFactors.ts'

test('uses prediction factors when present', () => {
  const out = factorsFromAlert('[虫情风险] x', { factors: ['连续 3 日湿度 > 80%', 'NDVI 低于田间均值 15%'] })
  assert.equal(out.length, 2)
})

test('parses message parentheses', () => {
  const msg = '[虫情风险] 地块 河间 - 风险等级：high（连续 3 日湿度 > 80%；NDVI 低于田间均值 15%）'
  const out = factorsFromAlert(msg)
  assert.equal(out.length, 2)
  assert.equal(out[0], '连续 3 日湿度 > 80%')
})
```

- [ ] **Step 2: 决策页**

选中预警 `message` 含 `[虫情风险]` 时，在「联动处置建议」**之上**加面板「风险因子」，`lines` 至少 1 条（高风险草稿通常 ≥4 个因子；若种子暂未 high，用解析到的列表，**不要**假造两条）。实现时：`fetchPestPredictions` 已在 remote store，决策页也可再 GET 一次按 `fieldId` 匹配。

`buildRuleSuggestions` 的虫情那条巡田建议保留。

# P3 病名环境规则链与工程化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 识别结果结合该监测点气象/墒情升降预警级别并给出一句适期建议；支持一次多图批量分析；开发机用 waitress 托管 Flask，可选导出 ONNX。

**Architecture:** 规则链做成与 Mock 现有 `evaluateDisasterRules`（**仅瞬时**气温/墒情阈值，无耐受、无落库）平行的**纯函数**（病名 × `airTemp`/`airRh`/`soilVwc`），由 Flask 在 `analyze_image` / `batch` 里调用。环境读数优先用请求里的可选字段；若带了 `pointId` 且设置了 `ML_BJJ_MOCK_ORIGIN`（默认 `http://127.0.0.1:3000`），再 GET `/weatherReadings` 按 `pointId` 匹配。生产进程：Windows/宝塔用 waitress；Linux 可用 gunicorn。ONNX 为可选加速，默认仍加载 `.pt`。

**Tech Stack:** Flask、urllib 读 Mock、waitress、onnx/onnxruntime（`requirements.txt` 已有）、pytest、Vue 仅批量上传最小改动。

**Spec:** [`新模型训后-后端丰富说明.md`](../方案/新模型训后-后端丰富说明.md) §4.3 batch、§4.4 工程化、§5.2 规则链、§七 P3。前置：P0/P1；P2 的 `pointId` 落库建议先做，但本计划规则函数不依赖 JSON 记录。

**Related:** [`规则链建模与实现方案.md`](../方案/规则链建模与实现方案.md) 的链1阈值（土壤 <15% 重旱、气温 >38℃ 高温）在本计划中**复用数字**，但输出只挂在**这一次识别结果**上。该方案中的 `[自动预警]` 环境链（耐受计时 + 写入 `alerts`）**尚未编码**，P3 **不实施、也不假装 Mock 里已有**。

## Global Constraints

- 不上 Django/Spring；不重训检测模型。
- 不改智能分析三列布局；批量只加「多选上传」最小入口。
- 规则只升降 `low|medium|high`（`critical` 映射为 `high` 以便现网 `createAlert` 仍可用），并返回 `reasons: list[str]`。
- 未知病名或环境字段缺失 → **不升降级**，`reasons` 为空。
- ONNX 默认关闭；`ML_BJJ_ONNX=1` 且存在 `pest-cls-best.onnx` 才走 onnxruntime。
- 测试：`ml-bjj\.venv\Scripts\python.exe -m pytest ml-bjj/tests -v`。

### Disease × environment rules (copy exactly)

| 条件 | 动作 |
|------|------|
| `label != 健康` 且 `airRh >= 80` 且病名为稻瘟病/稻颈瘟/小麦赤霉病 | `level` 至少 `high`；reason「高湿利于该病流行」 |
| `label != 健康` 且 `soilVwc <= 15` | `level` 至少 `medium`；reason「墒情偏低，结合旱情复核」 |
| `label != 健康` 且 `airTemp >= 38` | `level` 至少 `high`；reason「高温胁迫，建议尽快处置」 |
| `label == 健康` 且 `soilVwc <= 15` | `level` 保持识别结果（健康仍为 `low`）；reason「植株看似健康但墒情偏低」写入 `advice` 不升病害级 |
| 其余 | 保持 `classify_level` 原值 |

`advice`：有防治 `timing` 时拼一句「当前环境：{reasons 用分号连接}。{timing 首句}」；无 reasons 则 `advice` 为 `null`。

```python
from __future__ import annotations

HUMID_DISEASES = {"稻瘟病", "稻颈瘟", "小麦赤霉病"}
LEVEL_RANK = {"low": 0, "medium": 1, "high": 2}


def _bump(current: str, target: str) -> str:
    if LEVEL_RANK.get(target, 0) > LEVEL_RANK.get(current, 0):
        return target
    return current


def apply_disease_env_rules(
    label: str,
    base_level: str,
    env: dict | None,
    timing: str | None,
) -> dict:
    level = base_level if base_level in LEVEL_RANK else "medium"
    reasons: list[str] = []
    env = env or {}
    rh = env.get("airRh")
    temp = env.get("airTemp")
    vwc = env.get("soilVwc")

    if label != "健康" and rh is not None and float(rh) >= 80 and label in HUMID_DISEASES:
        level = _bump(level, "high")
        reasons.append("高湿利于该病流行")
    if label != "健康" and vwc is not None and float(vwc) <= 15:
        level = _bump(level, "medium")
        reasons.append("墒情偏低，结合旱情复核")
    if label != "健康" and temp is not None and float(temp) >= 38:
        level = _bump(level, "high")
        reasons.append("高温胁迫，建议尽快处置")

    advice = None
    extra = "植株看似健康但墒情偏低" if (label == "健康" and vwc is not None and float(vwc) <= 15) else None
    bits = list(reasons)
    if extra:
        bits.append(extra)
    if bits:
        timing_bit = (timing or "").split("。")[0]
        prefix = "当前环境：" + "；".join(bits) + "。"
        advice = prefix + (timing_bit + "。" if timing_bit else "")
    return {"level": level, "reasons": reasons, "advice": advice}
```

```python
import json
from urllib.request import urlopen

from disease_env_rules import apply_disease_env_rules
from knowledge import get_treatment_item

def parse_env_from_request() -> dict | None:
    keys = ("airTemp", "airRh", "soilVwc")
    env = {}
    for key in keys:
        raw = request.form.get(key)
        if raw not in (None, ""):
            env[key] = float(raw)
    return env or None

def fetch_point_weather(point_id: int) -> dict | None:
    origin = os.environ.get("ML_BJJ_MOCK_ORIGIN", "http://127.0.0.1:3000")
    try:
        with urlopen(f"{origin}/weatherReadings", timeout=2) as resp:
            rows = json.loads(resp.read().decode("utf-8"))
    except Exception:
        return None
    for row in rows:
        if int(row.get("pointId") or 0) == point_id:
            return {
                "airTemp": row.get("airTemp"),
                "airRh": row.get("airRh"),
                "soilVwc": row.get("soilVwc"),
            }
    return None
```

```python
from __future__ import annotations

import os

from waitress import serve

import app as serving


def run() -> None:
    serving.main.__doc__  # keep import side effects
    port = int(os.environ.get("ML_BJJ_PORT", "5000"))
    if not serving.use_mock():
        weights = serving.resolve_weights_path()
        if not weights.is_file():
            raise SystemExit(f"找不到模型权重: {weights}")
        clf = serving.get_classifier()
        meta_classes = serving.load_model_meta().get("classes") or []
        if meta_classes and list(clf.classes) != list(meta_classes):
            raise SystemExit("权重 classes 与 pest-cls-meta.json 不一致")
        if len(clf.classes) != 23:
            raise SystemExit(f"期望 23 类，实际 {len(clf.classes)}")
        print(f"[ml-bjj] waitress 就绪，{len(clf.classes)} 类")
    serve(serving.app, host="0.0.0.0", port=port, threads=4)


if __name__ == "__main__":
    run()
```

### Task 1: readings 过滤纯函数 + API + 种子

**Files:**
- Create: `src/utils/sensorReadings.ts`
- Test: `src/utils/sensorReadings.test.ts`
- Modify: `src/mock/db.json`、`src/mock/server.ts`、`deploy/api_mock/server.js`、`src/api/rules.ts`、`scripts/sync-mock-db.mjs`

**Interfaces:**
- Consumes: `{ id, pointId, recordedAt, airTemp, airRh, soilVwc, soilTemp10cm }`
- Produces: `filterReadings(rows, pointId, from?: string, to?: string)`；ISO 日期字符串比较（含当日）

- [ ] **Step 1: Write the failing tests**

```ts
import assert from 'node:assert/strict'
import { test } from 'node:test'
import { filterReadings } from './sensorReadings.ts'

const rows = [
  { id: 1, pointId: 2, recordedAt: '2026-08-19T08:00:00+08:00', airTemp: 33, airRh: 40, soilVwc: 12.1, soilTemp10cm: 30 },
  { id: 2, pointId: 2, recordedAt: '2026-08-21T08:00:00+08:00', airTemp: 35, airRh: 38, soilVwc: 12.8, soilTemp10cm: 31 },
  { id: 3, pointId: 1, recordedAt: '2026-08-21T08:00:00+08:00', airTemp: 28, airRh: 50, soilVwc: 25, soilTemp10cm: 27 }
]

test('filters by point and date range inclusive', () => {
  const out = filterReadings(rows, 2, '2026-08-20', '2026-08-21')
  assert.equal(out.length, 1)
  assert.equal(out[0].id, 2)
})

test('sorts by recordedAt', () => {
  const out = filterReadings(rows, 2)
  assert.equal(out[0].id, 1)
})
```

- [ ] **Step 2: Run to fail**

Run: `pnpm exec tsx --test src/utils/sensorReadings.test.ts`

- [ ] **Step 3: Implement `filterReadings`**

用 `recordedAt.slice(0, 10)` 与 `from`/`to`（`YYYY-MM-DD`）比较。无 `from`/`to` 则该站全部，按时间升序。

- [ ] **Step 4: 种子**

`sensorReadings`：point 1/2/3 各 7 行，日期 `2026-08-15`～`2026-08-21`（或与预报窗口对齐）。雄县 `soilVwc` 在 11.5～14.2。`id` 自增。

`monitorPoints` 京津冀 3 站加 `"online": true`，`"lastSeenAt": "2026-08-21T14:00:00+08:00"`。任选东北一站 `"online": false"`，旧的 `lastSeenAt`（例如 `2026-08-01T00:00:00+08:00`），便于灰点验收。

- [ ] **Step 5: 路由**

在 `server.use(router)` **之前**：

```ts
server.get('/field-sensors/:pointId/readings', (req: Request, res: Response) => {
  const db = readDb(res)
  if (!db) return
  const pointId = Number(req.params.pointId)
  const from = typeof req.query.from === 'string' ? req.query.from : undefined
  const to = typeof req.query.to === 'string' ? req.query.to : undefined
  const rows = Array.isArray(db.sensorReadings) ? db.sensorReadings : []
  return res.jsonp(filterReadings(rows, pointId, from, to))
})
```

`deploy/api_mock/server.js` 同样加（`require` 过滤函数：可把 `filterReadings` 再抄一份进 `ruleChainRunner.cjs` 导出，避免 CJS import `.ts`）。

`src/api/rules.ts`：

```ts
export const fetchSensorReadings = (pointId: number, from?: string, to?: string) =>
  http.get(`/field-sensors/${pointId}/readings`, { params: { from, to } })
```

`syncKeys` 增加 `'sensorReadings'`。然后 `pnpm run sync:mock-db`。

Run: `pnpm exec tsx --test src/utils/sensorReadings.test.ts`

# 项目启动说明（开发环境 · 互联网＋）

> 京津冀 v3 版本：**前端 + Mock 后端 + v3 真实 AI 推理** 三服务并行。  
> 智能分析接入见 `[阶段A-网站接入方案.md](./方案/阶段A-网站接入方案.md)`。  
> **基准日**：2026-07-09

---

## 一、服务与端口

| 服务 | 端口 | 命令 | 作用 |
|------|------|------|------|
| 前端（Vite） | **5173** | `pnpm dev` | 页面、路由 |
| Mock 后端 | **3000** | `pnpm run mock` | 登录、预警、监测点、决策等 REST |
| v3 AI 推理 | **5000** | `python ml-bjj\serving\app.py` | 智能分析页真实病害识别 |

```text
浏览器  http://127.0.0.1:5173
    │
    ├─ /api/analysis/*  ──代理──►  127.0.0.1:5000  （ml-bjj 推理）
    └─ /api/*           ──代理──►  localhost:3000  （json-server Mock）
```

**演示智能分析（真实 AI）时，三个终端都要开。** 只开前端 + Mock 时，登录/地图/预警可用，但识别接口会超时或失败。

| 项 | 要求 |

## 三、首次安装（只需一次）

### 3.1 前端依赖

在项目根目录 `DetectSystem`：

```powershell
cd D:\code2\software\vue\program\DetectSystem
pnpm install
```

### 3.2 Python 虚拟环境（AI 推理）

```powershell
cd D:\code2\software\vue\program\DetectSystem

# 创建虚拟环境（只需一次）
python -m venv ml-bjj\.venv

# 激活
ml-bjj\.venv\Scripts\Activate.ps1

# 安装依赖（含 torch、flask 等）
pip install -r ml-bjj\requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

确认权重存在：

```powershell
Test-Path ml-bjj\models\pest-cls-best.pt   # 应输出 True
```

## 四、日常启动（三终端）

在 **三个独立终端** 中分别执行（均先在项目根 `DetectSystem`）：

### 终端 1 · Mock 后端

```powershell
cd D:\code2\software\vue\program\DetectSystem
pnpm run mock
```

看到监听 **3000** 即成功。

### 终端 2 · v3 AI 推理

```powershell

```

期望输出类似：

## 五、登录与演示路径

### 5.1 登录

1. 打开 http://127.0.0.1:5173  
2. 角色选择 **农技员**（智能分析等模块需要）  
3. 手机号 / 密码可用 Mock 账号，例如：`13800000000` / `123456`

### 5.2 智能分析（真实 AI）

1. 侧边栏进入 **智能分析**（`/analysis`）  
2. 上传测试图（JPG/PNG，≤ 2MB）  
3. 作物选择：**小麦 / 玉米 / 番茄**  
4. 点击 **确定** 或 **识别**  
5. 查看病名、置信度；可到 **灾害预警** 查看 `[AI识别]` 记录

### 5.3 推荐测试图（v3 验证集）

| 文件 | 期望结果 | 置信度参考 |
|------|----------|------------|
| `ml-bjj/data/bjj_cls/val/小麦锈病/小麦锈病_00001.png` | 小麦锈病 | ≈ 87.9% |
| `ml-bjj/data/bjj_cls/val/玉米大斑病/玉米大斑病_00001.jpg` | 玉米大斑病 | ≈ 91.5% |

命令行对照（可选）：

```powershell
ml-bjj\.venv\Scripts\Activate.ps1
python ml-bjj\scripts\predict.py --image "ml-bjj\data\bjj_cls\val\小麦锈病\小麦锈病_00001.png"
```

## 七、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 智能分析报网络/超时 | 终端 2 未启动或 5000 被占用 | 启动 `app.py` 或换端口 `ML_BJJ_PORT=5001`（需同步改 vite 代理） |
| 识别结果随机、与图片无关 | 仍在用旧 `server/app.py` Mock | 改用 `python ml-bjj\serving\app.py` |
| `找不到模型权重` | 未训练或未拷贝 `pest-cls-best.pt` | 见 `docs/互联网+/模型/训练/ml-bjj训练操作手册-开发版.md` |
| 登录失败 | 终端 1 Mock 未启动 | `pnpm run mock` |
| `Activate.ps1` 无法执行 | PowerShell 策略限制 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 页面能开但 API 全挂 | 只开了终端 3 | 补开终端 1、2 |

## 八、环境变量（可选）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ML_BJJ_WEIGHTS` | `ml-bjj/models/pest-cls-best.pt` | 指定权重路径 |
| `ML_BJJ_PORT` | `5000` | 推理服务端口 |
| `ML_BJJ_USE_MOCK` | `0` | 设为 `1` 时推理服务回退 Mock（答辩降级） |
| `MOCK_PORT` | `3000` | Mock 后端端口 |

Mock 降级示例：

```powershell
$env:ML_BJJ_USE_MOCK="1"
python ml-bjj\serving\app.py
```

## 九、仅前端 + Mock（不跑 AI）

适用于改 UI、测登录/预警，**不需要** Python：

```powershell
pnpm run mock    # 终端 1
pnpm dev         # 终端 2
```

智能分析页需真实识别时，再按 **§四** 增加终端 2（推理服务）。

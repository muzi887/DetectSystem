## 一、服务与端口

| 服务 | 端口 | 命令 | 作用 |
|------|------|------|------|
| 前端（Vite） | **5173** | `pnpm dev` | 页面、路由 |
| Flask | **5000** | `python ml-bjj/serving/app.py` | 登录、预警、规则链、识病 |
| MySQL | 机内 3306 / 外网 **13306** | 云端宝塔 `detect_system` | **唯一**业务库。本机 Navicat/Flask 用 13306（与已能连的 `iotmysql` 同门）；云上 Flask 用 `127.0.0.1:3306` |

```text
浏览器  http://127.0.0.1:5173
    │
    ├─ /api/analysis/* 、 /api/treatments/*  ──►  127.0.0.1:5000（路径保留 /api）
    └─ 其余 /api 去掉前缀                   ──►  127.0.0.1:5000（/login、/alerts…）
                 Flask
                    └─ DATABASE_URL → 云端 detect_system
                       本机 Flask：@82.157.234.123:**13306**
                       云上 Flask：@127.0.0.1:**3306**
```

**两个终端：** 先设 `DATABASE_URL` 再起 Flask，然后 `pnpm dev`。不要执行 `pnpm mock`（会提示已停用）。紧急演示才用 `pnpm mock:legacy`。

## 二、前置要求

| 项 | 要求 |
|----|------|
| Node.js | 18+ |
| 包管理 | pnpm（推荐）或 npm |
| Python | 3.10+，虚拟环境 `ml-bjj\.venv` |
| MySQL | 云端宝塔库名/用户 `detect_system`；本机通过公网连这一份 |
| 环境变量 | `DATABASE_URL`（密码只放本机/服务器环境，**禁止写入 Git**） |
| 权重 | 登录/预警 **不依赖** 权重；智能分析需 **23 类** `pest-cls-best.pt`。磁盘若仍是 8 类，识图会提示未就绪，其它页面仍可用 |

宝塔：该库 → **权限** 允许你的电脑公网 IP。这台云机对外 MySQL 已映射为 **13306**（`iot_db` 能通的就是这个口），本机不要用 3306。空库需先建表并导入，见 §四。

## 八、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 登录 503「未配置数据库」 | 没设 `DATABASE_URL` | 当前终端重新 `$env:DATABASE_URL=...` 再启 Flask |
| 登录超时 / 连不上库 | `DATABASE_URL` 误用 3306，或库权限未允许你的 IP | 本机改用 **13306**；宝塔该库 → 权限加你的 IP |
| 监测点空、登录失败 | 空库还没 `alembic` / 导入 | 按 §四做一次 |
| 智能分析 503 模型未就绪 | 权重不是 23 类 | 登录仍可用；识病等 23 类权重 |
| `pnpm mock` 立刻退出 | 已停用主 Mock | 按 §五起 Flask；紧急才 `pnpm mock:legacy` |
| `Activate.ps1` 无法执行 | PowerShell 策略 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 页面能开 API 全挂 | 只开了 `pnpm dev` | 补开终端 1 Flask |
| 改了预警线上演示也变了 | 本机连的就是云库 | 导入/清空前先宝塔备份 |

## 九、环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `DATABASE_URL` | （必填） | 本机：`mysql+pymysql://detect_system:<密码>@82.157.234.123:13306/detect_system`；云上 Flask：主机 `127.0.0.1`、端口 **3306** |
| `ML_BJJ_WEIGHTS` | `ml-bjj/models/pest-cls-best.pt` | 识病权重 |
| `ML_BJJ_PORT` | `5000` | Flask 端口 |
| `ML_BJJ_USE_MOCK` | `0` | `1` 时识病走哈希假识别，**业务仍走 MySQL** |
| `ML_BJJ_DISABLE_SCHEDULER` | `0` | `1` 时关闭 60 秒规则链（跑测例用） |

识病降级（业务库不变）：

```powershell
$env:ML_BJJ_USE_MOCK="1"
python ml-bjj\serving\app.py
```

## 十、生产构建与线上切流

```powershell
pnpm build
```

上传 `dist/` 覆盖服务器 `frontend/dist/`。Nginx 把 `/api/analysis/`、`/api/treatments/` 以及其余 `/api/`（去掉前缀）都转到 `127.0.0.1:5000`。云上 Flask 的 `DATABASE_URL` 用 `127.0.0.1`。停掉宝塔 Node 项目 `api_mock`。细节见 [`../部署/云服务器部署更新说明.md`](../部署/云服务器部署更新说明.md)。

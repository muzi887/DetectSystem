# 智能分析页面重构方案（一屏展示 · 三列 AI 推理台）

> **页面**：`/analysis` · `src/views/user/DataAnalysis.vue`  
> **背景**：智慧决策页已重构为 **一屏三列 IoT 决策台**（V2.2）；智能分析页仍为 **上表单 + 下结果** 的纵向堆叠，且使用 `page-main-shell--scroll`，两页视觉与工作流不统一。答辩演示路径为 **智能分析 → 产生预警 → 智慧决策**，分析页应与之形成对称的 **输入 → 推理 → 输出** 三列布局。  
> **关联**：[`智慧决策页面重构方案.md`](./智慧决策页面重构方案.md)、[`防治知识库实现方案.md`](./防治知识库实现方案.md)、[`阶段A-网站接入方案.md`](./阶段A-网站接入方案.md)、[`../2.0-功能扩展规划.md`](../2.0-功能扩展规划.md) §3.2  
> **状态**：📋 方案定稿，待实施

## 一、问题与目标

### 1.1 现状问题

| 现象 | 原因 | 对比智慧决策 |
|------|------|--------------|
| 页面可整体纵向滚动 | `page-main-shell--scroll` | 决策页已用 `--fill` 一屏高度链 |
| 上传区与类别按钮横排、结果区另起一行 | 两阶段纵向布局 | 决策页为三列同屏 |
| 类别为右侧竖排大按钮 | 小挑时期表单布局 | 决策页为紧凑 Tab / 列表 |
| 防治建议平铺 `TreatmentGuidePanel` | 未与决策页 Collapse 统一 | 决策页右栏 `a-collapse` |
| 分析完成后仅链到预警中心 | 缺「智慧决策」快捷入口 | 答辩动线需两页衔接 |

### 1.2 业务工作流（不变）

```text
上传图片 + 选作物/类别 → POST /api/analysis/image → 展示病名 + 置信度
    → createAlert 写预警 → 预警中心 / 智慧决策可读
```

API、Vite 代理、推理服务 **不改动**；本方案仅重构 **页面布局与展示组件**。

### 1.3 重构目标

| 编号 | 要求 | 验收标准 |
|------|------|----------|
| **G1** | **一屏三列** | 桌面 ≥1280px：输入 \| 预览/状态 \| 结果同屏，无页面级滚动 |
| **G2** | **风格统一** | 与决策页共用 `page-main-shell--fill`、`.glass-widget-card`、Grid 列宽 |
| **G3** | **左栏输入** | 上传、作物、识别类别、补充说明、主操作按钮 |
| **G4** | **中栏预览** | 大图预览 + 上传/分析进度 + 分析完成后摘要指标 |
| **G5** | **右栏输出** | 病名、置信度、健康 Tag；防治建议 `a-collapse`；跳转预警/决策 |
| **G6** | **窄屏降级** | ≤992px 单列：输入 → 预览 → 结果 |
| **G7** | **状态清晰** | 空态 / 上传中 / 分析中 / 有结果 四态与中、右栏联动 |

## 二、与智慧决策的对齐关系

### 2.1 双页 IoT 工作流

```text
┌──────────────────── 智能分析 /analysis ────────────────────┐
│  Input          │  Inference View    │  Output / Runbook   │
│  上传+参数       │  图像+进度+摘要      │  病名+防治 Collapse  │
└───────────────────────────┬────────────────────────────────┘
                            │ createAlert
                            ▼
┌──────────────────── 智慧决策 /decision ────────────────────┐
│  Alarm Queue    │  Situation           │  AI 建议 Collapse  │
│  待办列表        │  监测+地图            │  联动处置           │
└────────────────────────────────────────────────────────────┘
```

| 决策页列 | 分析页列 | 职责 |
|----------|----------|------|
| 左 · 队列 | 左 · **输入** | 发起任务 |
| 中 · 态势 | 中 · **预览** | 任务上下文与过程反馈 |
| 右 · 处置 | 右 · **输出** | 结论与可执行建议 |

### 2.2 共用设计令牌（实施时抽取或复制）

| 项 | 决策页已有 | 分析页沿用 |
|----|------------|------------|
| 页面壳 | `page-main-shell--fill` | ✅ 同 |
| 卡片 | `glass-widget-card`、`widget-card` | ✅ 同 |
| Grid | `minmax(260px,300px) \| 1fr \| minmax(300px,360px)` | ✅ 同 class 或 `.iot-dashboard-grid` |
| 右栏防治 | `buildTreatmentPanels` + `a-collapse` | ✅ 替换 `TreatmentGuidePanel` 平铺 |
| 溢出 | 右栏 Collapse、无列内滚动 | ✅ 同 [溢出说明](./智慧决策-左栏分页与溢出实现说明.md) |

### 2.3 布局方案对比

| 方案 | 布局 | 结论 |
|------|------|------|
| A. 现状 | 上：表单+竖排类别；下：结果 | 归档 |
| **B. 三列** | 左：输入；中：预览；右：结果+防治 | **★ 采用**（与决策对称） |
| C. 左预览右结果 | 中列取消，两列 | 预览区过窄，不推荐 |
| D. Tab 切换 | 输入/结果 Tab | 违背 G1 一屏展示 |

## 三、布局设计

### 3.1 目标线框（桌面 ≥1280px）

```text
┌──────────────────────────────────────────────────────────────────────────┐
│  AppLayout 顶栏 + 主导航                                                  │
├──────────────────────────────────────────────────────────────────────────┤
│  智能分析（glass 卡片 · 占满视口）                                           │
│  ┌─────────────┬──────────────────────────┬───────────────────────────┐  │
│  │ 左列 260–300│ 中列 flex-1               │ 右列 300–360               │  │
│  │ 分析参数     │  图像预览                  │  分析结果                  │  │
│  │ 上传缩略触发  │  上传/分析进度              │  病名 + 置信度 + Tag       │  │
│  │ 作物/类别    │  完成后：作物·类别·时间      │  a-collapse 防治建议       │  │
│  │ 补充说明     │                          │  [预警中心] [智慧决策]      │  │
│  │ [开始分析]   │                          │                           │  │
│  └─────────────┴──────────────────────────┴───────────────────────────┘  │
│  未分析 → 中列空态预览框 + 右列占位；分析中 → 中列 Spin + 右列 loading      │
└──────────────────────────────────────────────────────────────────────────┘
```

### 3.2 Grid 规格

与决策页保持一致，便于共用样式：

```css
.analysis-dashboard {
  display: grid;
  grid-template-columns: minmax(260px, 300px) minmax(0, 1fr) minmax(300px, 360px);
  gap: 16px;
  flex: 1;
  min-height: 0;
  overflow: hidden;
}
```

| 列 | 类名 | 面板 |
|----|------|------|
| 左 | `.col-input` | `input-panel` |
| 中 | `.col-preview` | `preview-panel` |
| 右 | `.col-output` | `output-panel` |

### 3.3 高度链

```text
.app-shell (100vh)
  └─ .content-slot (min-height:0)
       └─ .page-main-shell--fill          ← 由 --scroll 改为 --fill
            └─ .analysis-page-fill
                 └─ .analysis-dashboard
```

### 3.4 各列内容规格

**左列 · 输入**

| 区块 | 内容 |
|------|------|
| 上传 | 保留 `picture-card`；缩略图 120×120 或点击在中列放大预览 |
| 作物 | `a-select`：小麦 / 玉米 / 番茄（与 v3 模型一致） |
| 识别类别 | 四档 **横排 Tab**（灾害 / 病虫害 / 气候 / 其他）；默认可选中「病虫害」 |
| 补充 | `a-textarea` rows=2 |
| 操作 | 主按钮「开始分析」合并原「识别」「确定」；分析中 `loading` 禁用 |

> **说明**：当前 v3 推理仅输出 8 类病虫害 label；其余类别 Tab 保留为演示入口，结果区可标注「当前模型为病虫害分类，其他类别仅供参考」。

**中列 · 预览**

| 状态 | 展示 |
|------|------|
| 未上传 | 虚线占位 + 「请上传叶片图片」 |
| 已上传 | 大图 `object-fit: contain`，最大高度占满中列 |
| 上传中 | 圆形进度 overlay（沿用现有逻辑） |
| 分析中 | `a-spin` + 文案「正在智能分析…」 |
| 已完成 | 底部 meta 条：作物 · 类别 · 分析时间 |

**右列 · 输出**

| 状态 | 展示 |
|------|------|
| 空态 | 图标 + 「上传并开始分析后，结果将显示在这里」 |
| 分析中 | 与中间列同步 loading |
| 有结果 | 标题区：病名 + 健康/需关注 Tag；置信度进度条；低置信度复核提示 |
| 防治 | `buildTreatmentPanels(getTreatment(病名))` → **`a-collapse`**（与决策页同默认展开规则） |
| 底栏 | 文案「已写入预警列表」+ 链接 **前往预警中心**、**前往智慧决策** |

## 四、右栏溢出

防治条目较多时，右栏采用与智慧决策相同的 **R1 Collapse**，**无列内滚动条**。方案与实现复用 [溢出说明 §二、§四](./智慧决策-左栏分页与溢出实现说明.md)。

左、中列内容高度固定，一般无需分页；若后续增加「历史分析记录列表」，再单独立项溢出说明。

## 五、交互规格

### 5.1 分析流程

```text
beforeUpload 校验 → customUpload 本地预览 → 点击「开始分析」
    → analyzing=true → analyzeImage API
    → 写 analysisResult → createAlert → analyzing=false
```

逻辑 **保持现有** `handleConfirm` / `handleIdentify` 行为，仅合并为一个入口。

### 5.2 右栏防治展示

| 项 | 说明 |
|----|------|
| 数据源 | `useTreatmentGuide().getTreatment(result)` |
| 组件 | 使用 `buildTreatmentPanels` + `a-collapse`，**逐步弃用** 结果区内嵌 `TreatmentGuidePanel` 平铺 |
| 默认展开 | 同决策页：「化学防治」+ 无则「病害概述」 |
| 低置信度 | `< 70%` 且非健康：Collapse 顶栏或单独 Alert 显示复核提示 |

### 5.3 答辩快捷跳转

| 按钮 | 路由 | 场景 |
|------|------|------|
| 前往预警中心 | `/warnings` | 核对新写入的 `[AI识别]` 预警 |
| 前往智慧决策 | `/decision` | 演示「分析 → 决策」闭环 |

### 5.4 空态与错误

| 场景 | 中列 | 右列 |
|------|------|------|
| 未上传 | 占位图 | 空态文案 |
| 未点分析 | 有图无结果 | 空态文案 |
| API 失败 | 保留预览图 | `message.error`；不写入 result |
| 健康结果 | 预览 + meta | Tag「健康」；防治 Collapse 显示巡检类条目 |

## 八、验收清单

**布局与风格**

- [ ] 与 `/decision` 同屏高度感，桌面无页面级纵向滚动  
- [ ] 三列 Grid 列宽、间距、glass 卡片风格与决策页一致  
- [ ] `page-main-shell--scroll` 已改为 `--fill`  

**功能回归**

- [ ] 上传 JPG/PNG、≤2MB 校验仍有效  
- [ ] 开始分析 → 真实/ Mock 推理 → 病名 + 置信度正确  
- [ ] 分析成功仍 `createAlert` 写入预警  
- [ ] 低置信度复核提示仍出现  

**右栏与联动**

- [ ] 防治建议为 `a-collapse`，无列内滚动条  
- [ ] 「前往预警中心」「前往智慧决策」可跳转  
- [ ] 健康类不展示高危药剂为主的内容  

**答辩路径**

- [ ] 智能分析上传 → 出结果 → 智慧决策可见新预警（与决策页 G7 默认选中配合演示）

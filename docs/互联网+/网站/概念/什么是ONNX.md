# 什么是 ONNX

> 说明可选的另一种模型运行格式，以及它和 `.pt` / PyTorch 的关系。  
> 导出脚本、环境变量、测试策略见 [`新模型训后-P3-规则链与工程化实施计划.md`](../实施计划/新模型训后-P3-规则链与工程化实施计划.md) Task 5，本文不重复。

---

## 一、一句话

**ONNX**（Open Neural Network Exchange）是一种 **神经网络的交换格式**：把已经训练好的结构与权重存成 `.onnx` 文件，可以用别的运行库（如 onnxruntime）来推理，不一定每次都走 PyTorch。

本项目主路径仍是 `pest-cls-best.pt` + PyTorch。ONNX 是 P3 的 **可选项**，用来在部分机器上加快或减轻对 PyTorch 的依赖。默认关闭。

---

## 二、它解决什么问题

`.pt` 和 PyTorch 绑在一起：加载、softmax 前的前向计算都靠 `torch`。换环境、不想装完整 PyTorch、或只想要推理速度时，可以：

```text
训练仍用 PyTorch → 导出 pest-cls-best.onnx → 推理时用 onnxruntime 算 logits
                 → 之后仍 softmax → 作物掩码 → topk（与现逻辑相同）
```

导出是「翻译」不是「再训练」。类名仍以 meta / 原权重为准，不另学一套病。

---

## 三、在本项目中怎么开关

| 情况 | 走哪条路 |
|------|----------|
| 不设环境变量（默认） | 只加载 `.pt`，和现在一样 |
| `ML_BJJ_ONNX=1` **且** 已有 `pest-cls-best.onnx` | 前向用 onnxruntime，后面掩码等不变 |
| 设了开关但没有 onnx 文件 | 不能假装成功；计划要求默认仍能走 PyTorch |

没有权重或仍是旧的 8 类时，导出允许失败，**不能**为了迁就导出而放宽「必须 23 类才能启动」的门禁。

---

## 四、它不是什么

- 不是新的病虫害模型，也不替代作物掩码。
- 不是 waitress：ONNX 管 **怎么算那一次前向**；waitress 管 **HTTP 进程怎么挂在端口上**。
- 不是训练格式的首选：训练、微调仍用 PyTorch。

## 六、小结

**ONNX = 把练好的网络另存一种可交换格式，可选地用 onnxruntime 做前向；本项目默认仍用 PyTorch。**

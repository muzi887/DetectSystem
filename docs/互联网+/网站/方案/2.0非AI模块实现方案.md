### 和原文方案不一致、但已按后出实施计划落地的点

这些不是漏做，是后来故意改的，读旧接口表时不要按 7 月原文去对：

1. **自动预警不走 `evaluateDisasterRules`。** `POST /disasterRules/evaluate` 仍是瞬时打分 JSON，**不写** `alerts`。落库在 `src/mock/persistRules.ts` 三条链。
2. **`POST /alerts/evaluate-all` 只跑链 1。** 链 2 / 链 3 分别是 `POST /weather/extreme-events/evaluate`、`POST /pest-risk/evaluate`。定时器调 `runAllChains`（1→2→3），不是第四条链。
3. **预报/极端/虫情预测走 json-server 集合名**，不是原文的 `/weather/forecast`：前端用 `/weatherForecast`、`/extremeEvents`、`/pestRiskPredictions`。
4. **没有** 单独的 `src/api/weather.ts`、`fieldSensors.ts`、`useWeatherForecast.ts`；接口集中在 `src/api/rules.ts`，轮询在 `useAlertEngine.ts`（挂在 `AppLayout`）。

## 一、为什么要单独写这份方案

`2.0-功能扩展规划.md` 是产品级总纲；AI 与知识库链路已在 7 月完成。剩余工作集中在 **「感知 → 规则 → 预警 → 决策」的非 AI 闭环**，且与现有 V1.0.4 代码高度耦合——适合在 Mock 层增量扩展，而非推倒重来。

| 维度 | V1.0.4 当时现状 | 2.0 目标 | 2026-08-21 实际 |
|------|-----------------|----------|-----------------|
| 预警 | 人工新建 + 单阈值着色 | 双阈值 + 耐受时间 + 自动入库 | **已做**：`alertRules` + `persistRules`，**不是**改造 `evaluateDisasterRules` 落库 |
| 气象 | 快照卡片 | 7 日预报 + 极端天气 | **部分**：预报种子 + 链 2 已通；页面仍是快照卡 + 极端标签 |
| 传感 | `weatherReadings` 单点快照 | 历史曲线、多站对比 | **未做**：传感器 Tab 仍是预警计数图 |
| 遥感 | 多时相 NDVI、墒情热力图 | 风险规则 + 地块高亮 | **部分**：链 3 + NDVI「虫情高风险」标；无边界高亮 |
| 自主性 | 手动刷新 | 定时评估 + 自动预警 | **已做** Mock 60s + 前端 30s 拉预警；无通知/真日报 |

**竞赛演示原则**：Mock 数据 + 规则引擎即可闭环；真实设备/API 作为「可切换数据源」，答辩时注明数据来源。

#### 4.1.1 目标

- 空气/土壤指标支持**历史趋势**（不只快照）
- **双阈值 + 耐受时间**自动产生分级预警
- 农技员可配置阈值（合作社只读）
- 与 `WarningSystem.vue`、`alertLevel.ts` 等级统一

```typescript
export function evaluateReading(
  reading: SensorSnapshot,
  profile: ThresholdProfile,
  state: RuleState[]

export function mapRuleToAlertLevel(level: RuleLevel): AlertLevel {
  // hint → medium/warning（黄）
  // alert → high/critical（红）
```

**耐受逻辑**：

```text
读数超 hint 阈值 → 记录 startedAt
持续 < durationMinutes → 不产预警
持续 ≥ durationMinutes 且未发过同规则预警 → POST /alerts（source: auto）
读数恢复正常 → 清除 ruleState
```

| POST | `/disasterRules/evaluate` | **扩展现有**：加入 profile + 耐受 + 可选 `persistAlert: true` |
| POST | `/alerts/evaluate-all` | **新增**：遍历所有监测点，批量评估（供调度器调用） |

3. 维护 `ruleState`，达标则 `db.alerts.push(...)` 并写 `source: 'auto'`

```typescript
  evaluateAllPointsAndPersist(db)
  evaluateExtremeWeather(db)

```

前端 `stores/data.ts` 同步 `setInterval` 拉取 `alerts` / `monitorPoints`（30–60s），地图与预警中心自动刷新。

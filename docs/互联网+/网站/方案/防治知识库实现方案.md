## 一、要不要从网上下载？

### 1.1 结论（答辩 / 演示够用）

| 做法 | 是否必须 | 说明 |
|------|----------|------|
| **自己整理 JSON 知识库** | ✅ **推荐** | 8 类病害，每类 1 条结构化文案即可闭环演示 |
| 从网上**参考**公开农技资料 | 建议 | 查症状、药剂、适期，**手写**进本项目 JSON |
| 从网上**批量爬取**数据库 | ❌ 不推荐 | 版权/格式不统一/与 v3 标签难对齐，投入大 |
| 下载第三方「知识库 API」 | ❌ 非必须 | 竞赛演示无硬性要求；可后期再接 |

**一句话**：**不需要下载现成数据集**；需要的是 **8 条与 v3 中文标签一一对应的防治说明**，可参考公开资料后由团队撰写。

### 1.2 可参考的公开来源（手写摘录，注明出处即可）

| 类型 | 示例来源 | 用途 |
|------|----------|------|
| 国家级农技 | [全国农技推广网](https://www.natesc.org.cn/)、农业农村部病虫情报 | 发生规律、防治适期 |
| 省级植保 | 河北省农业农村厅植保资讯、京津冀地方病虫预报 | 本地化表述 |
| 教材 / 图谱 | 高校植物保护教材、病害图谱 | 症状描述（答辩讲解） |
| 农药信息 | 中国农药信息网（登记查询） | 核对药剂名称是否仍登记 |

> **注意**：资料用于**查阅核对**，项目内落库内容建议 **自己组织语言**，避免大段复制；答辩 PPT 可写「参考××技术规程」。

### 1.3 不建议的做法

- 整站爬虫入库（法律与维护成本高）
- 引入与 v3 **标签不一致** 的病名（如「小麦条锈病」——v3 已合并为「小麦锈病」）
- 把知识库做成第二个 AI 模型（当前阶段过度设计）

## 二、知识库放哪里、长什么样

### 2.1 推荐路径

```text
ml-bjj/knowledge/
  treatment.json       # ★ 主库：8 类病害 + 健康（与 v3 标签键名一致）
  README.md            # 可选：字段说明、引用来源
```

也可同步一份到前端便于直连（二选一，**不要两处手工维护**）：

```text
src/assets/knowledge/treatment.json   # 若采用「前端静态 import」方案
```

**推荐**：源文件放 `ml-bjj/knowledge/treatment.json`，构建时复制到 `public/knowledge/` 或 `src/assets/`（脚本一次配置）。

### 2.2 与 v3 模型的键对齐

知识库 **primary key 必须与 AI 输出完全一致**（`classes.txt`）：

```text
健康
小麦锈病
小麦赤霉病
小麦白粉病
小麦蚜虫为害
玉米大斑病
玉米锈病
番茄早疫病
```

智能分析返回 `result: "小麦锈病"` → 直接 `treatments["小麦锈病"]` 取防治方案。

### 2.3 JSON 结构（建议）

```json
{
  "version": "1.0",
  "region": "京津冀",
  "updated_at": "2026-07-12",
  "items": {
    "小麦锈病": {
      "crop": "小麦",
      "aliases": ["条锈病", "叶锈病", "秆锈病"],
      "summary": "叶部出现黄褐色粉状孢子堆，严重时叶片枯死，影响灌浆。",
      "risk_level": "high",
      "measures": {
        "chemical": [
          "发病初期选用三唑酮、戊唑醇等登记药剂，按说明书稀释喷雾。",
          "同一作物季注意轮换作用机制，避免抗药性。"
        ],
        "biological": [
          "保护田间天敌；优先采用低毒药剂与绿色防控。"
        ],
        "agronomic": [
          "选用抗病品种；适期播种，合理密植，加强肥水管理。",
          "收获后深翻，减少病残体。"
        ]
      },
      "timing": "齐穗至灌浆期重点监测；见病斑 5% 田块即启动防治。",
      "safety": "施药佩戴防护具；注意风向与蜜蜂活动期避让。",
      "references": ["全国农技中心小麦锈病防控技术方案（摘录）"]
    },
    "健康": {
      "crop": "通用",
      "summary": "未检出明显病害症状。",
      "measures": {
        "agronomic": ["保持常规巡检与田间记录；异常时复拍送检。"]
      },
      "timing": "按生育期每周巡田 1–2 次。"
    }
  }
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `crop` | ✅ | 小麦 / 玉米 / 番茄 / 通用 |
| `summary` | ✅ | 1–2 句症状或含义（结果页展示） |
| `measures.chemical` | 病害建议有 | 药剂与用法（演示可 1–2 条） |
| `measures.agronomic` | 建议有 | 农艺措施 |
| `timing` | 建议有 | 防治适期 |
| `aliases` | 可选 | 兼容用户口语 / Mock 旧名 |
| `references` | 可选 | 答辩引用来源 |

## 三、在系统里怎么用（三条链路）

```text
                    treatment.json
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
  智能分析结果页      智慧决策页         预警详情（可选）
  DataAnalysis.vue   DecisionSupport.vue
        │                 │
        │ 识别完即展示      │ 解析 [AI识别] 预警文案
        └────────┬────────┘
                 ▼
           用户看到可执行防治建议
```

### 3.1 链路 1：智能分析页（优先 · P0）

**时机**：`analyzeImage` 返回 `result` 后，用病名查知识库。

**UI**：在现有置信度下方增加「防治建议」卡片（化学 / 农艺 / 适期分条展示）。

**逻辑示意**：

```typescript
import treatments from '@/assets/knowledge/treatment.json'

const guide = treatments.items[aiResult] ?? treatments.items['健康']
```

**健康类**：显示「保持巡检、继续观察」，不推送高等级药剂方案。

### 3.2 链路 2：智慧决策页（P1）

**现状**：`DecisionSupport.vue` 的 `generateSuggestions()` 仅根据预警级别、温湿度、关键词生成通用文案，**未解析病害名**。

**改造**：若 `alert.message` 含 `[AI识别]`，用正则提取病名，例如：

```text
[AI识别] 监测到 小麦 - 小麦锈病 (置信度: 87.9%)
                              ↑ 查 treatment.json
```

将查到的 `measures`、`timing` 追加到 `currentSuggestions` 列表顶部。

### 3.3 链路 3：推理 API 扩展（可选 · P2）

在 `ml-bjj/serving/app.py` 响应中增加 `advice` 字段（读取同一份 JSON）。

| 方案 | 优点 | 缺点 |
|------|------|------|
| **前端读 JSON**（推荐） | 改动的文件少；不重启 5000 | 需重新 build 前端 |
| 后端读 JSON | 接口一次返回 | 改 Flask、前后端都要发版 |

竞赛演示 **优先前端静态方案** 即可。

## 六、示例条目（可直接改写入 JSON）

### 小麦赤霉病（摘录模板）

- **summary**：穗部出现枯白穗、粉红色霉层，多雨高湿易流行。
- **chemical**：扬花期遇连阴雨，按登记范围使用戊唑醇、氰烯菌酯等药剂预防。
- **agronomic**：避免晚播弱苗；及时清除病残体；加强排水降湿。
- **timing**：**齐穗扬花初期** 为关键预防窗口。
- **safety**：施药注意个人防护；严格安全间隔期采收。

### 玉米大斑病（摘录模板）

- **summary**：叶片长梭形大斑，潮湿时病斑灰褐色带暗纹。
- **chemical**：发病初期选用吡唑醚菌酯、苯醚甲环唑等，叶面均匀喷雾。
- **agronomic**：种植抗病品种；合理密植；增施磷钾肥。
- **timing**：苗期至抽雄期见病即防，重发田块 7–10 天复喷。

## 八、常见问题

**Q：必须用大模型生成防治方案吗？**  
A：**不必。** 结构化 JSON + 规则查找即可满足「识别 → 建议」闭环；LLM 可作为后期增强。

**Q：健康类要不要写药剂？**  
A：**不要。** 只写巡检与复测建议，避免误导。

**Q：识别错了怎么办？**  
A：低置信度提示人工复核；决策页文案注明「请以田间复核为准」。

**Q：要不要做多语言 / 多地区？**  
A：当前京津冀试点 **只做中文、单 region 字段** 即可。

**Q：知识库要训练进模型吗？**  
A：**不要。** 与 `pest-cls-best.pt` 分离；模型只负责「是什么病」，知识库负责「怎么治」。

## 二、当前能识别什么

### 2.1 按作物分类

| 作物 | 可识别类别 | 说明 |
|------|------------|------|
| **小麦** | 小麦锈病、小麦赤霉病、小麦白粉病、小麦蚜虫为害、健康 | 三种锈病已合并为「小麦锈病」 |
| **玉米** | 玉米大斑病、玉米锈病、健康 | |
| **番茄** | 番茄早疫病、健康 | 设施蔬菜代表 |
| 水稻 / 桃 / 苹果 | ❌ **不在 v3** | 见 v2 权重或后续扩充 |

「健康」为 **全局 1 类**（小麦、玉米、番茄的正常样本训练时合并）。

### 2.2 完整 8 类列表

```text
健康
小麦锈病、小麦赤霉病、小麦白粉病、小麦蚜虫为害
玉米大斑病、玉米锈病
番茄早疫病
```

与训练集标签一致，见：`ml-bjj/data/bjj_cls/classes.txt`

### 2.3 模型会输出什么

```powershell
python ml-bjj\scripts\predict.py --image "某张叶子.jpg"
```

**验证集抽测（2026-07-09，已通过）**：

| 测试图 | 模型输出 | 置信度 |
|--------|----------|--------|
| `bjj_cls/val/小麦锈病/小麦锈病_00001.png` | 小麦锈病 | **87.87%** |
| `bjj_cls/val/玉米大斑病/玉米大斑病_00001.jpg` | 玉米大斑病 | **91.51%** |

典型终端输出：

```text
识别结果: 小麦锈病
置信度:   87.87%
```

- **识别结果**：上表 8 类之一  
- **置信度**：0–100%；一般 **≥ 80%** 较可信，**< 70%** 建议人工复核  
- **路径注意**：从项目根运行时需写完整路径 `ml-bjj\data\bjj_cls\val\...`；扩展名以目录内实际文件为准

### 2.4 当前不能做什么

| 能力 | 状态 | 说明 |
|------|------|------|
| 按前端选的「作物」过滤结果 | ❌ | 上传时选 cropType 不影响模型，8 类全局竞争 |
| 受害区域框选（检测框） | ❌ | 仅分类，不画 bbox |
| 严重程度分级 | ❌ | 不输出轻/中/重 |
| 自动给出防治方案 | ❌ | 需后续知识库 |

| 小麦锈病拆成条锈/叶锈/秆锈 | ❌ | v3 仅输出「小麦锈病」 |
| 保证河北实地 100% 准确 | ❌ | 需本土化验证 |

## 四、本土化测试：需要怎样的图片

### 4.1 总体原则

```text
拍清楚「病斑/虫害主体」> 拍整片田
一种图只突出一个主要问题
叶片/穗部特写，光线自然
```

### 4.2 格式与数量

| 要求 | 建议 |
|------|------|
| 格式 | JPG / PNG |
| 分辨率 | 短边 ≥ 512 px |
| 单张大小 | ≤ 2 MB（对接网站时） |
| 首轮摸底 | 每类 **3–5 张**，合计约 **25–40 张** |

### 4.3 拍摄内容（京津冀 v3）

#### 小麦（优先）

| 测试目标 | 建议拍什么 |
|----------|------------|
| 小麦锈病 | 叶部橙黄/褐色锈斑特写（不区分条/叶/秆锈） |
| 小麦赤霉病 | 穗部枯白/粉红霉层 |
| 小麦白粉病 | 叶面白色粉状物 |
| 小麦蚜虫为害 | 可见蚜虫或典型为害状 |
| 健康 | 同地块无症麦叶 |

#### 玉米

| 测试目标 | 建议拍什么 |
|----------|------------|
| 玉米大斑病 | 叶片长条形大斑 |
| 玉米锈病 | 叶部锈色孢子堆 |
| 健康 | 正常玉米叶 |

#### 番茄

| 测试目标 | 建议拍什么 |
|----------|------------|
| 番茄早疫病 | 叶片同心轮纹斑（设施大棚） |
| 健康 | 正常番茄叶 |

### 4.4 建议采集清单（最小可行）

| 序号 | 作物 | 类型 | 张数 |
|------|------|------|------|
| 1 | 小麦 | 锈病 | 5 |
| 2 | 小麦 | 赤霉病 | 3 |
| 3 | 小麦 | 健康 | 3 |
| 4 | 玉米 | 大斑病或锈病 | 3 |
| 5 | 玉米 | 健康 | 2 |
| 6 | 番茄 | 早疫病 + 健康 | 各 2（若有条件） |

合计约 **20–25 张** 可完成首轮摸底。

## 五、如何执行本土化测试

### 5.1 命令行测试

```powershell
cd D:\code2\software\vue\program\DetectSystem
ml-bjj\.venv\Scripts\Activate.ps1

python ml-bjj\scripts\predict.py --image "D:\你的路径\20260710_河间_小麦_锈病_01.jpg"
```

默认加载 `ml-bjj/models/pest-cls-best.pt`。指定权重：

```powershell
python ml-bjj\scripts\predict.py --image "图片.jpg" --weights ml-bjj\models\pest-cls-best.pt
```

记录：**人工标签**、**模型输出**、**置信度**。

### 5.2 结果记录表（建议）

| 文件名 | 地块 | 人工判断 | 模型输出 | 置信度 | 是否一致 |
|--------|------|----------|----------|--------|----------|
| 小麦锈病_00001.png | 验证集 | 小麦锈病 | 小麦锈病 | 87.87% | ✅ |
| 玉米大斑病_00001.jpg | 验证集 | 玉米大斑病 | 玉米大斑病 | 91.51% | ✅ |
| …_锈病_01.jpg | 河间 | 小麦锈病 | 小麦锈病 | 91% | ✅ |

可保存为 `ml-bjj/data/local_test/results.csv`。

### 5.3 结果怎么用

| 结果 | 建议动作 |
|------|----------|
| 一致且置信度 ≥ 80% | 答辩现场演示备用图 |
| 一致但 70%–80% | 可用，说明「建议复核」 |
| 不一致或 < 70% | 收入 `hard_cases/` 备 v3.1 增训 |
| 某类完全无法识别 | 补拍 20+ 张 → 并入训练集 → 重跑 prepare + train |

## 六、实地照片若要加入训练（v3.1）

1. 按 **v3 中文类名** 放入文件夹（与 `bjj_cls` 一致，如 `小麦锈病/`）  
2. 合并进 `data/bjj_cls` 或单独目录后重跑 `prepare_bjj.py`  
3. `python ml-bjj\scripts\train_cls.py --epochs 20`  
4. 备份新权重为 `pest-cls-bjj-v3.1.pt`

| 目标 | 是否要实地数据 |
|------|----------------|
| 完成训练、接网站、答辩演示 | **不必须**（当前 98.99% 可演示） |
| 提高京津冀实地准确率 | **强烈建议** 抽测 20–40 张 |
| 新增作物/病害类 | **必须** 增数据并重训 |

## 八、能力边界一句话总结

**v3 模型**：京津冀 **8 类** 病虫害分类器，验证集 **98.99%**，覆盖小麦/玉米/番茄；命令行与网站智能分析均已接入 v3 推理（`ml-bjj/serving/app.py`）。

**本土化测试**：京津冀实地 **25–40 张** 清晰特写，覆盖小麦锈病/赤霉病、玉米、番茄；先 `predict.py` 摸底，再决定是否 v3.1 增训。

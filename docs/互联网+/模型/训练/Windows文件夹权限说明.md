# Windows 文件夹「安全」页说明（训练数据包）

> 场景：在 `ml-bjj/data/` 里解压开源包（如 *An Open-Source Multi-Format Maize Leaf Image Datas*）后，删除/改名弹出 **「文件夹访问被拒绝」**。  
> 改的是 **Windows NTFS 权限**，不是 Vue / Flask 代码。  
> 属性窗口路径：文件夹右键 → **属性** → **安全**。

---

## 一、这个页面在说什么

上半是「谁能碰这个文件夹」，下半是「选中的这一项能做什么」。

截图里 **Users** 被点中时：

| 权限 | 勾上 = 可以 | Users 常见情况 |
|------|-------------|---------------|
| 完全控制 | 改权限、删、写 | 通常不勾 |
| 修改 | 增删改文件和子文件夹 | **未勾 → 不能删包** |
| 读取和执行 / 列出 / 读取 | 打开、看里面有什么 | 一般已勾 |

资源管理器多数时候用的是 **Users** 这份令牌（即使你登录名是管理员）。Users 只有读，就会出现：

> 你需要来自 `mmmuu\JessamynAdmin` 的权限才能对此文件夹进行更改

意思是：当前窗口**不够格改**，系统点名「管理员账号」去批准，不是文件夹坏了。

---

## 二、列表里这几个名字是什么

`mmmuu` 是这台电脑的名字（工作组）。后面才是角色。

| 名称 | 是谁 | 和你的关系 |
|------|------|------------|
| **Authenticated Users**（已验证的用户） | 任何已经登录的人（含你） | 往往有 **修改**。有时仍删不掉，因为真正挡你的是下面 **Users** |
| **SYSTEM** | Windows 自己（服务、更新） | 不要改、不要删这一项 |
| **Administrators**（`mmmuu\Administrators`） | 本机「管理员」组 | 完整控制。用「以管理员运行」的程序写入的文件，所有权常落在这里 |
| **Users**（`mmmuu\Users`） | 本机普通用户组 | 你的资源管理器默认走这一组。**只有读**时，界面里就不能删、不能改名 |

另外：登录名 `JessamynAdmin` 可以同时属于 Administrators 和 Users。  
资源管理器默认按 **Users（只读）** 干活；解压软件若「以管理员运行」，写入的目录就会变成「管理员可写、Users 只读」——这就是解压玉米数据包后删不掉的典型原因。

**不要**给 Everyone 完全控制；训练数据只需你自己能删、能拷。

## 三、要改哪里（对照属性窗口）

目标：让你能 **删除或移动** 整个数据包目录。

### 做法 A（多数情况够用）

1. 仍在 **安全** 页，点 **编辑**（「要更改权限，请单击编辑」旁边）。  
2. 上面选 **Users**（或列表里出现的 `JessamynAdmin`）。  
3. 下面勾选 **修改**（写入通常会跟着勾上）。  
4. **应用** → **确定**。若问是否应用到子文件夹，选 **是**。  
5. 关掉属性，再删文件夹。

「编辑」是灰的：先关占用该目录的窗口（看图、解压、训练脚本），或用做法 B。

### 做法 B（编辑失败 / 子文件仍拒绝）

1. **安全** 页右下角 **高级**。  
2. 顶部 **所有者** → **更改** → 填 `JessamynAdmin` → 确定。  
3. 勾选 **替换子容器和对象的所有者** → 确定。  
4. 回到安全页，按做法 A 给 Users 勾上 **修改**。

弹窗 **重试**：若出现 UAC，用 JessamynAdmin 同意，等于临时用管理员身份删一次。

## 四、和训练目录的关系

- 源图应放在 `ml-bjj/data/<中文类名>/`（见 [玉米水稻补图-搜索词条.md](./玉米水稻补图-搜索词条.md)）。  
- 英文长名的开源解压包只是中转，用完应移出仓库或删除，**不必提交 git**。  
- 解压时尽量不要「以管理员运行」压缩软件，可减少再遇到只读 Users。

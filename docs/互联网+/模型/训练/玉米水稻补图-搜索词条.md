# 玉米 / 水稻补图 — 搜索词条与来源

> 用途：补充仍偏少的玉米类、以及水稻里仍偏少的类；在 Kaggle / Roboflow 等站检索后归入 `ml-bjj/data/<中文类名>/`。  
> 搜英文词条通常比中文更准；归档后须重跑 `prepare_from_class_folders.py`（当前 `data/bjj_cls/` 仍是旧切分，与源图不一致）。  
> 统计口径：2026-08-22 扫 `ml-bjj/data/<中文类名>/`（不含 `archive*`、`bjj_cls`、`hard_cases`、YOLO/竞赛解压包目录）。

**易混、不要硬塞**

| 包里常见名 | 实际 | 处理 |
|------------|------|------|
| `Gray_Leaf_Spot` / `Corn_Cercospora_Leaf_Spot` | 灰斑 | 系统无此类，跳过 |
| `Northern_Leaf_Blight` / 笼统 `Blight` | 大斑或统称 | ≠ 弯孢、≠ 小斑 |
| `Common_Rust` / `Corn_Common_Rust` | 普通锈病 | 已够 |
| `Corn_Streak` | 玉米条纹（病毒相关） | 系统无，跳过 |

## 除 Kaggle 外的国外来源

缺 **弯孢 / 窄条斑 / 叶鞘腐败** 时，大量「锈病+大斑+灰斑+健康」包可直接跳过。可并行搜：

| 类型 | 站点 | 说明 |
|------|------|------|
| 数据集 / 标注 | [Roboflow Universe](https://universe.roboflow.com) | 优先搜 `curvularia`、`sheath rot`、`narrow brown leaf spot`；看有无图片预览 |
| 竞赛 | [Zindi](https://zindi.africa) | 常要 Accept terms；多为检测框 |
| 聚合 | [Hugging Face Datasets](https://huggingface.co/datasets)、[Google Dataset Search](https://datasetsearch.research.google.com) | 英文病名；**先看是不是影像集** |
| 论文附数据 | [Papers with Code](https://paperswithcode.com) | 跟到原始下载 |
| 作者上传 | [Zenodo](https://zenodo.org)、[Figshare](https://figshare.com)、[Mendeley Data](https://data.mendeley.com) | 少见病小包 |
| 经典图库 | PlantVillage 及镜像 | 对当前缺口帮助有限 |
| 零星 | Wikimedia Commons、Flickr | 拉丁学名；注意许可 |

实操优先：**Roboflow + Zenodo/Figshare + Google Dataset Search（筛带图的包）**。

**别下错**

| 搜到什么 | 是什么 | 能否补弯孢图 |
|----------|--------|----------------|
| GBIF / Plazi **Checklist** | 物种名录、分类论文数字化 | **否**（几乎无训练用病叶图） |
| 加纳赛全量 `images` 无 CSV | 检测原图 | 须配 `Train.csv`；且无弯孢类 |
| Roboflow 卡在 Starting Download | 导出问题 | 换 YOLOv8、无痕或 Show download code |

## 使用提示

1. 用英文病名搜 → 核对类名与是否有图 → 拷入 `ml-bjj/data/<中文类名>/`。解压包若删不掉，见 [Windows文件夹权限说明.md](./Windows文件夹权限说明.md)。  
2. 「锈病+大斑+灰斑+健康」玉米包、只有 `Brown Spot`/`Leaf Blast` 的水稻包，对当前 P0/P1 帮助小。  
3. 注意许可证。  
4. **不要**把 `bacterial_leaf_streak` 当窄条斑，`sheath blight` 当叶鞘腐败，`Gray_Leaf_Spot`/`Cercospora` 灰斑当弯孢/小斑/褐斑。  
5. 源图变更后必须重切再训：

```powershell
python ml-bjj\scripts\prepare_from_class_folders.py
python ml-bjj\scripts\train_cls.py --epochs 20
```

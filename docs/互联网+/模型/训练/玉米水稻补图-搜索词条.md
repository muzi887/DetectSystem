> 用途：补充仍偏少的玉米类、以及水稻里仍偏少的类；在 Kaggle / Roboflow 等站检索后归入 `ml-bjj/data/<中文类名>/`。

## 除 Kaggle 外的国外来源

缺 **弯孢 / 窄条斑 / 叶鞘腐败** 时，Kaggle、Roboflow 上大量「锈病+大斑+灰斑+健康」包可直接跳过。可并行搜：

| 类型 | 站点 | 说明 |
|------|------|------|
| 数据集 / 标注 | [Roboflow Universe](https://universe.roboflow.com) | 优先搜具体病名：`curvularia`、`sheath rot`、`narrow brown leaf spot` |
| 竞赛 | [Zindi](https://zindi.africa) | 常要 Accept terms；多为检测；未必含水稻 |
| 聚合 | [Hugging Face Datasets](https://huggingface.co/datasets)、[Google Dataset Search](https://datasetsearch.research.google.com) | 英文病名 / 拉丁学名 |
| 论文附数据 | [Papers with Code](https://paperswithcode.com) | 跟到原始下载 |
| 作者上传 | [Zenodo](https://zenodo.org)、[Figshare](https://figshare.com)、[Mendeley Data](https://data.mendeley.com) | 少见病小包 |
| 经典图库 | PlantVillage 及镜像 | 对当前缺口帮助有限 |
| 零星 | Wikimedia Commons、Flickr | 拉丁学名；注意许可 |

实操优先：**Roboflow + Zenodo/Figshare + Google Dataset Search**。

## 使用提示

1. 用英文病名搜 → 核对类名 → 拷入 `ml-bjj/data/<中文类名>/`。  
2. 常见「锈病+大斑+灰斑+健康」玉米包、以及只有 `Brown Spot` / `Leaf Blast` 的水稻包，对当前 P0/P1 帮助小。  
3. 注意许可证；Roboflow 卡住时可换 YOLOv8、无痕窗口或 Show download code。  
4. **不要**把 `bacterial_leaf_streak` 当窄条斑，`sheath blight` 当叶鞘腐败，`Gray_Leaf_Spot` 当小斑/褐斑/弯孢。  
5. 源图变更后必须重切再训：

```powershell
python ml-bjj\scripts\prepare_from_class_folders.py
python ml-bjj\scripts\train_cls.py --epochs 20
```

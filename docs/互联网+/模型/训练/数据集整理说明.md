## 三、命令（复制即用）

在项目根目录 `DetectSystem` 下，**先进入虚拟环境**：

```powershell
cd D:\code2\software\vue\program\DetectSystem
ml\.venv\Scripts\Activate.ps1
```

若首次整理小麦/水稻，需安装 PyYAML：

```powershell
pip install PyYAML -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 第 1 步：整理小麦 + 水稻

```powershell
python ml\scripts\prepare_wheat_rice.py
```

成功后生成：


| 输出目录                 | 内容            |
| -------------------- | ------------- |
| `ml/data/wheat_cls/` | 小麦 15 类，中文文件夹 |
| `ml/data/rice_cls/`  | 水稻 9 类，中文文件夹  |


**若只整理其中一个：**

```powershell
python ml\scripts\prepare_wheat_rice.py --wheat-only
python ml\scripts\prepare_wheat_rice.py --rice-only
```

**自定义路径（目录名不同时）：**

```powershell
python ml\scripts\prepare_wheat_rice.py ^
  --wheat-source "ml\data\wheatPlantDiseases\data" ^
  --rice-source "ml\data\riceLeafDiseases\rice"
```

### 第 2 步：与桃/苹果合并

```powershell
python ml\scripts\merge_datasets.py
```

默认合并三个来源 → `ml/data/all_crops_cls/`：

- `ml/data/plantvillage_cls`（桃、苹果）
- `ml/data/wheat_cls`
- `ml/data/rice_cls`

### 第 3 步：训练 v2 模型

```powershell
python ml\scripts\train_cls.py --data-dir ml/data/all_crops_cls --epochs 20
```

权重仍输出到 `ml/models/pest-cls-best.pt`。

### 第 4 步：测试

从已整理目录中 **任选一张真实图片**，把路径填入 `--image`（不是字面文件名）：

```powershell
python ml\scripts\predict.py --image "D:\code2\software\vue\program\DetectSystem\ml\data\wheat_cls\val\小麦赤霉病\wheat_Fusarium_Head_Blight_00001.png"
```

其他示例目录：

```text
ml/data/wheat_cls/val/小麦条锈病/
ml/data/rice_cls/val/稻瘟病/
ml/data/plantvillage_cls/val/健康/
```

> 注意脚本路径为 `ml\scripts\predict.py`（**scripts** 复数）。

## 五、常见问题


| 问题                       | 解决办法                                                             |
| ------------------------ | ---------------------------------------------------------------- |
| `找不到小麦源目录`               | 确认路径为 `ml/data/wheatPlantDiseases/data`（含 train/valid）           |
| `找不到水稻 images`           | 确认路径为 `ml/data/riceLeafDiseases/rice`（含 images、labels、data.yaml） |
| `No module named 'yaml'` | `pip install PyYAML`                                             |
| 合并后类别太多、训练很慢             | 先用 `--sources ml/data/wheat_cls ml/data/rice_cls` 只练小麦+水稻        |
| 训练很慢 / 电脑休眠 | CPU + 2 万+ 张图；20 epoch 需数小时；训练时电源设为「从不休眠」 |
| `ml\script\predict.py` 找不到 | 应为 `ml\scripts\predict.py`（多一个 s） |
| 想重新整理 | 直接再跑对应脚本，会清空输出目录后重建 |

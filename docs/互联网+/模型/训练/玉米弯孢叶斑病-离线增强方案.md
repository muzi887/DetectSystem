# 玉米弯孢叶斑病 — 离线增强方案

> 背景：公开数据集里**很难找到**单独的「玉米弯孢叶斑」叶片图包；当前 `ml-bjj/data/玉米弯孢叶斑病/` 仅约数十张原图。  
> 本文说明：为何难找、还能怎么补、以及本仓库的 **离线增强** 脚本怎么用。  
> 补图搜索词条见 [`玉米水稻补图-搜索词条.md`](./玉米水稻补图-搜索词条.md)。

---

## 一、问题是什么

| 项 | 说明 |
|----|------|
| 目标类 | **玉米弯孢叶斑病**（病原多为 *Curvularia* 属） |
| 当前状况 | 源图张数明显少于锈病、大斑等类（约 50～60 张量级） |
| 训练影响 | 类内样本少时，模型对该类容易欠拟合或置信度不稳 |
| 公开集现状 | Kaggle / Roboflow 上大量玉米包只有锈病、大斑、灰斑、健康，**几乎没有 `Curvularia` 文件夹** |

因此会出现：按文档搜 `curvularia leaf spot maize`，却**下不到**像穗腐、瘤黑粉那样「按类分好文件夹」的包——这属于常态，不是搜索方式错了。

---

## 二、为什么总下错包

搜 `curvularia` 时，结果里常混入与**训练用病叶图无关**的内容：

| 搜到的类型 | 例子 | 能否当训练图 |
|------------|------|----------------|
| 物种名录 / 分类论文 | GBIF、Plazi Checklist | **否**（无叶片照片集） |
| 菌株、降解实验 | 电缆 PVC 降解里的 *Curvularia lunata* | **否** |
| 通用玉米 7 类包 | Blight / Rust / Gray Leaf Spot / Healthy… | **否**（无弯孢类） |
| 胁迫、缺水数据集 | maize water stress | **否**（不是病害） |
| 加纳检测赛 | `Train.csv` + 大量 images | **否**（无弯孢类；且是检测格式） |

**易混、不要硬塞进「弯孢」**

- `Gray_Leaf_Spot` / `Cercospora` → 灰斑（系统无此类）
- 笼统 `Leaf Blight` / `Leaf Spot` → 病名不明确
- `Northern_Leaf_Blight` → 大斑，≠ 小斑，≠ 弯孢

---

## 三、还能怎么补真图（长期）

在跑离线增强之前或之后，仍建议**慢慢补真图**：

1. **论文附图**：Google Scholar / 知网搜「玉米 弯孢叶斑」「*Curvularia* maize leaf」，从 Supplementary figures 保存清晰病叶图（注意版权与许可）。  
2. **更精确的英文搜法**：`curvularia lunata maize leaf`、`curvularia maydis corn`、`maize foliar disease curvularia`；必须看到**叶片病斑预览**再下载。  
3. **实地拍摄**：京津冀田间若有样本，手机拍 20～50 张往往比再下 10GB 杂包更有价值。  
4. **Roboflow**：继续搜 `curvularia`，但只接受带预览、类名明确的 CV 包。

离线增强**不能替代**真图，只适合「暂时凑够训练张数、先训一版」。

---

## 四、离线增强是什么

**离线增强**：不联网、不下载新图，只用类文件夹里**已有原图**，在本机用脚本生成更多**变体图**（旋转、翻转、亮度等），文件名带 `aug_` 前缀，**不覆盖原图**。

```text
原图:     IMG_001.jpg
增强图:   aug_01_IMG_001.jpg
          aug_02_IMG_001.jpg
          aug_03_IMG_001.jpg
```

与「补图」对比：

| | 补图（下载新数据集） | 离线增强 |
|--|----------------------|----------|
| 图片来源 | 网上新图 | 现有文件夹内原图 |
| 真实性 | 高 | 变体，略弱于真图 |
| 适用 | 长期实地识别 | 少样本类先训起来、演示 |
| 本仓库脚本 | `classify_rice.py`、手工拷图等 | `augment_class.py` |

默认只处理 **`玉米弯孢叶斑病/`** 一类，避免给已充足的锈病、大斑等无谓扩增。

## 五、本仓库脚本：`augment_class.py`

路径：`ml-bjj/scripts/augment_class.py`  
依赖：项目已有的 **Pillow（PIL）**，无需新装包。

### 5.1 会做哪些变换

每张原图随机组合（温和，避免不像真叶）：

- 水平翻转（50% 概率）
- 小角度旋转（约 ±5°～±12°）
- 亮度、对比度微调
- 轻微中心裁剪后缩回原尺寸

### 5.2 命名与安全规则

- 新文件前缀：`aug_01_`、`aug_02_`…  
- **跳过**已以 `aug_` 开头的文件，避免重复执行时指数膨胀  
- **不修改、不删除**原图

### 5.3 用法（项目根 `DetectSystem`）

```powershell
# 1. 预览：统计将生成多少张，不写盘
python ml-bjj\scripts\augment_class.py --dry-run

# 2. 正式生成（默认每张原图额外 3 张）
python ml-bjj\scripts\augment_class.py

# 3. 可调倍数，例如每张 4 张
python ml-bjj\scripts\augment_class.py --per-image 4

# 4. 指定其他类（一般不需要）
python ml-bjj\scripts\augment_class.py --class 玉米弯孢叶斑病
```

示例：约 58 张原图 × 默认 `--per-image 3` ≈ **新增 174 张**，文件夹合计约 **232 张**（以你本机 `dry-run` 输出为准）。

### 5.4 增强之后必做

增强只增加 `data/玉米弯孢叶斑病/` 里的文件，**不会**自动更新 `bjj_cls/`。若只增强不 prepare，训练仍用旧 `bjj_cls`（与源图对不上，见 [`玉米水稻补图-搜索词条.md`](./玉米水稻补图-搜索词条.md)）。

```powershell
python ml-bjj\scripts\prepare_from_class_folders.py
python ml-bjj\scripts\train_cls.py --epochs 20
```

训完用 `predict.py` 或网页识病抽测弯孢类样本。

## 六、推荐决策流程

```text
还在找公开弯孢包？
    ├─ 找到带预览、类名明确的 CV 包 → 拷进 data/玉米弯孢叶斑病/ → prepare → train
    └─ 找不到或只有灰斑/大斑/锈病包 → 跳过，不要硬塞

需要尽快能训一版？
    └─ augment_class.py（先 dry-run）→ prepare → train

以后有实拍或论文图？
    └─ 直接追加进同一文件夹（原图与 aug_* 可并存）→ 再 prepare
```

**建议**：公开集继续「低频搜」；训练上先用 **离线增强 + 现有原图**，真图到手再逐步替换、不必删光 `aug_*`（除非你想减量）。

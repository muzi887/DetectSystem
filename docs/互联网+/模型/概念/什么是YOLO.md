# 什么是 YOLO

> 面向零基础：YOLO 是什么、和「整张图分类」差在哪，以及本仓库里哪里会碰到它。  
> 深度学习框架见 [`什么是PyTorch.md`](./什么是PyTorch.md)。  
> 水稻 YOLO 包转中文类文件夹见 `ml-bjj/scripts/classify_rice.py`。

---

## 一、一句话定义

**YOLO**（You Only Look Once，你只看一次）是一类 **目标检测** 算法：一张图里同时找出「有什么物体」和「在图的哪个位置」（通常用矩形框标出）。

可以把它想成：不仅说「这是稻瘟病」，还标出「病斑在叶片的哪一块」。

本项目正式识病服务（`ml-bjj`）当前主路径是 **整图分类**（一张图 → 一个病名），不是线上跑 YOLO 检测。补数据时却常下载到 **YOLO 格式** 的公开数据集，所以需要认识它。

---

## 二、检测 vs 分类（和本项目的关系）

| | 图像分类（本项目主用） | 目标检测（YOLO 一类） |
|--|------------------------|------------------------|
| 问什么 | 整张图属于哪一类？ | 图里有哪些目标、各在哪？ |
| 标签 | 类名（如「稻瘟病」） | 类名 + 框坐标 |
| 典型输出 | `稻瘟病 0.91` | 多个框：`稻瘟 [x,y,w,h] 0.88` |
| 本仓库 | `train_cls.py` / `predict.py` | 多见于下载的第三方数据包 |

```text
分类：  [整张叶片照片] → 一个病名
检测：  [整张叶片照片] → 若干框 + 每个框的病名
```

补图时：若只做分类训练，往往 **只要图片和类名**；YOLO 包里的框标注可以忽略，但要把图按类归进 `ml-bjj/data/<中文类名>/`。

---

## 三、「YOLO 格式」数据包长什么样

社区里说「YOLO 数据集」，多半指 Ultralytics / YOLOv5 一类目录约定，而不是「必须跑 YOLO 模型」：

```text
某数据集/
  images/
    train/   xxx.jpg
    valid/   ...
    test/    ...
  labels/
    train/   xxx.txt   ← 与图片同名
    ...
  data.yaml 或 *.yaml  ← 写清有几类、类名是什么
```

每个 `labels/*.txt` 一行通常是：

```text
<类别编号> <中心x> <中心y> <宽> <高>
```

坐标一般是相对整图宽高的 **0～1 小数**。类别编号对应 yaml 里的 `names` 列表下标。

**本仓库实例**：`ml-bjj/data/archive (2)/RiceDiseaseDataset_yolo_test/`  
- `rice_detection.yaml` 里 `nc: 3`，类名为 `Brown_Spot`、`Rice_Blast`、`Bacterial_Blight`  
- 有 `images/` + `labels/`，属于检测用包；补分类时按文件名/类映射拷到中文文件夹即可。

另一常见来源是按类分好的 YOLO 分类/检测包，脚本 `classify_rice.py` 用 yaml 里的英文类名映射到中文（如 `Rice__LeafBlast` → `稻瘟病`）。

---

## 四、名字里为什么叫「只看一次」

早期检测方法会在图上滑很多窗口、或分两阶段先找区域再分类，速度慢。YOLO 把「找框 + 认类」放进 **一次前向计算**，所以叫 You Only Look Once，适合实时场景（摄像头、无人机）。

后来有很多代：YOLOv3、v5、v8、v11 等，接口和权重格式略有差别，但「检测 + 常见数据集目录」这一思路大致相同。

---

## 五、和本项目相关的注意点

1. **下载到 YOLO 包 ≠ 要改成 YOLO 识病**。先确认目标是补分类样本，还是真要做病斑定位。  
2. **有框不等于类名和你们一致**。必须对照 yaml 的 `names`，再映射到 `稻瘟病`、`水稻白叶枯病` 等；对不上的类不要硬塞。  
3. **test 集有的比赛不给标签**。补图优先用带标签的 `train`（或已按文件夹分好的类目录）。  
4. **增强图**（文件名带 `rotated` 等）与原图高度相关，大量掺入可能虚增张数、对实地泛化帮助有限，可酌情少用。

## 六、和「Paddy Doctor」等分类比赛的区别

| | Paddy Doctor 一类 | archive (2) 一类 |
|--|-------------------|------------------|
| 常见组织 | `train_images/blast/` 按文件夹分好类 | `images/` + `labels/*.txt` |
| 任务 | 分类竞赛 | 检测格式 |
| 补分类 | 直接拷文件夹 | 按 yaml/文件名归类后再拷 |

两者都可能叫「水稻病害数据」，**目录结构不同**；先看有没有 `labels/*.txt` 和 `names:`，就能判断是不是 YOLO 检测格式。

## 三、当前能识别什么

### 3.1 23 类清单（Serving / `classes.txt` 目标）

与 `CANONICAL_CLASSES` 一致：

```text
健康
小麦锈病、小麦赤霉病、小麦白粉病、小麦蚜虫为害
玉米大斑病、玉米锈病、玉米南方锈病、玉米小斑病
玉米弯孢叶斑病、玉米褐斑病、玉米瘤黑粉病、玉米茎腐病、玉米穗腐病
番茄早疫病
水稻白叶枯病、水稻褐斑病、水稻负泥虫为害、稻瘟病
水稻叶鞘腐败病、水稻叶黑粉病、水稻窄条斑病、稻颈瘟
```

「健康」仍是 **全局 1 类**。小麦三种锈病仍合并为「小麦锈病」。

### 3.2 8 类权重实际能分的类（未替换前）

```text
健康
小麦锈病、小麦赤霉病、小麦白粉病、小麦蚜虫为害
玉米大斑病、玉米锈病
番茄早疫病
```

即：没有水稻 8 类、没有玉米南方锈病等 7 个新增玉米类。即使用 23 类门禁强行改代码放行 8 类，也不该在答辩里说能识稻瘟。

### 3.3 按作物（掩码之后 · 23 类权重到位后）

| 作物 | `cropType` | 允许的病名 |
|------|------------|------------|
| 小麦 | `wheat` | 健康 + 4 个小麦类 |
| 玉米 | `corn` | 健康 + 9 个玉米类 |
| 番茄 | `tomato` | 健康 + 番茄早疫病 |
| 水稻 | `rice` | 健康 + 8 个水稻类 |

未知 `cropType` 不过滤。`peach` / `apple` / 桃 / 苹果 **直接 400**，不进入推理。

### 3.4 命令行抽测（8 类权重 · 2026-07-09）

```powershell
python ml-bjj\scripts\predict.py --image "ml-bjj\data\bjj_cls\val\小麦锈病\小麦锈病_00001.png"
# 小麦锈病  87.87%

python ml-bjj\scripts\predict.py --image "ml-bjj\data\bjj_cls\val\玉米大斑病\玉米大斑病_00001.jpg"
# 玉米大斑病  91.51%
```

`predict.py` 默认加载 `pest-cls-best.pt`，**不做作物掩码**（与网站不同）。

### 3.5 当前能做 / 不能做

| 能力 | 状态 | 说明 |
|------|------|------|
| 按前端选的作物过滤结果 | ✅ Serving | softmax 之后掩码再归一化 |
| 防治方案 | ✅ | `treatments.json` 23 类；分析/决策页已接 |
| top-3 与人工复核标记 | ✅ Serving | `topk`、`needs_review`（低置信或 top1–top2 分差小） |
| 批量多图 | ✅ | P3 batch 入口 |
| 病名 × 温湿墒升降级 | ✅ Serving P3 | 挂在**这一次识别**上，不是 Mock 链 1 落库 |
| 受害区域框选（检测框） | ❌ | 仅分类 |
| 严重程度轻/中/重 | ❌ | 不输出 |
| 小麦锈病拆条锈/叶锈/秆锈 | ❌ | 不拆类；输入别名回落为「小麦锈病」 |
| 保证河北实地 100% 准确 | ❌ | 见 §五 本土化 |
| 8 类权重下启动 23 类门禁服务 | ❌ | 必须先重训 23 类 |
| 桃 / 苹果 cropType | ❌ | Serving 返回 400；分析页无选项 |

### 3.6 与网站文案

| 名称 | 23 类目标是否直接输出 |
|------|------------------------|
| 小麦锈病 / 赤霉病 / 白粉病 | ✅ |
| 玉米大斑病 / 锈病 / 南方锈病等 | ✅（权重到位后） |
| 番茄早疫病 | ✅ |
| 稻瘟病 / 稻颈瘟等水稻类 | ✅ 防治库、`rice` 掩码、Mock 样例已接。**真实出这几个病名**须 23 类权重（`bjj_cls` 已是 23 类，磁盘 `pest-cls-best.pt` 仍是 8 类） |
| 桃、苹果相关 | ❌ 不输出。分析页无选项；Serving 拒收作物；病名（桃缩叶病等）不进防治/预警文案 |
| 小麦条锈病 / 叶锈病 / 秆锈病 | ❌ 不作为独立类。别名一律回落为 **小麦锈病**（分析页、预警、防治接口） |

## 五、本土化测试：需要怎样的图片

### 5.1 原则

```text
拍清楚「病斑/虫害主体」> 拍整片田
一种图只突出一个主要问题
叶片/穗部特写，光线自然
```

### 5.2 格式与数量

| 要求 | 建议 |
|------|------|
| 格式 | JPG / PNG |
| 分辨率 | 短边 ≥ 512 px |
| 单张大小 | ≤ 2 MB（对接网站时） |
| 首轮摸底 | 每类 **3–5 张**；23 类不必一次拍齐，优先小麦锈病/赤霉、玉米大斑、稻瘟 |

### 5.3 拍摄内容

**小麦（优先）**：锈病叶斑、赤霉穗部、白粉、蚜虫为害、同地块健康叶。  
**玉米**：大斑、锈病；有条件再拍南方锈、小斑、弯孢等。  
**番茄**：早疫病轮纹斑。  
**水稻**（23 类）：叶瘟梭斑、穗颈瘟、白叶枯等，与类名文件夹一致。

最小可行仍可先走小麦+玉米+番茄约 20–25 张摸底（与 8 类时期相同），水稻另补。

## 六、如何执行本土化测试

### 6.1 命令行

```powershell
cd D:\code2\software\vue\program\DetectSystem
ml-bjj\.venv\Scripts\Activate.ps1

python ml-bjj\scripts\predict.py --image "D:\你的路径\20260710_河间_小麦_锈病_01.jpg"
```

指定权重：

```powershell
python ml-bjj\scripts\predict.py --image "图片.jpg" --weights ml-bjj\models\pest-cls-best.pt
```

记录：**人工标签**、**模型输出**、**置信度**。网站路径另记所选 `cropType`（命令行无掩码，可能与页面第一名不同）。

### 6.2 结果记录表

| 文件名 | 地块 | 人工判断 | 模型输出 | 置信度 | 是否一致 |
|--------|------|----------|----------|--------|----------|
| 小麦锈病_00001.png | 验证集 | 小麦锈病 | 小麦锈病 | 87.87% | ✅ |

可保存为 `ml-bjj/data/local_test/results.csv`。

### 6.3 结果怎么用

| 结果 | 建议动作 |
|------|----------|
| 一致且置信度 ≥ 80% | 答辩备用图 |
| 一致但 70%–80% | 可用，说明建议复核 |
| 不一致或 &lt; 70% | 收入 `hard_cases/`，见 v3.1 文档 |
| 某类完全无法识别 | 补拍 → 源图目录 → `prepare_from_class_folders.py` → 重训 |

## 七、实地照片若要加入训练

1. 文件夹名必须是 **23 类中文名**（与 `classes.txt` 一致）  
2. 放入 `ml-bjj/data/<类名>/` 后跑 `prepare_from_class_folders.py`（不要用已删除的 `prepare_bjj.py`）  
3. `python ml-bjj\scripts\train_cls.py --data-dir ml-bjj/data/bjj_cls --epochs 20`  
4. 确认新 `pest-cls-meta.json` 为 23 类后再覆盖 `pest-cls-best.pt`，重启 serving

| 目标 | 是否要实地数据 |
|------|----------------|
| 解开 23 类门禁、网站能识水稻/新玉米类 | **必须重训**（公开源图即可先训一版） |
| 提高京津冀实地准确率 | **强烈建议** 抽测 20–40 张 |
| 答辩只演示非 AI 闭环 | 不必须等实地 |

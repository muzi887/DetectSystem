# 什么是 PyTorch

> 本文档面向 **零基础读者**，用通俗语言解释 PyTorch 是什么、能做什么，以及它在本项目（作物灾害智慧监测预警系统）中如何被使用。  
> 机器学习整体概念见 [`什么是机器学习.md`](./什么是机器学习.md)。  
> 若你想直接动手训练模型，请阅读 [`AI模型训练说明.md`](./AI模型训练说明.md) 或 [`ml-bjj训练操作手册.md`](./ml-bjj训练操作手册.md)。

---

## 一、一句话定义

**PyTorch** 是 Meta（原 Facebook）开源的 **深度学习框架**。用 Python 就能搭建神经网络、训练模型、做推理。本项目的作物病虫害分类模型（`ml-bjj`）就是用它训练和部署的。

可以把它理解成：**给神经网络用的「工具箱 + 计算器」**。你负责准备图片和标签，PyTorch 负责在 GPU 或 CPU 上做大规模数值计算，并自动算出该如何调整模型参数。

Python 里导入时写的是 `import torch`，所以文档和代码里常把 **PyTorch** 与 **torch** 混称，指的是同一套库。

---

## 二、它解决什么问题

传统代码靠人写规则；深度学习让模型从大量图片里自己学特征。要把这件事跑起来，需要三样能力：

1. 把图片变成数字，并能放到 GPU 上加速；
2. 训练时自动计算「错了多少、该往哪改」；
3. 用现成积木搭出卷积、全连接、损失函数、优化器。

PyTorch 分别对应这三件事：**张量（Tensor）**、**自动求导（Autograd）**、**神经网络模块（`torch.nn`）**。

```text
上传一张叶片照片
      ↓
变成数字（张量 Tensor）
      ↓
送进神经网络（torch.nn）
      ↓
输出 23 类各自的分数 → softmax 变成概率
      ↓
取出最可能的病名 + 置信度
```

## 三、用一个生活例子理解

| 角色 | 对应物 |
|------|--------|
| 学生 | 神经网络（模型） |
| 练习册 | 标注好的叶片图片（训练集） |
| 批改老师 | 损失函数（告诉模型「这次错在哪」） |
| 订正方法 | 优化器（按梯度更新参数） |
| 草稿纸 + 计算器 | **PyTorch** |

没有 PyTorch，你要自己实现矩阵乘法、反向传播、GPU 调度。有了它，训练循环可以写成：前向计算 → 算损失 → 反向传播 → 更新参数。

## 四、几个关键概念

### 4.1 张量（Tensor）

多维数组，用法接近 NumPy，但可以放到 **GPU** 上加速。一张 RGB 图片在模型里通常是形状为 `(3, 高, 宽)` 的张量；一批图则是 `(批次, 3, 高, 宽)`。

### 4.2 自动求导（Autograd）

训练时模型会算一个「损失」（预测和正确答案差多远）。PyTorch 能自动对所有可训练参数求梯度，相当于告诉每一层：「往这个方向改，下次会更准」。

### 4.3 神经网络模块（`torch.nn`）

卷积层、线性层、激活函数、损失函数等都封装成模块。本项目分类模型建立在预训练视觉网络之上（经 `timm` 加载），再用本项目 23 类数据微调。

### 4.4 权重文件（`.pt`）

训练完成后，学到的参数保存为 `.pt` 文件。本项目主权重是 `ml-bjj/models/pest-cls-best.pt`。推理服务启动时 `torch.load` 加载，不必重新训练。

### 4.5 Softmax

模型最后一层给出各类的原始分数（logits）。`torch.softmax` 把它们变成 **和为 1 的概率**。它和作物掩码是前后两步，数字例子见 [`作物掩码与推理接入.md`](./作物掩码与推理接入.md) 第三、四节。

### 4.6 CUDA / GPU

| 检查结果 | 含义 |
|----------|------|
| `torch.cuda.is_available()` 为 `True` | 本机有 NVIDIA 显卡，训练和推理更快 |
| 为 `False` | 用 CPU 也能跑，只是更慢 |

本项目健康检查接口会返回 `cuda` 字段，方便确认当前推理跑在 GPU 还是 CPU。

## 五、一次训练在做什么

```text
① 读一张（或一批）已标注图片
      ↓
② 变成张量，送进模型 → 得到各类分数
      ↓
③ 用损失函数比较「预测」和「正确答案」
      ↓
④ 反向传播：自动算出每个参数该怎么改
      ↓
⑤ 优化器（如 AdamW）按学习率更新参数
      ↓
⑥ 重复成千上万次，直到验证集准确率不再提升
```

对应代码直觉（不必背，理解流程即可）：

```python
import torch

# 前向：模型看图，给出分数
logits = model(images)
loss = criterion(logits, labels)

# 反向：算出梯度并更新参数
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

本项目训练脚本是 `ml-bjj/scripts/train_cls.py`，产出 `pest-cls-best.pt` 与 `pest-cls-meta.json`。

## 六、和 TensorFlow 等有何不同

| 对比项 | PyTorch | TensorFlow |
|--------|---------|------------|
| 写法 | 更接近普通 Python，调试直观 | 早期偏静态图，现也支持即时执行 |
| 研究与视觉项目 | 使用更广 | 工业部署历史上更常见 |
| 本项目 | **采用 PyTorch**（`torch` / `torchvision`） | 未作为主框架 |

两者都能训练和上线。本仓库选择 PyTorch，是因为视觉分类生态（`timm`、`.pt` 权重、现有 `serving` 代码）都围绕它。

相关库：

| 包名 | 作用 |
|------|------|
| `torch` | 核心：张量、自动求导、神经网络 |
| `torchvision` | 图像变换、常用视觉模型与数据集工具 |
| `timm` | 大量预训练图像模型，本项目用它加载骨干网络 |

## 七、在本项目中的位置

```text
DetectSystem
├── ml-bjj/
│   ├── requirements.txt      # 声明 torch、torchvision
│   ├── scripts/train_cls.py  # 用 PyTorch 训练 23 类
│   ├── models/*.pt           # 训练得到的权重
│   └── serving/              # 推理时 import torch，加载权重
└── 网站「智能分析」页         # 调用推理 API，不直接 import torch
```

**数据流简述**：

```text
用户选作物并上传图片
      ↓
Flask 推理服务（ml-bjj/serving）
      ↓
PyTorch 加载 pest-cls-best.pt，输出 23 类概率
      ↓
按作物做掩码与归一化（只保留小麦/玉米/番茄/水稻相关类 ∪ 健康）
      ↓
返回病名、置信度、topk、needs_review、防治建议
```

前端 Vue 页面 **不运行 PyTorch**；PyTorch 只在 Python 训练脚本和推理服务里工作。

## 八、如何确认本机已安装

在已激活的 Python 环境中执行：

```powershell
python -c "import torch; print('PyTorch', torch.__version__); print('CUDA', torch.cuda.is_available())"
```

- 能打印版本号：安装成功。
- `CUDA True`：可用 GPU 加速。
- `CUDA False`：CPU 模式，功能完整，速度较慢。

安装依赖（在 `ml-bjj` 目录）：

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 十、小结

| 要点 | 说明 |
|------|------|
| **本质** | Python 深度学习框架，用来训练和运行神经网络 |
| **核心能力** | 张量计算、自动求导、现成网络模块、GPU 加速 |

## 二、现网（按 23 类已就绪）应写成什么样

```text
浏览器 → Nginx :88
            └─ /api 全部 → Flask :5000（ml-bjj/serving）
                              ├─ /api/analysis/*、/api/treatments  23 类识病 + 防治库
                              ├─ /login、/monitorPoints、/alerts…  自研 REST
                              └─ SQLAlchemy → 云端 MySQL detect_system
                                    三条规则链 + 60 秒调度写 alerts
```

说明书 **禁止** 再写：业务走 json-server / Mock `:3000`、图片分析在 `server/app.py` 按哈希分类、后端约 392 行、作物下拉含桃/苹果作为可识别类。

说明书 **必须如实保留** 的演示边界（避免第二次文实不符）：

- GIS 点选墒情：最近监测站土壤湿度，不是专业插值产品（现 §4.3.5 已写，保留）。
- 相关数据底部「AI 智能分析」：按读数/预警 **拼句子**，不是第二次模型推理。
- 简报：现实现是拉日报 markdown、下载 **txt**，不是 PDF。现 §4.3.7 写「演示 PDF」须改正。
- 东北监测点可有预警；遥感地块种子目前主要是河间/雄县/栾城。

**§4.5 在 23 类已就绪时的写法（技术方法，对应第二份通知）：**

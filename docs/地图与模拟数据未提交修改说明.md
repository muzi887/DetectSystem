## 行为变化

### 地图展示

原先使用：

```ts
https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png
```

现在使用：

```ts
https://webst0{s}.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z}
```

因此页面更偏向真实地理影像展示，适合查看植被、水系、地貌等自然要素。

### Mock 数据热读取

`json-server` 默认会把 `db.json` 缓存在内存中。新增中间件后，每次 GET 请求会重新读取 `db.json`：

```ts
server.use((req: Request, _res: Response, next) => {
  if (req.method === 'GET') {
    const db = JSON.parse(fs.readFileSync(dbPath, 'utf-8'))
    router.db.setState(db)
  }
  next()
})
```

这样覆盖线上 `api_mock/db.json` 后，通常只需刷新页面即可看到最新点位；若更新了 `server.js`，仍建议重启宝塔 Node 项目。

## 部署注意事项

1. 若只改 `db.json`，上传覆盖 `/www/wwwroot/DetectSystem/api_mock/db.json` 后刷新页面即可验证。
2. 若改了 `server.js`，上传覆盖后需要在宝塔 Node 项目中重启 `api_mock`。
3. 若改了 `MapVisualization.vue`，必须重新构建前端并上传新的 `dist`：

```bash
pnpm build
```

4. 线上如访问 `/home` 出现 Nginx 404，需要确认站点配置包含：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```
